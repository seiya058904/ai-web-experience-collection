# GRID — Collection adaptation

GRID — The Architecture of Visual Order is the supplied original twelve-system visual study. Its persistent semantic article, live typography, layout, original photograph and raster treatment are retained. Runtime source is adapted for the Collection's independent multi-page lifecycle, navigation and root-locked dependencies. No additional whole-application MIT license is asserted.

The photograph is **Bw Stairs** by **Dmitrijs Milajevs (2018)**, licensed **CC BY3.0**. It is locally served byte exact; the work crops, rotates, changes contrast and processes its raster. See [PHOTO-ATTRIBUTION.md](licenses/PHOTO-ATTRIBUTION.md) for the original source, author and license links. Actual gallery captures contain this credited photograph plus live code-built lettering, not AI composition-study images.

Roboto Flex, Instrument Serif and IBM Plex Mono are local fonts under their respective SIL Open Font License records. Original asset provenance and all supplied notices are preserved in [licenses](licenses/README.md). Historical relative paths/versions in upstream records refer to the standalone delivery. Current Collection runtime uses installed Lenis1.3.26 and GSAP3.15.0 without dependency updates. Vite notices describe upstream build tooling, not a second deployed build.

The series metadata describes a fictional specimen, not a physical exhibition. AI-assisted Visual Bible research is preserved as provenance, never deployed as live typography or navigation.
