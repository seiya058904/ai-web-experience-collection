# FRAME · Windows 启动说明

## 打开独立网页

完整解压 ZIP 后，用浏览器打开根目录的 **`FRAME.html`**（约 **2.68 MB**）。它已嵌入网页所需的图片、字体和程序，无需安装 Node.js 或 npm，也无需联网。它与第十章导出的独立短片是两个文件。

当前浏览器验证环境不允许完成本地 `file://` 打开检查，也未在 Windows 真机执行；此项仍未实测。需要通过本地地址打开时，可使用下面的启动方式。

## 通过本地服务体验附带的成品

1. 先把 ZIP **完整解压**到一个文件夹，不要在压缩包预览窗口里运行。
2. 安装 **Node.js 24**。若电脑已经安装，可在终端执行 `node --version` 查看版本。
3. 双击 **`Start-Frame.cmd`**。脚本会启动本地服务，并打开浏览器。
4. 使用期间保留终端窗口；结束后关闭窗口，或按 `Ctrl+C`。

默认地址：**http://127.0.0.1:4173/**。

交付包包含 `dist` 成品时，启动无需执行 `npm install`，也不需要付费服务或运行 API。Node.js 安装完成后，可以离线体验。网页本身统一使用英文。

若默认端口已被占用，在此文件夹打开终端，执行：

```powershell
node scripts/serve-built.mjs --port 4174
```

然后打开 **http://127.0.0.1:4174/**。

## 修改源码

首次安装依赖需要联网。在项目文件夹打开 PowerShell：

```powershell
npm ci
npm run dev
```

检查和重新构建：

```powershell
npm test
npm run build
npm run preview
```

如果 PowerShell 提示不允许运行 `npm.ps1`，可将上面的 `npm` 写成 `npm.cmd`，无需修改系统执行策略。

## 带走自己的短片

在第八章调整间距与两处停顿，第九章播放自己的版本，第十章下载 PNG 分镜或 HTML 小片。导出的 HTML 应包含必要画格和时间表，可以直接双击，在本地独立重放。

根目录的 `FRAME.html` 是独立网页；`dist/index.html` 请通过附带启动脚本或本地服务打开，保持 `dist` 内资源结构完整。

最终测试结果以交付验收报告与 `evidence` 中的真实证据为准；本启动说明本身不代表已完成验收。
