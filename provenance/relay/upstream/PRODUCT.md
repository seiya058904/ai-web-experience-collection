# RELAY — A Message Finds Its Way

An English-language, browser-local interactive artwork about a sentence crossing an unreliable transport environment. The visitor can intervene and observe a true change in delivery, ordering, retransmission, and acknowledgement. Audience: curious people, without assumed networking knowledge.

## Product truth

- Entire simulation is memory-only and never sends the visitor's message over the network.
- This is an original toy protocol, not TCP, QUIC, BGP, or a network monitoring dashboard.
- Three independent times: scroll composition, simulation clock, read-only recorded history.
- Fixed byte ranges, seeded deterministic discrete events, finite retries, explicit terminal states.
- Six observation chapters from a partial sentence through a whole sentence or an honest failure.
- Interventions: toggle a channel, change channel speed, discard one acknowledgement.
- New rounds are explicit; scrolling and historical inspection never create sends.
- All text is live DOM/SVG. All fonts and runtime assets are local.

## Pinned art direction

Warm ivory #F1EBDD, graphite #292B29, vermilion #D94D2F for data, pine #55766A for acknowledgements. Wide sculptural tracks and fine enamel-like packets. Generous typography safe zones. Orthographic / shallow depth; no neon network globe. Vertical mobile reconstruction, not a reduced desktop diagram.

## Delivery boundary

Only a clean source ZIP, with lockfile, sources, assets, English setup instructions, real concept records, model rules and testing evidence. Local development and internal QA only. No deployment, public preview sharing, git push, or changes to existing repositories.
