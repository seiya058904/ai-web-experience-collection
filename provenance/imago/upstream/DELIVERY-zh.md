# IMAGO — 交付说明

## 已完成

IMAGO 是一部以同一只想象中的帝王蝶为主角的英文互动自然史网站。十章依次覆盖蛹的初见、卵、取食、蜕皮、结蛹、发育、翅纹显现、羽化、展翅和离场；九处相邻交接均提供可停留、可返回的阶段画面。

视觉采用骨白、深叶绿、玉绿和少量翼橙，配合 Cormorant Garamond 与 Inter。本次实际生成了 **31 张图像成果**，形成 **27 个正式图像角色**，其中包含三个 Hero 候选、桌面精修、独立竖版构图、支撑点修正版、羽化中间阶段、枝条到卵叶的空间衔接，以及末章停栖画面。它们是艺术重构，网站已明确说明这一点。

观察工具包含卵的近看、初孵与三龄对照、五个龄期说明、三阶段结蛹、外观与发育示意切换、早中晚蛹体观察、并排比较、拖动揭示、四个羽化画面、展翅阶段及前翅／后翅／身体细节。结尾离场由用户主动触发，也可直接查看终景或恢复停栖。

源码使用 TypeScript、Vite 和实际集成的 Lenis。状态由滚动位置和明确操作决定；页面提供原生章节链接、键盘操作、减弱动态模式、图片回退与重试。环境声默认为关闭，开启后播放合成的柔和空气声。

## Windows 启动

1. 完整解压压缩包，进入 `IMAGO` 文件夹。
2. 安装包含 npm 的 **Node.js 22.12 或更新版本**。
3. 双击 `start-imago.cmd`。首次缺少依赖时，脚本会执行 `npm ci`。
4. 用浏览器打开终端实际显示的本地地址。
5. 检查生产构建时，使用 `build-preview.cmd`；停止服务按 Ctrl+C。

也可以在项目目录执行：

```sh
npm ci
npm run dev
```

首次安装依赖需要联网。图片和生产字体都在包内，网站运行不需要账号、API Key 或外部运行服务。不要直接双击 HTML 文件打开；请使用本地 HTTP 服务。Windows 脚本经过源码检查，但没有在真实 Windows 机器上执行。
