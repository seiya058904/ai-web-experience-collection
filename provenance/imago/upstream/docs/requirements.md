## Reporting rules

Record browser/version, CSS viewport, DPR, known device information, and actual network/CPU throttling. Distinguish viewport sizing from real hardware, saved-state visual review from continuous motion, and a candidate build from the final archive. Preserve failures and their corrections. Do not infer FPS, Lighthouse results, physical-device behavior, or screen-reader coverage from these records. A concept image is not a browser screenshot; a successful build or matrix is not a complete visual verdict.
