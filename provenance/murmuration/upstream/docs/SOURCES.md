# Sources and creative boundaries

Primary sources revisited on **24 October 2026**. These sources inform the work; their text, photographs, installation imagery and recordings are not repackaged as production assets.

| Primary source | What was used | Boundary in this work |
| --- | --- | --- |
| [Craig Reynolds — Boids](https://www.red3d.com/cwr/boids/) and [1987 paper, Flocks, Herds, and Schools](https://www.cs.toronto.edu/~dt/siggraph97-course/cwr87/) | Local separation, alignment and cohesion as a basis for collective behavior. | The controls alter those implemented steering terms. The artwork makes no claim of a universal biological explanation. |
| [Ballerini et al. — Interaction ruling animal collective behavior depends on topological rather than metric distance](https://arxiv.org/abs/0709.1916), PNAS 105, 1232–1237 (2008) | The studied starling flocks motivated a small local neighborhood; about six or seven interacting neighbors was a result in that study. | The implementation uses an approximate bounded query for up to seven neighbors. That number is not presented as a law for every flock. |
| [Attanasi et al. — Information transfer and behavioural inertia in starling flocks](https://arxiv.org/abs/1303.7097), Nature Physics 10, 691–696 (2014) | Observed turning information travels through a flock. | The recorded perturbation in this site is produced by its own simple model. It does not reproduce the paper's particular dynamics, propagation speed or measurements. |
| [RANDOM INTERNATIONAL — Swarm Study / I](https://www.random-international.com/swarm-study-/-i) | The visitor can become part of a responsive collective. | This informs the causal interaction, not the installation's hardware, geometry or visual design. No source artwork image is included. |
| [DRIFT — Flylight](https://studiodrift.com/work/flylight/) | A work that sustains attention on relationships between an individual and a group. | The site keeps its own natural sky and winged agents. It does not copy glass lighting elements or an exhibition interior. |
| [Lenis official repository](https://github.com/darkroomengineering/lenis) | Official ScrollTrigger integration: Lenis scroll callback, GSAP ticker time in milliseconds, disabled automatic RAF. | One Lenis instance and one coordinated ticker. Installed version is pinned to 1.3.27. |
| [GSAP ScrollTrigger documentation](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) | Progress evaluation and deliberate geometry refresh. | One shared progress source; no independent competing scroll loop. Installed GSAP is pinned to 3.15.0. |
| [Playwright Page API](https://playwright.dev/docs/api/class-page) | Actual viewport rendering, input, screenshots, routing and browser checks. | Routing disables HTTP cache; cache validation therefore uses a separate real loopback HTTP fixture. Browser coverage is explicitly reported. |
| [Vite JavaScript API](https://vite.dev/guide/api-javascript.html) | An isolated, ephemeral development server for verification. | Local test use only; no deployment or preview sharing was performed. |
| [Chrome Page Lifecycle API](https://developer.chrome.com/docs/web-platform/page-lifecycle-api) and [Chromium page scheduler implementation](https://chromium.googlesource.com/chromium/src/+/HEAD/third_party/blink/renderer/platform/scheduler/main_thread/page_scheduler_impl.cc) | Distinct visibility, freeze and resume behavior; a visible page cannot be used as proof of a real background freeze. | The native suite activates another tab, records real hidden/freeze/resume events, and checks the first returning model state. |
| [Playwright issue 2286: foreground page behavior](https://github.com/microsoft/playwright/issues/2286) | Why ordinary Playwright pages cannot establish native background lifecycle coverage. | A fresh Chromium process is controlled through the public DevTools protocol for that specific check; no page visibility property is patched. |

## Authored data and visual assets

`src/hero.json`, `public/records/flight.bin.gz` and the propagation evidence are generated by the included deterministic model. The opening posters are captured from its actual Canvas output. They contain no substituted flock photograph.

The empty sky was generated specifically for this project using `image_gen.imagegen`. Five additional real generations explored composition before production, including two different hero routes. Their prompts, tool-returned filenames, original image hashes, dimensions and roles are in `IMAGE_GENERATION.json`. Compact reference images and the selection rationale are in `concepts/` and `VISUAL_BIBLE.md`.

No stock-photo package, scraped installation photograph, remote image hotlink, external font CDN, icon service or sound library is used. The small emblem and all bird geometry are original vector/code assets.
