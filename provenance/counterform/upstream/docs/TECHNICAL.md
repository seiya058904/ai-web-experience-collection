# COUNTERFORM — 技术说明

本项目由静态 HTML、CSS、SVG 和 JavaScript 组成。浏览器直接读取随包提供的资源；预览阶段没有构建步骤、后端服务、API 密钥或第三方网络依赖。运行方法见 [README](../README.md)，最终检查结果见 [QA](QA.md)。

## 1. 结构与资源入口

`index.html` 按顺序延迟加载本地 Lenis、已打包材质、`src/type-handoff.js` 和 `app.js`。正文与控件保留在语义化 HTML 中，内联 SVG 提供准确的字形轮廓；材质画布补充 MARK 与 PRESS 的空间表现。

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 内容与结构 | `index.html` | 七个章节、SVG 定义、章节目录、来源说明、原生表单。 |
| 视觉系统 | `styles.css` | 字体声明、颜色与尺度、桌面和移动构图、阅读模式。 |
| 应用控制 | `app.js` | 统一 RAF、Lenis、场景进度、导航与焦点、变轴设置、状态恢复。 |
| 文字交接 | `src/type-handoff.js` | 使用真实 Range 行框测量，将同一组原生文字从实验区位置移到终章位置；无独立 RAF。 |
| 字形依据 | `docs/font-spec.json`、`index.html` 的内联 SVG、`src/materials.js` | 真实字体实例、度量、完整轮廓和独立字腔。 |
| 材质实现 | `src/materials.js` → `assets/materials.js` | 凹刻石材、金属字面、纸面印迹与绝对进度渲染。 |
| 本地预览 | `scripts/serve.mjs` | 使用 Node.js 内置模块的静态文件服务器，默认 `127.0.0.1:4173`。 |

Node 启动脚本需要版本 20 或更高；运行 `npm start` 不会下载依赖。使用 Python 静态服务器也可预览。可通过环境变量 `PORT` 改变 Node 服务器端口；它始终绑定本机回环地址。

## 2. 真实字体与变轴映射

运行文件为三个本地 WOFF2：Fraunces 正体、Fraunces 斜体、Roboto Flex。原始 TTF、SIL OFL 1.1 文本与来源记录随包保留。轮廓提取、版本和字符覆盖详见 [FONT-SOURCES](FONT-SOURCES.md)。

### 公开实验区

LIVING TYPE 与 PAGE 共用 Roboto Flex、同一个文字状态和同一组轴值。

| 控件 | 实际轴 | 范围 | 页面初始值 | 对应 CSS |
| --- | --- | --- | --- | --- |
| Weight | `wght` | 100–1000 | 650 | `font-weight: var(--weight)` |
| Width | `wdth` | 25–151 | 100 | `font-stretch: var(--width)`；变量保存百分比 |
| Optical size | `opsz` | 8–144 | 72 | `font-optical-sizing: none`，`font-variation-settings: 'opsz' var(--optical)` |

这里的初始值是作品选择的设计实例，不是字体二进制默认值。Roboto Flex 的二进制默认值分别为 `wght=400`、`wdth=100`、`opsz=14`。它还有十个真实轴，公开控件没有改变那些轴的默认值。

宽度来自字体的实际 `wdth` 轴。光学字号控制为不同阅读尺寸设计的细节，它不等于 CSS `font-size`。`fitType()` 只在内容可能溢出时，按真实行框调整显示字号：先尝试目标字号，再进行 11 次有界查找。这个容纳文字的布局步骤与三个字体轴各自独立。

Fraunces 的实际轴为 `wght` 100–900、`opsz` 9–144、`SOFT` 0–100、`WONK` 0–1；随附文件没有 `wdth`。不要给它接入虚构的宽度控制器。每个字体的全部二进制默认值见 `font-spec.json`。

## 3. 字形、度量与实体几何

字形几何从随附字体的指定实例提取，采用其实际轮廓，未使用位图文字或手画的近似 R。

| 实例 | 选定轴值 | em 单位 | Cap height | x-height |
| --- | --- | --- | --- | --- |
| Fraunces | `wght=600, opsz=100, SOFT=0, WONK=1` | 2000 | 1400 | 881.043 |
| Roboto Flex | `wght=650, wdth=100, opsz=72` | 2048 | 1456 | 937.535 |

Cap height 取自平顶 H，x-height 取自小写 x。原始坐标以基线为 0、Y 向上；放入 SVG 时再进行 Y 轴翻转和平移。两枚对照 R 按可见大写高度对齐，而不是用相同 CSS 字号假定它们一样大。

Fraunces 的部分笔画轮廓互相重叠。导出时先依据非零填充规则求并集，再用 Skia PathOps 隔离真实字腔。原始完整路径同时保留在 JSON 中。导出坐标精度为 0.001 字体单位；“准确轮廓”指来源和形状保持，屏幕曲线仍由 SVG 或 WebGL 渲染器离散化显示。

MARK 与 PRESS 使用同一组 Fraunces 外轮廓和字腔：

- **MARK：** 上层石块真的挖去 R 的笔画区域，字腔成为保留原表面高度的岛；下层实体形成约 0.25 场景单位深的凹刻底面。
- **PRESS：** 字面从真实轮廓挤出并水平镜像；整块字模转为朝下，靠近纸张、接触、提起，再回到左侧。金属字面与印迹采用相同的 2.16 场景单位大写高度。

Fraunces 是当代字体。这两幕是材质化设计研究；页面没有为它们赋予古代碑刻、特定历史字模或具体印刷机的身份。印刷原理与历史文案的依据见 [REFERENCES](REFERENCES.md) 和 [TERMINOLOGY](TERMINOLOGY.md)。

## 4. 单一时钟与确定性的滚动状态

应用通过一个按需调度的 `requestAnimationFrame` 入口完成更新。Lenis 配置 `autoRaf:false`、`autoResize:false`；应用显式调用 `lenis.raf(animationTime)`。这个逻辑时钟只累加连续运行的 RAF 帧间隔：进入空闲、隐藏或恢复状态时清除上一帧时间锚点，下一帧重新建立锚点，避免把长时间停留当成一次巨大的滚动推进。材质模块自身不建立 RAF。

滚动距离来自七段 `.beat`。各段长度是当前视口高度的倍数：`2.05 / 2.1 / 2.75 / 1.8 / 2.15 / 1.8 / 1`。`locate()` 把绝对 `scrollY` 映射为章节和 `0..1` 局部进度，画面再由该进度直接计算。它不累加滚轮事件，也不依赖一次性的进入回调。

每章前段建立构图，中段保留阅读时间，最后 22% 进入衔接。V2 的完整 R 从首帧可见，字腔始终留白；开场滚动完成描边，并把初始 1.025 倍尺度收束到 1 倍。章节主体按各自交接窗口重叠，标题与说明另有较短的退场，避免整幕同时消失或两组文案重叠。

字腔桥接取自实际 SVG 的屏幕矩阵，或材质对象的相机投影。MARK → PRESS 让石板缩小并靠近镜像字面，再交换材质；PRESS → DIVIDE 将印迹向对照字形对齐。PRESS 的材质进度在衔接开始前映射完毕；接触、着墨、分离和反向撤销都是该进度的函数，完整分段见 [MATERIALS](MATERIALS.md)。

LIVING TYPE → PAGE 使用 `src/type-handoff.js` 测量两个真实 DOM 布局。`Range` 给出词段在两端的位置；支持 `Intl.Segmenter` 时按完整字素边界处理，尽量保持词语完整，只在真实换行处拆分长词。交接时只显示一层原生文字，原始标题保留测量布局及语义；需要时统一收小字号为交错行轨迹留出空间，三个字体轴不变。缺少分段能力或布局方向不合适时，回退为整段原生文字。测量只在文字、字体或尺寸失效时重做，动画仍由应用的同一 RAF 驱动。

滚动状态和用户轴值分别持有。拖动滑块不会把实验区字体覆盖成滚动动画值。沉浸模式通过 `inert` 与 `aria-hidden` 管理非活动章节，控件在所属面板已经可读后才参与交互。章节链接更新 URL hash；普通 Motion 模式使用约 480ms 的当前画面到目标画面过渡，阅读模式与减少动态效果下直接定位。

键盘触发导航后，由统一 RAF 在导航结束时交付标题焦点。访客进行指针或键盘操作会取消待交付焦点，滚轮与触屏接管会中断导航，不再有延迟的标题聚焦计时器。普通关闭目录或按 Escape 会返回打开目录的控件；选择章节则由导航管理目标焦点。

页面隐藏时取消待执行 RAF；恢复可见后重新检查尺寸与材质状态。窗口调整采用 100ms 防抖，并尽可能保留章节内的相对进度。窄屏文字输入时，`visualViewport` 大幅缩小时会让表单占用实际可用高度并允许局部滚动，同时固定故事位置；关闭输入后恢复正常模式与测量。真实软键盘与工具栏伸缩的实测范围见 [QA](QA.md)。

## 5. 材质接口与性能上限

`window.CounterformMaterials.create(canvas)` 返回 `ready`、`info`、`resize()`、`render()`、`renderLayers()`、`counterMatrix()` 与 `dispose()`。`render({scene, progress, reduced})` 接收绝对进度，稳定场景沿用单次绘制。`renderLayers({layers})` 让 MARK 与 PRESS 在同一 renderer 中合成；每层包含 `scene / progress / opacity / rect`，可用 `sourceSize` 固定基准捕捉尺寸。`counterMatrix()` 从实际对象位姿与相机投影返回 SVG 仿射矩阵，查询后恢复状态。

双材质交接在固定画布上缓存两张 GPU `FramebufferTexture`。它们保留原有曝光、抗锯齿与墨点透明度，再由合成 quad 映射到目标矩形。使用 `sourceSize` 时，目标平移和缩放不触发 3D 重绘；只有场景、位姿、基准尺寸或画布变化才更新捕捉。相同最终状态会跳过绘制。完整参数与定向验证见 [MATERIALS](MATERIALS.md)。

| 资源 | 实现限制 |
| --- | --- |
| WebGL 画布 | 共用一个 renderer：稳定时绘制当前材质，MARK → PRESS 时合成两份缓存。 |
| 应用传入 DPR | 视口宽度超过 2200px 时最多 1；其他尺寸最多 1.5。 |
| 材质模块硬上限 | DPR 最多 1.65，并进一步把缓冲区限制到约 330 万像素；取更严格者。 |
| 表面贴图 | 四张确定性生成的 512×512 表面图。 |
| 接触阴影 | 128×128 的局部贴图。 |
| 光照 | 本地生成的工作室环境，1024×1024 阴影图。 |
| 交接缓存 | 两张 RGBA8 GPU 画布捕捉，合计不超过约 26.4 MB 色彩存储；没有额外场景深度或多重采样渲染目标。 |
| 布局更新 | 字体样张变化或尺寸失效时重新容纳；无需每帧重算所有文字。 |

这些是资源限制与调度策略，不代表在任意设备上达到某个 FPS。已测环境及结果以 [QA](QA.md) 为准。

## 6. 阅读模式与能力回退

- **减少动态效果：** 系统偏好默认进入连续阅读布局；Index 中的 Motion 可手动切换。窗口高度低于 700px 时，无论横屏或竖屏，也默认使用阅读布局。
- **JavaScript 不可用：** 七章正文和 SVG 在正常文档流中完整显示。脚本控制的目录入口、章节轨道、字腔描线操作、变轴表单与末页来源按钮隐藏；解剖项在源 HTML 中禁用，仍保持清晰的静态定义。来源内容移入可见文档流，并通过原生 `details / summary` 继续展开阅读。正常加载脚本后，应用启用解剖交互。
- **Lenis 不可用：** 应用仍可依据原生滚动计算章节状态，导航使用浏览器的滚动能力。
- **WebGL 不可用或上下文丢失：** 隐藏材质画布，保留同一章节的 HTML/SVG 表达；上下文恢复时重新生成环境渲染目标、清除双层捕捉缓存、恢复场景环境和阴影，再通知应用重绘。
- **会话存储不可用或数据损坏：** 恢复代码捕获错误并继续使用初始值。

**字体加载：** 三个轴控件在等待 Roboto Flex 时禁用，文字编辑与 Reset 保持可用。应用使用 `document.fonts.load()` 并确认返回的 Roboto Flex 字体确实为 `loaded`，没有把 `document.fonts.ready` 的完成误当成字体成功。加载失败或等待超过 8 秒会显示简短状态，并把样张身份与末页说明改为加载中或回退状态。超时后迟到的成功结果仍会解除禁用、恢复真实变轴身份。真正失败时，页面提示刷新重试。实际故障注入结果见 [QA](QA.md)。

## 7. 会话状态与本地资源

`sessionStorage` 的键为 `counterform-type-v1`，只保存文字与 `weight / width / optical`。恢复时仅接受有限数字，并按对应输入范围裁剪；文字截取到 72 个字符单位。空白文字显示默认短句 **“Give type room to breathe.”**。Reset 会恢复作品初始值并保存。

章节链接使用 URL hash 与 History API；`popstate` 会跳到对应章节。滚动进度、手动解剖选区与手动 Motion 选择没有作为永久用户设置保存。应用未使用 `localStorage`、服务端账户或遥测。

正文的字体、Lenis、材质包和 SVG 均通过相对路径读取。纹理与光照在内存中确定性生成，设计概念图只存在于文档目录，运行时不加载。来源说明中的外部链接由访客主动打开；观看展览不依赖这些网站在线。

## 8. 编辑位置与可选重建

| 修改目标 | 主要位置 | 相关复核 |
| --- | --- | --- |
| 文案、章节标题、来源链接 | `index.html` | 英文断行、移动端空格、术语准确性。 |
| 颜色、字号、控件布局、响应式构图 | `styles.css`、`DESIGN.md` | 六个目标尺寸的稳定画面与衔接。 |
| 章节长度、导航、RAF、状态保存 | `app.js`；段长另在 `index.html` 的 `data-span` | 正反滚动、历史导航、后台恢复、阅读模式。 |
| 实验区到终章的原生文字交接 | `src/type-handoff.js`、`app.js` | 两端对齐、不同断行、长词、用户轴值、正反交接。 |
| 变轴范围与默认样张 | `index.html` 的控件、`app.js` 的 `defaultType`、CSS 字体声明 | 与 `font-spec.json` 的真实轴对应；极值和长文案。 |
| 光照、石刻深度、金属和印刷动作 | `src/materials.js` | 重建后检查接触位置、镜像方向与逆向播放。 |
| 替换字体或改轮廓实例 | `assets/fonts/`、`docs/font-spec.json`、`index.html` 的内联 SVG、`src/materials.js` | 重新核查许可证、轴、度量和字腔；同步 SVG 与材质源码使用的轮廓。 |

HTML、CSS、`app.js` 和 `src/type-handoff.js` 的修改无需构建。只有修改 `src/materials.js` 后需要在项目根目录重新打包：

```sh
npx --yes esbuild@0.25.10 src/materials.js --bundle --minify --format=iife --target=es2020 --outfile=assets/materials.js
```

这是开发时的可选步骤，会按本地缓存情况获取 esbuild；交付包已包含生成结果，普通预览不运行这条命令。Three.js 0.180.0 的本地模块和 MIT 许可证也已包含。完整材质来源与复建依据见 [MATERIALS](MATERIALS.md)。

```sh
npm run check
```

上面的现有检查命令只验证主脚本、服务器、材质源码和文字交接源码的 JavaScript 语法；它不替代浏览器中的功能或审美验收。
