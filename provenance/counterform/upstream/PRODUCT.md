# COUNTERFORM

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated by the supplied independent-execution brief. Implementation decision: portable static HTML, CSS, SVG and JavaScript, local variable fonts and vendored Lenis. No build or network dependency to view the delivered project.

## Users

Visitors to an experimental typography exhibition; the project owner reviewing an independent immersive website for a personal design collection.

## Product Purpose

Make the negative space of a real letterform perceptible as a continuous object across carving, printing, typographic differentiation, anatomy and variable typography.

## Capabilities and Constraints

- Seven connected scenes with readable stable compositions and reversible scroll handoffs.
- Real font files, accurate vector outlines, honest font-axis controls and bundled redistribution licenses.
- Keyboard, pointer and touch controls; reduced-motion reading mode.
- User-defined review sizes: 360×780, 390×844, 768×1024, 1440×900, 1920×1080 and 3840×2160.
- Local-only independent source ZIP; no publication, Git push, existing repository changes, PR or Release.
- English editorial display copy; concise historically supportable explanations.

## Brand Commitments

COUNTERFORM / THE SHAPE OF READING. Warm paper, ink black, controlled proofreader red, physical evidence becoming accurate digital outlines. The letter R and its counter provide continuity. Typography is the primary artwork, with no rasterized body text or fabricated glyph samples.

## Evidence on Hand

The user's complete COUNTERFORM brief. Verified primary sources, real font files and license/axis metadata will be included with the source.

## Product Principles

1. Show the typographic mechanism through the real glyph.
2. Preserve readable resting compositions.
3. Distinguish design metaphor from historical evidence.
4. Make the complete experience usable without a server dependency or online asset service.

## Accessibility & Inclusion

Native labeled inputs, visible focus, keyboard navigation, motion preference support, reflowing mobile layouts and complete no-JavaScript reading content.
