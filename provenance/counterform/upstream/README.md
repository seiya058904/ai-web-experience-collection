# COUNTERFORM — THE SHAPE OF READING

一件关于字形与负空间的独立交互展览。以真实字母 **R** 的字腔为线索，连接刻写、印刷、衬线与无衬线、字形解剖、可变排版，最后收束成一张保留用户文字与字体设置的海报。

**V2 精修版：** 完整的 R 在开屏即清晰可见，字腔始终留白；章节中的字形按实际轮廓位置交接，石板收拢到字模附近，用户文字连续进入最后一页。

**完整静态源码，可直接在本地预览。无需构建、安装项目依赖或连接外部资源服务。** 字体、脚本、材质代码和许可证均包含在交付中。页面展示文案以英文为主。

## 本地运行

解压 ZIP，在包含 `index.html` 和 `package.json` 的项目目录打开终端，选择一种方式即可。

### Node.js 20 或更高版本

```sh
npm start
```

打开 **http://127.0.0.1:4173**。启动脚本仅使用 Node.js 内置模块，因此不需要先执行 `npm install`。也可以直接运行 `node scripts/serve.mjs`。

### Python 3

```sh
python -m http.server 4173 --bind 127.0.0.1
```

同样打开 **http://127.0.0.1:4173**。Windows 已安装 Python Launcher 时，也可以将命令中的 `python` 换成 `py`。

在终端按 **Ctrl+C** 停止服务器。两个示例都只监听本机地址。

也可直接打开解压后的 `index.html`，本地字体、脚本和材质随包提供。需要其他浏览器行为与调试的一致性时，可使用上述本地服务器；实际验证环境和版本范围见 [QA.md](docs/QA.md)。

## 建议的体验顺序

| 章节 | 看什么 / 可以做什么 |
| --- | --- |
| SPACE | 完整 R 从首屏即可辨认，内部保持真实留白；滚动完成字腔描边与轻微尺度收束。 |
| MARK | 用掠射光观察真实轮廓形成的凹刻、内壁和字腔岛。它是使用当代 Fraunces 字体的浮雕演绎。 |
| PRESS | 缓慢滚动，观察镜像凸起字面接近纸张、接触、分离与留下的正读印迹；反向滚动可逆转过程。 |
| DIVIDE | 对照 Fraunces 与 Roboto Flex，点击 **Trace the counters** 查看内部空间。 |
| ANATOMY | 点击 **Counter / Bowl / Serif**，观察空白、弧形笔画和衬线；小写 x 提供实际 x-height 参照。 |
| LIVING TYPE | 调整真实的 **Weight / Width / Optical size**，输入自己的英文短句，或用 **Reset** 恢复初始样张。 |
| PAGE | 欣赏继承相同文字与轴值的最终海报，再返回开场。 |

顶部 **Index** 可跳转章节、切换 **Motion**，并查看字体与来源说明。普通 Motion 模式下，章节选择用约 480ms 直接连接当前与目标画面，滚动或输入可接管过程；导航不会留下延迟抢回焦点的回调。滑块支持鼠标、触屏与键盘操作。

系统开启“减少动态效果”，或窗口高度低于 700px 时，页面默认采用完整的连续阅读布局。窄屏文字编辑遇到虚拟键盘压缩可视区域时，表单会使用独立的可用空间与局部滚动；真实手机键盘的验证边界见验收报告。

字体加载期间，三个轴控件会暂时禁用；文字编辑与 Reset 仍可使用。若出现字体加载提示，可按提示重试，已输入的文字会保留。

没有 JavaScript 时，七章仍按顺序完整呈现。需要脚本的目录、变轴表单与字腔描线入口会隐藏，解剖定义保留为静态说明；页面底部的原生 **Notes, typefaces & sources** 折叠区仍可展开阅读。

可变字体的文字与设置保存在当前浏览器标签页的会话中；刷新时会尝试恢复。输入长度上限为 72。当前随附字体面向页面中的拉丁字母内容，中文排版需要额外选择字体与重新验收。

## 文件与维护

| 文件 / 目录 | 内容 |
| --- | --- |
| `index.html` | 七章内容、SVG 字形、导航、原生交互控件与阅读回退。 |
| `styles.css` | 色彩、字号、网格、响应式构图、阅读模式。 |
| `app.js` | 滚动编排、字体控件、章节导航、会话状态与回退处理。 |
| `src/type-handoff.js` | 测量两页真实文字行框，以一层原生文字完成实验区到终章的连续交接；没有独立动画时钟。 |
| `src/materials.js` | 可读的石刻与印刷材质源码。 |
| `assets/materials.js` | 已打包的材质运行文件；普通预览直接使用它。 |
| `assets/fonts/`、`assets/vendor/`、`licenses/` | 本地字体、运行脚本、原始字体与相应许可证。 |
| `docs/` | 技术说明、设计依据、术语、研究来源与验收记录。 |

修改 HTML、CSS 或主交互脚本后刷新页面即可。修改材质源码后的重新打包命令见 [TECHNICAL.md](docs/TECHNICAL.md) 与 [MATERIALS.md](docs/MATERIALS.md)。
