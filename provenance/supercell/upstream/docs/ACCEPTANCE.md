# SUPERCELL — 实际验收与交付记录

验收日期：2026-10-24。最终结果依据实际浏览器、源码检查、渲染截图、录制数据和解压构建取得；下面的清单不是计划表。

## 1. 交付结论

五幕网站、共享切片／风切变交互、手机独立构图、降动效／无WebGL退路、研究与真实生图记录均已完成。最终功能回归 **31项通过、0项失败、0条常规控制台／页面错误**；8个指定视口的40个稳定构图和80张章节交界样本通过几何门禁。另有5项定向恢复回归、2项最终媒体失败退路检查，以及独立的暂停、音频、滚动条和真实后台恢复证据。

完整矩阵后发现的问题均有对应修复和最新有效回归。布局记录保留完整几何数据；早期功能失败由修复后的功能／恢复记录替代。最后的静态海报修复只调整媒体失败时的绘制方式，另外执行了有／无JavaScript的实测。没有将一次早期脚本的零退出码当作最终全站通过。

项目从独立源码ZIP解压到干净目录，按锁文件执行 `npm ci`、`npm run build`、`npm test`，均成功。最终封包已检查归档CRC、文件清单、源码哈希、全部本地资源和构建结果，记录于 `evidence/package-verification.json`。交付包含源码及可直接本地HTTP预览的 `dist/`，不包含依赖目录、浏览器、配置Profile、缓存、密钥或公开部署。

- 文献与API核对见 `RESEARCH.md`、`SOURCES_AND_LICENSES.md`；正式制作方向、稳定构图和交界契约见 `VISUAL_BIBLE.md`。Visual Bible在正式扩展场景前建立，后续根据实测同步了实际时序。

## 9. 性能：实测值与范围

最终功能回归时间：2026-10-24T16:32:56.396Z 至 2026-10-24T16:35:04.804Z。

在1440×900、III幕稳定停留、SwiftShader软件WebGL下采样120个浏览器rAF间隔：中位 **16.7ms**，P95 **49.9ms**，最大 **66.7ms**；该次Canvas缓冲为 **1440×900**。P95和最大值表明此软件渲染环境仍有较长帧；不据中位数声称全程60fps，也没有编造Lighthouse／Web Vitals得分。

生产实现减少稳定状态的重复DOM写入，密度纹理只在u变化时重算；微动绘制有上限，缓冲上限1920×1200、DPR上限1.35，并可在持续慢帧时降低栅格细节。降低细节不更改场的坐标、切片或用户状态。后台真实停止绘制；退出时释放GPU、音频、监听、触发器和主ticker。

Production单次冷／暖资源transfer为518,039B／0B，导航HTML另计。冷启动appReady约105ms、canvasReady约711ms；暖重载约73ms／244ms。这些只是在本地服务上的单次观测，含截图工具影响，不推广为真实用户或网络承诺。早期受开发热重载影响的冷测已明确废弃。
