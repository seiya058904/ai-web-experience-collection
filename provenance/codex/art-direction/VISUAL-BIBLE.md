# CODEX — Visual Bible

## 视觉命题

**Assembly through order and pressure.** 平面材料经由折线、顺序、张力、包覆与压力成为实体。画面中的变化有具体工艺原因：纸折起，书帖对齐，缝线拉紧，封板闭合，字印进入书布。

视觉基底是当代博物馆出版物与精细黑布装帧：象牙色纸、暖黑、低饱和衬纸、有限的金饰。精确的间距和有分量的实体共同构成版面。排版、目录、章节信息保持真实 DOM；AI 概念中的文字只是设计参考。

## 筛选与修订记录

1. **Generate** — 各组生成独立场景关键帧，统一暖黑、象牙纸、细织书布与编辑式留白。
2. **Compare** — 对照同一书体的封板厚度、纸芯色温、折背、缝线、金饰面积和字号关系。把工艺合理性与图像美感分别检查。
3. **Reject** — 第一版 CASE 的封板与大标题发生碰撞；不进入成品包。皮革、古董式装饰、书架和旧羊皮纸界面没有被选为本项目的材质路线。
4. **Refine / Regenerate** — CASE 调整对象和排版的空间关系后重新生成。首幕关键帧经 imagegen 编辑为带透明背景的独立书体；MARBLE 经 imagegen 编辑为不含界面文字的材料图。
5. **Curate** — 保留十张选定关键帧和四张最终 AI 源素材。开发及视觉检查中补充独立纸张纤维扫描式纹理；所有运行素材都有原始 PNG 与优化 WebP 的派生关系。
6. **Implement / Compare again** — 实际 Three.js 画面与关键帧并排核对，修改纸张观察角度、CASE 的三分之四视角、SEW 的斜向近景、黑布亮度和书口投影。最终界面仍是可逆的实时构造，不把整张概念网页截图当作页面。

提示词、生成来源和选用状态见同目录各 JSON 记录。未选图像已从交付项目排除；筛选原因继续保留，便于追溯。

## 材质约束

| 材料 | 视觉要求 | 最终处理 |
| --- | --- | --- |
| Paper | 轻微挠曲、清晰边缘、细纤维，避免发光白片和旧纸滤镜 | 连续薄实体；独立 AI 纸张 albedo；确定性纤维 relief；闭合纸边 |
| Page block | 多层纸的累积厚度，边线密而有序 | 真实嵌套纸张与有界实例；对齐后出现细密切口纹理 |
| Fold | 一条贯穿装配的轴，有圆弧和厚度 | Y 轴圆弧折背；纸面、背面和周边相连；嵌套折纸共享轴线 |
| Thread | 亚麻色、细、受张力影响，实际连接书帖 | 连续 TubeGeometry 路径，进入折背内部、绕过承托带、连接相邻书帖；自由线端逐渐收紧 |
| Spine | 连接形成共同结构，末端有书头带 | 共用凸形书脊轮廓，衬层逐段铺合，头尾缠绕线带 |
| Black bookcloth | 近黑、细织、无皮革高光，表面只在光下显现 | 本地 AI 书布 albedo 与微织纹 relief；低调 sheen；暖灰定向光 |
| Marbled paper | 炭黑、灰绿、骨色、少量赭色；像手工纸 | 同源纹样参与确定性梳理，转移后停止变化并保留完整 UV |
| Gold | 标题与一条细边的金属反射，不发光 | 金属度与粗糙度变化，非 emissive；没有金色粒子或全屏闪光 |
| Board | 有厚度、包覆和转折，不能只有悬空平面 | 带微小圆角的封板、书布皮层、四边 turn-ins、真实书脊铰链 |

## 字体进入物体

屏幕的 Cormorant Garamond 大标题负责叙事，Manrope 负责目录、动作和细节信息。相同字体在本地 Canvas 中生成字形遮罩，映射到封面固有 UV 上。压印直接改变书布的表面响应；书脊标题随弯曲封壳存在。文字的存在方式随工序改变，而不是让 HTML 跟在模型上方漂浮。

前景排版用疏密、换行、大小与留白建立层级；页面不使用营销卡片、统计数字、标签云或书店式操作。

## 运动与构图

各幕保持 **Enter → Stable Composition → Living Hold → Handoff → Exit** 的节奏。章节中段让物体与排版停稳，末段再交接视角。正文随进度淡出入，固定目录与章节控制在深浅背景变化时保持可辨。

SEW 使用斜向近景，让相邻折背和横向缝订形成规律。CASE 显示独立封板、书芯和衬纸的距离。IMPRESSION 使用克制的小字模，最终 CODEX 让书口与封板厚度同时可见。MARBLE 是全幅纹样构图，左下区域保留安静的文字空间。

移动端将文字移至上方，书体下移；GATHER 主要纵向排序，减少书帖实例。近景中的局部裁切是材料取景，交互按钮和正文必须完整可用。减少动态效果时关闭微动和指针视差，装配进度仍可由滚动控制。

## 工艺与艺术取舍

- 采用当代穿帖缝订的黑布书壳体系，避免把历史木板穿带装订与现代 case 混成一套假结构。
- SEW 关键帧简化了真实缝法。实时路径按照穿帖缝订与三条承托带重新构造，保留连续连接关系。
- 金饰关键帧中的较大片金箔没有照搬；实时版本把金属面积收在字印和细边。
- AI 源图的摄影细节与实时几何有不同表现范围。帧图确立材质、构图和节奏；运行时采用可逆、可操作、预算受控的模型。
- 书口修整、书头带、制壳、烫印与描金的先后在不同工艺中会变化。本项目把它们编辑为十幕连续研究，不把画面用作制造说明。
