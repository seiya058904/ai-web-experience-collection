# SILLAGE｜交付说明与验收摘要

日期：2026-11-09

SILLAGE 已制作成可本地运行的十章英文交互视觉随笔。交付包含完整源码、正式图像、字体、生产构建、启动脚本、锁文件、测试、设计说明、生图记录和真实浏览器证据。核心功能、已记录的布局与独立构建检查已完成；下载落盘、浏览器缩放等未覆盖项仍明确保留，不能据此称为所有环境的完整验收通过。

## 一、作品内容

作品以 Brightness、Spice、Warmth 三种视觉语汇展开。杏黄锐边、茄紫折面和暖棕压面围绕同一个不规则空腔组织，使用哑光、细孔和浅影区分性格。图形是原创视觉转译，不声称通过屏幕传递气味，也不预测香水性能。

| 章节 | 内容与实际操作 |
| --- | --- |
| 01 · Before a name | 完整印迹与三种边缘；图例可以分别突出一种语汇并恢复。 |
| 02 · A vocabulary of edges | 近看材质交界；三个按钮把短语与对应轮廓联系起来。 |
| 03 · First, then, still | Arrival、Unfolding、Trace 三个相对阶段；选择阶段改变视觉主次。 |
| 04 · One quiet chord | 切换独立部分与完整关系，观察同一空腔如何成立。 |
| 05 · The shape of absence | 分别移除一种语汇再恢复；只改变比较，不改个人配比。 |
| 06 · After you leave | 近、中、远三个观看状态，保留连续路径与可辨认的结构。 |
| 07 · One impression. Two memories. | 两段原创记忆提供标题建议；已经输入的私人标题会被保留。 |
| 08 · The whole of what remains | 三个阶段贯穿同一条留白路径；手机采用独立竖向构图。 |
| 09 · Your version | 调整三个整数份额、应用预设、命名和复位；总和始终为 100。 |
| 10 · What remains | 对比初始与当前作品，查看三阶段个人印迹并生成 PNG。 |

九处相邻过渡支持正反向浏览。通往第九章的过渡含有真实数字输入，与正式编辑器共用同一份状态；通往第十章的过渡会带入当前标题、配比和可操作的继续入口。

## 二、如何运行

需要 **Node.js 22.18 或更新版本**。实际构建环境为 Node.js 24.22.1、npm 11.9.0。

1. 完整解压 `SILLAGE-Source.zip`。
2. 进入其中的 `SILLAGE` 文件夹。
3. Windows 双击 `start.cmd`。
4. 浏览器打开 `http://127.0.0.1:4173/`。保持终端开启；按 Ctrl+C 停止。

已附带 `dist/`，运行现成作品不需要先安装 npm 依赖。如果浏览器没有自动打开，手动访问上述地址即可。不要直接双击 `dist/index.html`，模块脚本和图像导出需要正常 HTTP 来源。

通用启动命令：

```sh
node tools/serve.mjs --open
```

如果 4173 端口已占用：

```sh
node tools/serve.mjs --port 4174 --open
```

修改和重建：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

```sh
npm test
npm run build
node tools/serve.mjs --open
```

安装依赖需要网络。个人标题和配比在浏览器允许时保存在本机 localStorage；不同浏览器或端口有独立的存储空间。网站不需要账户、数据库、遥测或外部运行 API。Windows/macOS 启动脚本尚未在对应操作系统实际执行；已验证的是源码构建与生产文件预览。

## 三、美术与实现

实际生成了 **12 张独立 AI 图像成果**，包括三种 Hero 候选、桌面精修、独立手机 Hero、组合定帧、两种方向的全景、关键交接、材质图集和两段记忆图。记录包含真实提示词、原图、采用理由和使用位置，没有编造工具未返回的参数。

正式页面使用 **14 个 WebP 文件，共 1,415,236 字节，约 1.35 MiB**；这些包括响应式派生版本，不重复计为生图成果。精修图负责静态材质细节，可编辑作品由确定性的 SVG/Canvas 生成。三项份额分别影响图形面积与展开范围、折面节律、低伏表面的深度；任一份额为零时，相应成分实际退出，中性空腔仍保留。

运行栈为 Vite、TypeScript、Lenis、DOM、SVG 和 Canvas。字体本地打包。没有为了表现厚度加入 WebGL 依赖。

## 五、根据真实截图完成的修正

视觉复审挑出的两个较弱章节是第二章与第四章。响应式图片继承固定高度，导致材质交界和完整组合被错误裁切；已经修复图片高度与第二章取景，并回归检查第七章和相关记忆过渡。

最初较弱的第八至九章交接缺少实际控件，现已加入共享状态的原生数字输入。最后一轮复审又发现 320 像素下长标题挤压第九至十章交接，使阶段标签与图形碰撞；现在为画廊保留独立高度，标题和操作沿文档流继续，已补拍全部五个手机进度及最长标题后的可达操作。

独立视觉复审已给出可交付结论，范围限于审查过的源码和实际画面。它不替代下载、性能、实体设备或所有异常条件的验证。

## 六、仍未验证的项目

- **PNG 文件实际下载落盘：** 当前测试浏览器拒绝 Blob/Data 下载协议。已验证真实图像生成和显示，尚未验证最终保存动作；没有绕过该限制。
- **125% / 150% / 200% 原生浏览器缩放：** 快捷键没有改变实际视口或 DPR。没有把普通窄屏模拟当作缩放通过。
- **重试按钮完整恢复流程：** 已实现同地址重试和焦点恢复，但测试环境在资源文件恢复时自动刷新页面，无法独立证明该按钮完成了恢复。
- **系统低动态偏好切换、真实 Android/iOS、Safari/Firefox、物理触控、Windows/macOS 启动脚本执行：** 未覆盖；手动 Still 模式已检查。
- **性能和长期生命周期：** 未测 Lighthouse、FPS、冷启动时间、CPU/网络节流、堆内存、长时间后台暂停或所有乱序资源竞态，不提供推测指标。
- **完整辅助技术与听感评估：** 原生控件和键盘焦点已检查；没有完整屏幕阅读器、对比度审计或主观音频质量认证。

少数中段截图的 DOM 记录包含离屏 Hero 图片失败，当前可见交接画面已就绪；报告保留了这些记录，没有宣称每一帧的所有离屏资源都成功。最终独立生产主路径中没有出现资产替代。
