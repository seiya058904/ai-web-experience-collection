排版以英文的自然换行、词长和阅读节奏为准，并为字体回退预留空间。英文页面设置正确的 HTML 文档语言（如 lang="en"）；用户输入的语言不确定时不臆测。浏览器验收须逐章检查实际可见文案和交互状态：网站自带的标题、正文、图注、控件、错误提示、图片文字、替代文本、导出结果中的固定文字及无障碍名称均为英文且一致可读；如有旁白和字幕，也检查其英文版本；用户输入和动态引用完整保留。检查桌面、手机、低动态及键盘和辅助技术下的文字溢出、对比度、可访问名称和语言标记。若后文示例与本规则存在语言冲突，以本规则为准。

## 01｜创作命题与边界

创造一部关于**气味如何被描述、组合、记住与留下余韵**的视觉随笔。观众先遇见一个尚未命名的“气味形体”，随后认识它的三种语汇，观察它们在时间、距离和记忆中改变关系，最终完成属于自己的版本。形状用来表达感官关系、间距与余韵；全站不出现楼房、室内建筑漫游或空间事务所式作品集。

观众不需要懂香水。网站正文使用精炼、具体的英文。气味不能通过屏幕传送；网页始终清楚地把形状、颜色和变化标为**原创视觉转译**，不得伪称模拟真实鼻腔、预测香水性能或让用户“闻到”某种气味。

全站只使用三组原创气味意象：**清亮：青柚皮的锐意；辛意：轻微胡椒感；余温：干木的温沉**。它们是叙事词汇，不是调香配方、化学材料清单或真实商品。禁止香水瓶产品广告、透明玻璃折射、花园、漂浮花瓣、烟雾粒子云、气味分子漫游和泛化黑金奢侈品页面。独特性来自“关系可见”，不来自瓶子的包装。

### 已读取的一手依据

- [NIDCD：The Journey of Smell to the Brain](https://www.nidcd.nih.gov/news/multimedia/journey-of-smell-to-brain-text-version)：气味分子激活鼻中的嗅觉感受神经元，再向脑传递信号。本设计据此划清媒介边界：视觉只是联想与说明，不承诺真实嗅觉刺激，也不画伪科学分子机制。
- [Fragonard 官方香调说明](https://www.fragonard.com/en-int/fragonard/fragonard-p-2906-o-1492.htm)：该香型以 top、heart、base notes 分组呈现。本设计借用“不同层次共同构成气味”的组织方法；不复制其配方、商品、包装和花园意象，也不把三组叙事词汇冒充这款香水。

以上来源只支持所述有限事实。后面的颜色、形态、相对阶段与记忆片段均为原创决定。页面不编造挥发分钟数、浓度、分子大小或情绪疗效。

## 02｜Visual Bible：不见其物，看见其关系

| 维度 | 具体决定 |
|---|---|
| 主体 | 一个不对称、可分辨三种边缘的“嗅觉印迹”：清亮为薄而锐的杏黄弧脊，辛意为收紧的茄紫折面，余温为低伏、细孔状的暖棕压面。它不是实体雕塑或真实材料标本 |
| 配色 | 乳白 `#F3EDE1` 占大面积；杏黄 `#E7B353` 为清亮；茄紫 `#594051` 为辛意；暖棕 `#8A6750` 为余温；深墨褐 `#29211E` 承担正文。色名与纹理同时标识语汇，不能只靠颜色 |
| 材质 | 哑光粉质、干燥细孔、柔薄边缘；表面细节用于区分气味性格。无金属拉丝、镜面反射、玻璃凝胶或廉价磨砂 UI |
| 光 | 左上方大面积柔光，细微浅影形成可读厚度；高光只描边，不穿过正文；后段允许降低环境亮度，但不切入黑色科技展厅 |
| 观看语法 | 以俯视编辑、关系重排、局部近观为主；不是不断绕物旋转。每次改变尺度，都保留一个已认识的边缘或缺口 |
| 排版 | 英文标题用有气质的窄体衬线，解释用清爽无衬线。正文落在稳定乳白区，最多两组说明同时出现；章号小而清楚，不把整页做成大字海报 |
| 动态 | 有节制的边缘舒展、层次显露与距离变化；微动只影响附加表面，不能改变用户的配比与叙事进度。停下时像一幅完整的现代版画 |
| 手机 | 主体重新组织为纵向三层关系，关键缺口保留；说明在图形下方真实文档流中展开。低动态使用同一印迹的阶段定帧与明确按钮 |

**缺口的几何身份与颜色分开。** 全文“识别缺口”指同一位置和轮廓的空腔边界；默认清亮成分在附近形成杏黄色边缘。当清亮份额为零时，杏黄表面与对应清亮特征必须退出，缺口以中性留白保持连续，不能为了保留锚点而伪造一个仍然存在的成分。

视觉体验应从好奇、辨识、比较走向个人化和余韵。最强画面放在 CH-08；CH-04 与 CH-08 获得独立的高质量素材和交互制作资源。最后三章必须比前半程更丰富。

### Hero 六状态

1. **初见：** 立即出现与正式构图一致的精修印迹和真实标题“SILLAGE／气味的形状”；即使增强资源未到，识别缺口、三种表面与留白已成立。
2. **揭示：** 很小的层间位移让观众发现三种性格围住同一空腔；说明“有些东西，看不见，却改变了一个空间的感受”进入稳定文字区。不从黑场播放 Logo。
3. **完整构图：** 桌面主体占主要视觉重量而非填满屏幕，左侧标题与右侧印迹互相平衡；手机上下重排，不能用巨大标题挤掉主体。
4. **停留：** 只允许表面光泽极微弱变化；轮廓与正文稳定，必要时可暂停。提供“认识这三种语汇”的真实章节入口。
5. **首次滚动：** 识别缺口向画面中心靠近，局部表面被拆成可观察的形态与词语关系，衔接 CH-02；不是把整幅好画面直接淡掉。
6. **返回入口：** 直接恢复当前用户版本或默认印迹的稳定状态，不重放长开场；开场中滚动立即由当前位置接管。

### CH-01｜未命名

- **目的与新增：** 先遇见一段尚未被名词固定的感受。拍点 A 是印迹全貌；拍点 B 是空腔两侧的三种不同边缘被清楚区分。Hero 不只是一张标题海报。
- **进入—展开—停留—交出：** 按六状态导演执行；稳定构图保持主角与空白互相支撑。首次滚动交出识别缺口，标题先退出，印迹仍成立。
- **交互与媒介：** 图例按钮可短暂标出清亮、辛意、余温，关闭回到原图；普通观看即可理解全章。精修图承载细节，精确轮廓负责状态。
- **手机/低动态与验收：** 竖屏有完整印迹和可读标题；静态状态仍含两层信息。失败判据：只见通用几何物、看不出三种性格、主角被文字覆盖。

### CH-02｜词语的边缘

- **目的与新增：** 让观众认识本作品的描述语汇，而非学习“标准气味颜色”。拍点 A 为青柚皮、胡椒感、干木三种原创联想的极近局部；拍点 B 为它们各自对应的锐边、紧折、低伏表面。
- **画面与节奏：** 接住 Hero 缺口，以一张有编辑节奏的横向画面逐项揭示；短语如“清亮，不等于甜”“温沉，不等于重”必须标明为本作品的描述选择。停留时图文一一对应，交出一条共同基准线。
- **交互与资产：** 点击任一词使对应轮廓独立显现，再恢复全体；真实按钮不依赖 hover。来源意象用原创生图局部，语义文字用 DOM。
- **手机/低动态与验收：** 三项纵排且各有局部细节，低动态直接比较。不能让三种不同意象被同一朵模糊光斑代替，也不能写成气味分类学定律。

### CH-03｜先到与留下

- **目的与新增：** 展示作品的相对阶段，而非给香水做固定秒表。拍点 A 是三种语汇从开始就共同存在；拍点 B 是“初见／展开／余留”三幅构成中的视觉主次不同。
- **画面与承接：** 继承基准线，三层在其上错开占比；变化时保留彼此，不把前调机械删除后再生出后调。稳定构图并列三阶段，说明“这是一条艺术化的时间谱”。交出展开阶段的轮廓。
- **交互与媒介：** 三个阶段按钮真实切换视觉状态；SVG 负责准确对应，细节纹理复用。无虚构分钟数、化学曲线或浓度单位。
- **手机/低动态与验收：** 三幅纵向可比较；按钮与标签持续可读。验收关键是任意阶段直达、回滚后保持同一身份，不能随机重新生成纹理。

### CH-04｜一种和弦

- **目的与新增：** 将三个独立性格组织成一个可命名的整体。拍点 A 为三个边缘各自完整；拍点 B 为它们在空腔附近互相让位、接续，形成“晴窗之后”这一原创和弦。
- **画面与展开：** 继承 CH-03 的展开轮廓，采用浅俯视的大幅主图；杏黄绕开紫色折面，暖棕提供视觉落点。稳定画面必须有明确的内外关系，不把三个图层简单叠透明度。
- **交互与媒介：** “分别看／一起看”切换对应形态与说明，恢复时回到同一构成。使用 IMG-06 的高质量方向，轮廓控制仍由可计算形态实现。交出中心空腔。
- **手机/低动态与验收：** 上方作品、下方对照按钮；静态前后两幅同样讲清关系。此章是重点美术关口：不接受三张素材拼贴、双轮廓脏影或没有新增关系的放大。

### CH-05｜少了一笔

- **目的与新增：** 从缺席认识每种语汇的作用。拍点 A 为观众任选一种暂时移去；拍点 B 为完整版本与减法版本同时对照，具体指出消失的是锐意、紧张还是落点。
- **画面与时序：** 从空腔向外展开两个等大的观看区；完整版本固定在一侧，减法版本在另一侧。缺少的区域保持有意义的留白，不补成另一种随意图形。交出缺失边界。
- **交互与媒介：** 三个减法按钮＋恢复完整按钮；改变仅作用于该比较，不暗改后续个人版本。用精确遮罩与已有材质，无需新渲染器。
- **手机/低动态与验收：** 上下对应并保留清楚标记；可见结果不依赖动画。重点查恢复正确、比较尺度一致、文字不因图形重排跳动；不把视觉缺席说成真实嗅觉测量。

### CH-06｜离开以后

- **目的与新增：** 将气味从“一个构成”转为“经过之后的关系”。拍点 A 为近处三种边缘清楚可辨；拍点 B 为沿一条原创路径离开后，局部细节减少而整体轮廓仍留有暗示。
- **画面与承接：** 缺失边界被延长成一条平缓行进路径，路径两侧是连续压印与留白，禁止粒子散开。停留画面同时保有近处与远处，不强迫高速穿行；交出末端识别缺口。
- **交互与媒介：** “近／中／远”观察点改变细节与层次，提示其为视觉化距离；不得显示虚构米数或扩散公式。SVG 负责路径，分层图负责表面。
- **手机/低动态与验收：** 距离轴改纵向，三段都可直接读；低动态给完整长幅。验收确保是同一印迹的可追踪延续，绝非三张颜色不同的海报。

### CH-07｜同一种，两个记忆

- **目的与新增：** 同一组描述可以进入不同的个人叙事。拍点 A 是原创片段“刚剥开的柚皮，留在搬家后的窗边”；拍点 B 是“空木抽屉里，一张写了日期却没寄出的便条”。不得暗示这些是普遍生理反应。
- **画面与展开：** 两段只取手边局部，不搭完整房间；同一枚小印迹始终固定在两幅之间，明确配比未变。停留时两句短文与局部物件形成克制的视觉散文，交出不变的识别缺口。
- **交互与媒介：** 观众可选“更接近哪一段”，只影响终场的可编辑标题建议，不改写心理档案。无需账户、上传或自动分析用户。图像和文字分层。
- **手机/低动态与验收：** 两段顺序完整出现，选择可更改且可跳过。查两幅之间主体身份一致、叙事不依靠悬停、没有自动生成“你的性格是……”之类结论。

### CH-08｜余香的全貌

- **目的与新增：** 把此前分别认识的时间、距离和关系合成全站高潮。拍点 A 为同一条空白路径贯穿三个相对阶段；拍点 B 为观看范围拉开，观众看见留白如何把不同密度连成一个整体。
- **画面与展开：** 从记忆局部退到大幅俯视长构图，三层印迹沿路径有序错开，识别缺口在每层具有可辨识联系。不是建筑房间、不是花瓣隧道，也不把路径做成数据仪表盘。完整定帧应独立成为主海报。
- **交互与媒介：** 可点选某一阶段，突出它与前后的关系，退出回全景；复用稳定形态参数与 IMG-07 材质。路径空白交给 CH-09 作为操作空间。
- **手机/低动态与验收：** 纵向长构图保留三个阶段和完整因果，低动态以总览与局部插图替代推进。核对中段焦点、画面密度与正文区；这章不能只用颜色渐变冒充高潮。

### CH-09｜你的版本

- **目的与新增：** 让观众真正改变作品。拍点 A 调整清亮、辛意、余温三项相对份额；拍点 B 将所选构成应用于“初见／展开／余留”三阶段，看到它如何形成自己的连续印迹。
- **画面与交互：** 默认配比可定为 45／20／35，标明仅为视觉参数。三项份额使用 0–100 的整数并合计 100：改动一项后，剩余额度按另两项原比例补足；原比例同时为零时等分，整数舍入的余数分给数值较大的那项并校正总和。提供三套预设与复位，允许单项100，避免全零。轮廓面积、边缘节奏、层次深度各有明确映射，不能仅改颜色。给结果取一个可编辑的短标题。
- **媒介与承接：** SVG/Canvas 生成确定性的个人作品，纹理映射保持清楚；图形放主位，控件居边侧，页面不变成专业调香后台。交出完整用户构成。
- **手机/低动态与验收：** 三行滑块配数字输入或步进按钮，支持键盘与触控；低动态即时显示结果。验证极端配比仍优美、相同参数重现相同主体、复位与恢复可靠。

### CH-10｜余韵

- **目的与新增：** 回答入口“这段感受属于什么”。拍点 A 让初始印迹与最终作品在相同尺度下比较；拍点 B 展示用户标题、三项份额与最终长幅印迹，形成完整终场。
- **画面与承接：** 从 CH-09 的控件区退出到有充分呼吸的作品全景，温柔保留原先的识别缺口。文案可用“留下的，是你选择让它留下的部分”。不以卡片墙或普通 CTA 结束。
- **交互与交付：** 真实导出包含作品、标题与简洁份额说明的 PNG；无用户选择时也能导出默认版本。提供回看某章、恢复初始、重新组合；不擅自上传作品。
- **手机/低动态与验收：** 完整终场和按钮都在可访问流中；导出不得漏字体、使用失效远程图片或产生空白。验证带走的图形与屏幕当前构成一致，而非固定宣传图。

## 06｜本主题的实现重点与失败退路

1. **主体身份由参数保持。** 三组边缘与识别缺口在每章有稳定编号、原点、比例和层级。SVG/Canvas 负责可比较、可编辑和可导出的关系；生成纹理提供美术细节。不要在每章独立生成一个“差不多的形状”。
2. **高质位图与实时构成的接点先试作。** G2 必须同时试作 TR-01-02 和 TR-08-09，核对轮廓投影、纹理细节、色彩、透明边缘与标题区。实时程序形态达不到概念时，使用少量高质量材质片与受控遮罩重建，保留真实配比映射；不能用固定视频假装编辑结果。
3. **不强迫实时 3D。** 本站优先 DOM＋SVG/Canvas＋精修分层图，只有明确需要空间厚度时才使用共享 Three.js 场景；禁止为了技术名词把作品替换成三个默认几何体。
4. **图形比较与个人参数分离。** CH-05 的临时减法、CH-07 的文字偏好、CH-09 的份额与标题是不同状态；每项可恢复。导出和终场以当前有效个人状态生成，不读取已经过期的异步结果。
5. **声音保持克制。** 默认静音，可自愿启用低音量、合法来源或原创的稀疏环境声；声响不编码气味强度，不参与必须理解的内容。避免 ASMR 噱头、连续滴答或循环广告音乐。
6. **优先修复的美术问题。** “留白”不能变成空洞；细孔不能变成噪点；暖白不能变成灰脏；形体不能变成果冻；编辑控件不能压过作品。全站复审必须挑出最弱两章与最弱交接，依据实际截图继续精修。

## 执行契约｜把这份设计做成完整作品

以下是本提示词的一部分；执行者不需要另找总纲。上文的主题、章节、交接、交互与下列工程条件共同构成验收标准。所有拟产出图像、场景和文件都是待执行任务，不能冒充已经存在的资产或已通过的结果。

### A. 九项必须兑现的结果

1. **完成本篇规划的 10 个有效章节。** 每章兑现独立目的、两个实质拍点、稳定构图、前后承接及手机等价内容。导航、加载、纯过渡、页脚和同图换标题不计章节。本篇的十章不能擅自缩短；只有用户另行同意调整范围时才变更，且总纲硬下限为八个有效章节。
2. **Hero 是正式作品。** 初见、揭示、完整定帧、停留、首滚、返回六状态全部制作；桌面、手机与宽屏逐项对照概念中的主体比例、轮廓、光、材质、真实文字落点。
3. **在正式生产布局、场景制作及长时间建模之前，真实调用可用的 AI 生图工具。** 环境检查和技术探针可先做；至少得到上文分配的八张可独立查看成果：三条有实质差异的 Hero 路线、桌面精修一张、独立竖屏重构一张、中后段定帧两张、关键交接中帧一张。同图不能兼占两个计数角色，成果数不等于调用数。只写提示词、下载照片或拼低清缩略图不算完成。工具确不可用时尝试其他已授权入口；仍不可用则明确阻塞，并继续不依赖该工具的工作，不能伪称全流程通过。
4. **完成全部九个相邻交接及主要媒介接替。** 默认柔和、可追踪、可逆；中途停下仍是有主次的画面。上文五状态百分比仅指各交接自己的局部进度，不规定相同滚动长度。没有制作的边界不能以全屏黑场掩盖。
5. **实际集成 Lenis。** 采用协调的滚动驱动与明确的叙事状态，支持提前滚动、快滚、回滚、直接跳章和历史恢复；不锁滚、不吸附、不强制补播、不用长滞后制造柔和。
6. **文字与真实控件全程成立。** 可读、可点击、键盘可达；使用语义标题、原生按钮和链接，Canvas 中的必要信息提供 DOM 等价内容；菜单/模态可通过键盘退出，关闭后恢复合理焦点。不以删内容、极小字号、全页裁切或非语义图片文字解决排版问题。
7. **完成真实浏览器检查、生产构建、修复与复验。** 构建成功、测试数量、概念图、自评分均不能代替网页视觉和实际输入验证；没测的项必须写“未验证”。
8. **手机、宽屏、降低动态和异常资源下保留完整叙事。** 可以降低空间运动与后处理成本，不可把后半站删掉，不可把控件全部换成不能操作的图片。
9. **交付含正式资源的可运行源码 ZIP。** 未得到本任务的明确授权，不部署、不发布、不推送、不创建 PR/Release，也不自行加入现有 Collection。已经明确授予的权限按实际范围处理，不反复确认。

### B. 实现与状态必须统一

优先使用轻量、可复现的前端工程，例如 Vite + TypeScript；框架与渲染器按上文媒介选择，不为技术名词增加依赖。默认无需账户、数据库、遥测、外部运行 API 或付费运行服务。检查既有目录与项目规则，隔离新作品，保留无关文件。依赖版本锁定后复核官方文档；不要把本篇设计建议当作永不过期的 API。

Lenis 的样式、滚动事件与 RAF/ticker 按当前锁定版本集成。若由 GSAP ticker 手动推进 Lenis，就关闭该实例自动 RAF，避免双重推进；不要叠加第二个主滚动平滑器。DOM、Canvas/3D、标题与镜头消费同一套已协调叙事进度；使用数值 scrub 时，不可让一层直接读原始进度、另一层读仍在追赶的时间线。装饰微动可以独立计时，但不能改变对象身份或与叙事层争写同一属性。[技术依据：Lenis 官方仓库；GSAP ScrollTrigger 文档，见下方链接。]

核心画面由“当前章节及局部进度＋布局＋显式交互状态＋资源/质量状态”求值。不能依赖必须顺序触发的 onEnter/onLeave 或逐帧累加来完成场景。滚动位置只负责叙事浏览；投球、落子、修补、选择等有结果的操作，只由明确用户动作提交，回滚不重复提交。可重放的核心随机性固定种子或保存结果。资源请求带当前目标标识，A→B→C 后迟到的 B 只能缓存，不能覆盖 C。

同一对象保持身份、pivot、尺度和支撑关系；不同实体不强行做无依据的 morph。位图、序列与实时场景接管前，对齐屏幕轮廓、相机、主光、接触阴影、亮度和色彩流程；复杂透明不能靠两层 opacity 对倒敷衍。未就绪时显示当前目标章的高质量静态或轻量替代，不能沿用无关旧章。质量升级在当前进度接管，不重播入口。

只为真实展开设置 pin，清楚定义进入和释放；字体、资源尺寸或断点改变布局后，合并必要的重新测量，不能每帧 refresh。响应式重建清理旧时间线、监听、pin 和内联状态。菜单、滑块、局部拖拽与主滚动分清输入归属，不全局吞掉 wheel/touchmove。隐藏层不拦点击、不保留错误焦点。浏览器缩放、键盘、滚动条与章节锚点均能工作。

### C. 排版、资源与跨端

先安排真实标题、正文、图注、导航与控件，再添加动效；为英文长标题、两行标题及英文回退字体留出空间。正文采用正常文档流与合理行长，关键图文不能全部绝对定位在同一处。高光、运动前景、固定 UI 和旧章文字在转场中都不能破坏阅读；必要时对重要 DOM 矩形做碰撞筛查，再以实际截图检查 Canvas/WebGL 遮挡和对比度。

手机必须执行本篇的独立构图；尊重安全区、地址栏高度变化、横竖屏和短高屏。自动响应 `prefers-reduced-motion`，也可提供清楚的手动选择；偏好变化时清理旧动画并恢复当前章节、合理位置与已有交互状态。低动态模式保留全部十章与交互结果，用定帧、对照或按步查看替代飞行、强视差和持续自动运动，可关闭 Lenis 平滑并采用原生滚动。持续微动有合适的暂停控制。音频只在本主题确有价值时制作，用户主动启用、随时关闭；静音仍完整可理解。

首屏关键主图、真实标题和基础构图先成立，模型或精细效果随后接管；关键图不要误做懒加载，也不让十章大资源抢首屏带宽。提供合理尺寸、响应式图像和按需字体。分别记录首幅有意义视觉、完整 Hero 与可交互状态；预算根据实测的资源、解码、绘制和设备情况决定，不承诺未测的帧率。

当前章、邻近章与用户跳转目标按需要准备资源；离屏和后台暂停无效渲染。共享材质、几何、纹理和渲染目标有明确引用与释放策略，反向恢复与回收一起设计。来回浏览后资源/监听不得持续累加。字体、图像、模型失败以及 WebGL 不可用/上下文丢失时有对应章节的完整替代；网络恢复、后台返回、resize、刷新和历史返回保持合理章节与交互状态，不补播巨大时间差。
