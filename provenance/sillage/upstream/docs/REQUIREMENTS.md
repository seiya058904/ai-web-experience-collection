# SILLAGE — requirement and evidence ledger

This final ledger maps the supplied `01-sillage(1).md` to acceptance criteria and observations recorded on 2026-11-09. **Implemented** identifies a source path; **Observed** identifies an actual check; **Pending/Unverified** remains open. A browser-inspected composition does not automatically verify every interaction listed in its acceptance criterion.

Evidence IDs refer to [TEST-REPORT.md](TEST-REPORT.md): **U1/U2/U3** are the 78 state/artwork/transition tests; **U4** is final source and clean-extraction reproduction; **B1** is the ten-chapter/90-state browser inspection; **B2** covers native interactions; **B3** is PNG preparation; **B4** is the additional 27-state responsive matrix; **B5** is history/persistence; **B6** is image/font failure testing; **B7** is the independently rebuilt browser path; **V1** is the final visual SHIP decision; **A1/A2** are art provenance and byte inventory. Full G5 acceptance remains partial because the explicit environment, zoom, download and stress/performance limits remain unverified.

## Fixed scope and vocabulary

- Ten complete English chapters, nine reversible transitions and eight distinct generated image outcomes.
- Visible terms: **Brightness / Spice / Warmth** and **Arrival / Unfolding / Trace**. The internal phase ID `afterglow` is displayed as **Trace**.
- Default composition: **45 / 20 / 35**. Default title: **After the Open Window**.
- Memory suggestions: **The New Window** and **The Unsent Note**. A preference suggests a title; it does not change shares or overwrite a title without an explicit action.
- Presets: **Daybreak** (65 / 15 / 20), **Undertone** (25 / 45 / 30), **Last light** (20 / 15 / 65).
- All site-authored copy, controls, image labels, metadata, accessibility text, errors and export labels are English. Preserve user-authored titles as text in the language entered.
- An original visual interpretation of scent. No transmitted scent, perfume-performance prediction, formula, measured diffusion or therapeutic claim.
- Delivery is a runnable source ZIP with formal assets, lockfile, running instructions, source/licence notes and genuine evidence. This task grants no publication, deployment, push, PR, Release or Collection-inclusion permission.

Record defects as: **location → conditions → reproduction → observed failure → cause → correction → recheck**. Engineering assertions establish functional facts; visual inspection establishes composition, material, readability and transition hierarchy. An unavailable required image, unreproducible source package, broken core interaction or normal-scroll black flash prevents a claim of complete acceptance.

The final package should include source, dependencies/lockfile, redistributable formal assets and licences, README, Visual Bible, generation record, this requirement mapping, real QA summary, necessary evidence and a SHA-256 value. Exclude secrets, account data, `node_modules`, caches and unrelated debug material. State honestly when installation requires a network. Keep **Implemented / Verified / Unverified / Blocked** distinct in the final report.
