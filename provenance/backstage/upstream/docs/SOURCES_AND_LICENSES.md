# Sources and licenses

Recorded on 24 October 2026. This document distinguishes research references, original project material, generated studies and third-party software. Research sources informed the design; their photographs and diagrams are not bundled as website assets.

## Original project material

The stage geometry, scenic textures, prop shapes, HTML, styles and production state are original project work. Paint, wood and scenery are generated by the local Canvas routines in `src/materials.js`; depth, bracing, rails, occlusion and shadows come from `src/theatre.js`. Static posters are renderings of that same stage. No stock theatre photographs or downloaded scenic models are used.

No project-wide open-source license is assigned here to the original BACKSTAGE source. The terms of the third-party libraries and fonts below remain independent.

## Theatre and visual research

The following sources were read for their specific structural or artistic ideas. The longer research note explains the translation into the original model and the limits of that translation.

| Source | Verified contribution |
| --- | --- |
| [National Theatre — Playing With Scale](https://artsandculture.google.com/story/playing-with-scale-national-theatre/awWhDVSTan5fKQ?hl=en) | Physical set models as a tool for space, movement and materials; swinging, translating and revolving scenery; scene-by-scene model storyboards. |
| [IATSE Local 470 — Stage Carpentry](https://www.ia470.com/primer/scenery.htm) | Back battens, on-edge stiffeners, triangular jacks and stage braces. |
| [Northern Virginia Community College — The Flat](https://novaonline.nvcc.edu/eli/spd130et/TheatreAppreciation/flat-p.htm) | The distinction between a covered scenic front and its exposed framing; additional support for larger flats. |
| [J.R. Clancy — Rigging glossary](https://www.jrclancy.com/glossary.php) | Battens, guides, lift lines, loft blocks and masking vocabulary. |
| [The Old Vic — Model Box Geography](https://oldvicmodelbox.com/geography/) | Onstage/offstage visibility, revolves, pivoting wagons and wing masking. |
| [Theatres Trust — Theatre spaces](https://www.theatrestrust.org.uk/discover-theatres/theatre-faqs/171-what-spaces-make-up-a-theatre) | Wing storage, tracks and stage machinery; vertically flown scenery. |
| [Wenger — StageTek Owner’s Manual](https://www.wengercorp.com/Lit/Wenger_StageTek_Owners_280A099.pdf) | Modular deck frames, legs and joining components, used only as structural context. |
| [V&A — The story of theatre](https://www.vam.ac.uk/articles/the-story-of-theatre) | Moveable perspective scenery and shutters travelling in floor grooves. |
| [National Gallery — Perspective](https://www.nationalgallery.org.uk/paintings/glossary/perspective) | Painted depth, recession and a consistent vanishing point. |

These references do not certify the miniature’s engineering or physical safety. Its proportions and mechanisms are original simplifications designed for a browser experience. No institution endorses the project.

The supplied [INTERVAL](https://github.com/seiya058904/ai-web-experience-collection/blob/main/docs/interval/DESIGN.md), [KAGE / VOID](https://github.com/seiya058904/ai-web-experience-collection/blob/main/docs/kage/DESIGN.md) and [VEIL](https://github.com/seiya058904/ai-web-experience-collection/blob/main/docs/veil/DESIGN.md) design documents were read without modification. The official link above is retained instead of inventing a local license text or describing GSAP as MIT.

## Runtime privacy and portability

There are no analytics, external media calls, credentials, secrets or API keys in the experience. Production choices remain in tab-scoped `sessionStorage`. The first dependency installation requires package-registry access; the installed project builds and serves its assets locally afterward.
