# Third-party license records

Reviewed on 2026-11-09.

These files were copied without modification from the actual installed npm packages, except `gsap/NOTICE.txt`, which records the installed package license field and original source header because the package contains no standalone license file. `DEPENDENCIES.json` lists the package versions, package-declared licenses and copied notices.

The three font license files preserve their copyright notices and the full SIL Open Font License 1.1. TypeScript and Playwright notices include their distributed third-party notice files. Vite and Rolldown notices preserve the licenses supplied by their installed packages.

This directory does not relicense third-party software. The project's own code license, if present, does not supersede these licenses. Optional dependencies for platforms absent from this build environment remain described by `package-lock.json`; inspect their delivered package notices when installing on those platforms.
