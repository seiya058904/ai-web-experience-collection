# FERRUM — 产品说明与体验边界

## 作品定位

**FERRUM / THE MEMORY OF FIRE** 是六幕英文沉浸式网页作品，观看对象是一件原创、非历史归属的抽象钢制雕塑。它由粗粝坯体逐步获得刃形轮廓，并最终安静陈列。

核心体验是观察同一物体如何因火、力量、冷却与修饰而改变。视觉重点依次为材质与构图、镜头衔接、可停留的交互体验，同时保证基本可用性、性能与适配。所有章节应具有完整的观看价值。

网站中的“记忆”是诗性表达。作品不声称复原某一历史名刀，不是完整锻造程序、刀具制造教程或真实材料仿真。工艺用语与研究来源见 [RESEARCH.md](docs/RESEARCH.md)。

## 六幕叙事与原创英文文案

以下文案为本项目原创，可直接用于画面字幕；它们不是引自研究资料的原句。

| 章节 | 叙事任务 | 原创英文文案 |
|---|---|---|
| PROLOGUE — BEFORE FORM | 用侧光建立坯体的重量、比例与表面，给予观众辨认它的时间。 | Before the edge, there is only weight. |
| I — THE FURNACE | 局部热与光逐步成为主要视觉力量，暗部仍保留形体。 | The metal gathers light. |
| II — THE STRIKE | 一次明确接触将积蓄的力量转化为形态与痕迹。 | Force becomes a line. |
| III — THE TEMPERATURE BETWEEN | 热光退去，冷却与余雾使材料变化可感。 | The glow fades. The change remains. |
| IV — REVEAL THE EDGE | 缓慢掠过的冷光揭示棱线、表面与加工细节。 | Light follows the work of the hand. |
| EPILOGUE — THE RELIC | 回到安静的观看，让最终姿态回应最初的坯体。 | All that heat. This quiet object. |

这里的 **RELIC** 是章节名称，不表示真实出土、古董鉴定或馆藏身份。不得添加虚构年代、工匠署名、收藏履历或看似真实的馆藏编号。

## 连续性与交互要求

主角必须始终可辨认为同一件物体。轮廓、棱线和重要表面痕迹应具有连续关系；章节切换不应让它突然变成另一把器物。

每幕遵循 **Enter → Stable Composition → Living Hold → Handoff → Exit** 的观看节奏。观众应能停在稳定构图中欣赏细节；炉光、细尘、余热或轻微反射可保留生命感，但不依赖强制等待才推进剧情。

滚动反向、快速跨章与中途跳转均应恢复相应的形体、光线和文字状态。镜头衔接应利用同一边缘、局部热光或反射线，避免用黑块和突兀遮罩隐藏场景切换。

正文使用真实文字，导航应支持键盘和清晰焦点。信息不能仅靠颜色或动画传达。若提供声音，默认静音，并提供明确开关。若不提供声音，不显示无效音频控件。

## 适配与降级

- 桌面与移动端分别组织主体、字幕和留白；手机端不得只缩小桌面构图。
- 开始加载时应尽快出现可读、可见的内容，资源未完成时仍能理解并进入作品。
- 低性能设备、减少动态效果偏好、视口变化及后台恢复均应有合理行为。
- 若使用 WebGL，应处理上下文不可用或丢失；降级后仍须保留六幕内容和导航。
- 性能优化以减少无益开销为目的，不以持续空白、删去章节或破坏材质层次换取指标。

## 验收范围

至少检查 **360×780、390×844、768×1024、1440×900、1920×1080、3840×2160** 六个尺寸，覆盖各幕进入、稳定观看与交接状态。重点检查文字遮挡、几何连续性、反向滚动、快速滚动、重载、触摸和减少动态效果。

至少进行两轮逐张视觉检查，优先修正最弱章节及交接。黑块闪烁、突兀跳景、主体意外消失、材质塑料感、关键细节被文字遮挡及移动端叙事缺失均属于应修复的问题。

本文件定义产品目标，**不表示这些项目已经通过测试**。实际运行方式、已测环境、覆盖结果和未验证项应以最终 README 与验收记录为准；不得将未运行的浏览器或设备写成通过。

## 交付与范围

最终交付为完整、可本地运行的源码 ZIP，包含正式源码与资产、依赖说明、README、设计说明、研究与素材记录、浏览器验收结果及剩余限制。排除 `node_modules`、浏览器缓存、失败稿与大型无用临时文件。

素材以原创为原则；任何外部生产资产都必须有适用的使用依据。研究链接与资产授权分别记录。
