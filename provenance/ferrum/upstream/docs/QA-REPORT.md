# FERRUM — 最终浏览器与视觉验收

记录时间：2026-10-12 14:53 UTC。

## 结果与适用范围

本次交付通过 **23 项浏览器验收、19 项叙事与音频测试**，并完成 **6 种屏幕尺寸 × 6 幕 × 3 个阶段，共 108 张最终源码截图的逐图复核**。另外保留最后两处几何边界修复的 14 张局部复核图与数值证据。源码包在没有 `node_modules` 的隔离交付目录中完成构建和真实浏览器冒烟验证。

这些结果支持在本次 Chromium 环境中本地复核、继续开发和集成。审美判断是制作与复审结论，不代表奖项认证、摄影级真实度或所有设备上的性能承诺。后文明确区分真实浏览器输入、合成生命周期事件和未覆盖设备。

正常访问的错误与警告为 **0**，失败或外部资源请求为 **0**。禁用 WebGL、主动阻断可选贴图和注入渲染异常的独立测试会产生预期错误日志；报告保留这些日志，并按故障上下文区分，没有屏蔽所有 WebGL 警告。

停止滚动检查先等待 Lenis 实际结束滚动，再观察至少四个主循环帧及至少 500 ms。本次观察了 **4 帧 / 998 ms**，叙事进度漂移为 **0.00000000**，原生滚动位置漂移为 **0 px**，随后继续滚轮仍能前进。早期固定等待 1200 ms 的脚本不能可靠地区分惯性末段与停止状态，因此已改为实际状态门控，保留超时和漂移断言。

`pagehide/pageshow` 使用合成 PageTransitionEvent，证明应用处理器的暂停和恢复逻辑；不冒充操作系统实际挂起或浏览器原生 BFCache 的完整覆盖。CDP touch 使用浏览器触摸输入管线，但运行设备仍为 Linux 桌面环境。

## 视觉复审与修正记录

制作过程中至少两轮完整查看六幕的桌面、手机稳定构图，并针对最弱章节持续修改。早期独立审查曾退回热金属的封闭熔岩纹、水面的完整光圈以及砧体黑块问题。后续完整复审转为局部收紧；最后对水面可见性及最终矩阵的两处边界问题进行实际复拍。没有只凭测试通过便结束视觉工作。

| 发现 | 交付版处理 | 复核方式 |
| --- | --- | --- |
| 冷金属趋于均匀、塑料化 | 分离粗糙主面、研磨区、倒角及微划痕；重新组织窄反射 | 六幕桌面和手机定帧复审 |
| 高温面出现封闭熔岩纹与大块暗斑 | 连续纵向热场，细碎、断续的氧化层；局部热源影响邻近表面 | 炉火、击打近景逐图比较 |
| 锤砧成为无层次黑块 | 调整砧上表面材质、边缘与锤头侧面补光 | 击打稳定构图与两次接触 |
| 手机主体被地面切开 | 按真实变形后最低点放置地面，重新调整竖屏构图 | 手机六幕与方向切换 |
| 水面像 HUD 光圈，或局部反光太弱 | 移除完整圆环，保留碎反射、短接触余波和薄雾 | 宽屏与手机入水画面 |
| 金属倾离时尾端穿入砧面 | 独立砧体按金属真实最低点连续退开；锤头轨迹不变 | 768/390 交接复拍与 966 个几何样本 |
| 16:9 宽屏露出有限水面的硬边 | UV 四边在抵达几何边界前淡至透明，中央反光不变 | 1920 三阶段及 390 稳定画面 |
| 原生对话框 Tab 焦点逃逸 | 对话框首尾焦点循环并保留 Escape 焦点归还 | 实际键盘输入验收 |
| WebGL 恢复出现旧资源删除警告 | 在上下文丢失时释放旧 PMREM 目标，恢复后重建 | 强制丢失、章节跳转与恢复 |
| 上下文丢失出现短暂灰白画布 | 立即隐藏无效 canvas 并显示已准备静帧，恢复时平滑接回 | 即时计算样式、截图和故障验收 |

原穿砧复现帧中，砧面严格内部核验区内的金属顶点由 **232 变为 0**。使用实际几何顶点、morph、旋转和比例，在击打 local 0.08 至入水 local 0.16 区间检查 **6 尺寸 × 161 个进度样本，共 966 个样本**；每个样本的金属最低点均高于砧体最高点，共同父组局部坐标中的垂直净距不小于 **0.008**。整体缩放后的净距仍为正。

对水面 UV 四边进行了 **516 次解析公式检查**（每边 129 次，角点重复计入），新增透明度衰减因子均为 **0**；1920 与 390 视口的实际截图另行确认硬边消失，中央反光仍可见。这两项是对具体边界缺陷的检查，不将艺术场景宣称为物理模拟。

## 未覆盖与解释边界

1. **尚未在用户的 AMD 显卡、Windows 桌面或实际 4K 显示器上运行。** SwiftShader 证明的是本次软件图形路径，不提供硬件帧率结论。
2. 未实测 Safari、Firefox、真实 iOS/Android 手机、浏览器地址栏的物理收放及系统后台挂起。移动视口、触摸事件和方向切换已有自动化覆盖。
3. 已验证音频上下文与开关行为；未以真实扬声器、蓝牙设备或不同设备音量做听感与输出延迟标定。
4. 截图矩阵是离散的进入、停留和交接位置；滚动交互及状态连续性另有测试，但不代表对所有浮点进度逐帧审阅。
5. 采用有意的暗部和艺术化实时材质。水、蒸汽、热场与声景均为叙事表现，不是流体、热处理或显微组织的科学模拟。显示器黑位、色彩与字体栅格化仍可能改变观感。
6. 手动画质切换、静帧模式和已列出的故障回退路径已验证；**自动性能降档未在本次验收中触发验证**。没有进行长时间硬件压力测试、真实移动网络分档测速或完整无障碍认证。
