# FERRUM · Visual Bible

## 创作方向

作品是一段由观众滚动剪辑的材料电影。炭黑空间、骨白字、狭窄光源与同一件钢制器物形成全部视觉语言。主体持续存在；每一幕改变的是形态、温度、表面与观看尺度。不存在商城、武器游戏、仪表盘或历史馆藏身份。

## 色彩与文字

- 空间：`#0b0c0d`；主文字：`#e8e5de`；次文字：`#aaa9a4`。完整界面色值与当前尺寸以 [DESIGN.md](../DESIGN.md) 和 `src/styles.css` 为准。
- 余烬橙 `#e76b35` 是少量界面强调色。场景中的热度由程序材质、局部光源与受遮挡的暖晕共同表达；亮部要集中在有能量来源的位置，保留暗色氧化皮。
- 冷钢色来自狭窄环境反射和表面粗糙度，不作为另一个固定界面色值。主要暗面、磨削斜面与薄刃高光应保持层次。
- 巨型 FERRUM 和章节标题：本地 Antonio 300；目录标题：Barlow Condensed 500，章节编号使用同一字族，在 CSS 中名为 Barlow；界面与叙述：Manrope。随包字重与许可见 [ASSET-PROVENANCE.md](ASSET-PROVENANCE.md)。
- 正式画面的可读文字、控制和导航都由 DOM 绘制。概念图中描绘的排版只作构图参考，正式定帧不承载网页按钮或文字。
- 导航保持开放排版、细线和方形几何标记，不使用卡片或商业 CTA。

## 实时与定帧分工

主体验使用同一三维网格的形态插值、定制金属材质、环境反射、实时镜头、解析锤击与定量粒子；一个主动画循环驱动更新。叙事形态、热度和接触事件随滚动进度重求值，环境运动另用同一循环内的时间。炉、砧和冷却场景组在首次需要时建立；原坯 WebP 先加载，抛光 WebP 在首次抵达第 03 幕或后续章节时开始加载。

锤击交接时，砧顶、腰和底座作为独立主体，以当前旋转金属的实际最低点与砧顶包围盒上界计算向下位移：`min(0, lowestY - supportTop - .008)`。该调整随叙事状态连续求值，锤头仍使用原轨迹。水面透明度在四个 UV 外沿提前降至零，中央局部反射保留；面片外框由边缘渐隐处理。

环境反射由四条程序摄影灯带生成。水线、接触余波和接触阴影使用解析近似；暖晕为参与场景深度遮挡的加色软光面。当前实现没有屏幕后处理 bloom，也没有流体或热力学模拟。两张生成材质图仅提供局部表面细节。

视觉概念图仅用于构图研究。12 张正式定帧由 `scripts/render-stills.mjs` 输出同一实时场景的无文字浏览器画面，再由 `scripts/encode-stills.py` 编码为 WebP，桌面与竖屏各六张。它们用于保留六幕 DOM 文案与导航的定帧视图；实际浏览器、叙事状态、源文件和输出 SHA 保留在 [still-render-origin.json](design-reference/still-render-origin.json)，逐项文件见 [ASSET-INVENTORY.md](ASSET-INVENTORY.md)。

## 移动端

竖屏重新调整摄影机距离、目标点与物体方向；主要标题和叙述与主体分处屏幕上下区域。竖屏有单独像素比上限，低细节模式进一步减少像素预算与粒子数量。手机功能文字至少 11px，主要控制保留至少 44px 的触发高度。宽度大于 700px 的竖屏定帧采用完整适配；无悬停输入显示滚动提示，不要求移动指针。

## 审核重点

1. 大标题和刃形不碰撞；正文在最亮场景仍能读清。
2. 炉光、锤击接触和冷白高光必须有方向和位置来源。
3. 随意反向滚动，热度、模型、锤头和粒子由同一进度重新求值。
4. 章间不清空 canvas、不替换器物、不出现强制黑场。
5. 结尾的材质、布局与交互完成度等同首屏。

本文件记录方向、当前实现方法与审核约束，不代表已通过视觉或浏览器验收。最终实测结果与未覆盖环境应记录在根目录 `QA-REPORT.md`；[DESIGN.md](../DESIGN.md) 负责设计选择与样式 token。
