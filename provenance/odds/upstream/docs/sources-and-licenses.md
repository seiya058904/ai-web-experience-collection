## Eight generated image references

The eight files in `artwork/` were generated for ODDS with **`image_gen.imagegen`**. Actual prompts, their output provenance and assigned uses are recorded in [image-generation.json](image-generation.json). The tool did **not** supply generation seeds; no seed is invented. Historical source paths in that record document creation only and are not application dependencies.

| File | Dimensions | Role |
| --- | --- | --- |
| `artwork/img-01.webp` | 1536×1024 | Desktop-scale, three-quarter Hero A. |
| `artwork/img-02.webp` | 1536×1024 | Near-frontal exhibition-scale Hero B. |
| `artwork/img-03.webp` | 1536×1024 | Entry/lead-ball macro Hero C. |
| `artwork/img-04.webp` | 1536×1024 | Selected refined desktop visual reference. |
| `artwork/img-05.webp` | 1024×1536 | Independently generated portrait mobile composition. |
| `artwork/img-06.webp` | 1536×1024 | Chapter 4 path-relief composition. |
| `artwork/img-07.webp` | 1536×1024 | Chapter 8 many-ball portrait composition. |
| `artwork/img-08.webp` | 1536×1024 | Chapter 7→8 transition midpoint composition. |

These are original project assets produced through AI generation, not stock photographs, museum reproductions, or assets borrowed from another website. The brief requests no third-party logos or trademarks. No MIT, Creative Commons, or other third-party license is fabricated for them, and no legal guarantee of exclusivity or noninfringement is asserted.

The figures provide lighting, material and layout direction. Their painted pegs, paths and balls are not data. Live geometry, sample identities, counts and probability references are calculated in code. The production board, path diagrams and trays use SVG; the 256-ball portrait uses Canvas 2D with an SVG fallback. The [artwork gallery](../artwork/index.html) displays all eight independently.

## Additional generated production material

**IMG-09**, at `public/art/material.webp`, is a separate generated surface texture. It does **not** replace or count toward any of the eight reference roles. Its actual `image_gen.imagegen` prompt, source provenance and transformation are recorded in [material-generation.json](material-generation.json). The generation tool did not provide a seed.

The generated material was resized to **512×512** and encoded as WebP for runtime use. It is applied as a repeating low-opacity texture over the exact code-defined board. It contains no statistical diagram, numerical label, peg or ball. This production material is an original AI-generated project asset under the same provenance description and limitations as the eight references, with no fabricated third-party artwork license.

The normal production build serves the tile locally. `ODDS-Offline.html` embeds it together with the application styles, script, favicon and bundled font files. These packaging choices do not change the component licenses below.
