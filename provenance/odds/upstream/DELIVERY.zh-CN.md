## 二、Windows 使用方式

源码流程需要 **Node.js 24 或更新版本**及 npm。第一次安装依赖需要网络。

- 双击 `START-WINDOWS.cmd`：安装缺失的锁定依赖并启动开发服务器。
- 双击 `PREVIEW-WINDOWS.cmd`：构建并启动生产预览。
- 按终端打印的地址打开浏览器；保持窗口开启，结束时按 Ctrl+C。
- 两个 CMD 文件已做静态检查，但没有在 Windows 系统实际执行。

也可以在项目目录运行：

```powershell
npm ci
npm run build
npm run preview -- --host 127.0.0.1
```

修改源码后，用以下命令同时更新生产构建与自包含离线文件：

```powershell
npm run portable
```

不要直接双击 `dist/index.html`；它使用外部本地模块资源，应由 HTTP 服务器提供。直接打开的单文件版本是 `ODDS-Offline.html`。

## 三、已经实现的作品

网站自带文案、控件、模型说明、无障碍名称及 SVG 导出的固定文字均采用英文。视觉采用奶油背景、蓝色厚度钉板、橙球与克制的版式；主体图形由精确 SVG/Canvas 重建。

| 章节 | 实际功能 |
| --- | --- |
| 01 · Every chance leaves a trace. | 点击产生独立入口样本，显示八步路径与真实落点；提供暂停、按步和立即看结果。 |
| 02 · Left. Or right. | 四次独立单步选择；方向键只查看既有选择，不改变随机结果。 |
| 03 · More paths than places. | 枚举四层的 16 条路线；按终点或前两步筛选、选择路线、复位。 |
| 04 · The middle has more ways in. | 八层九终点的精确组合权重与概率说明。 |
| 05 · Small samples have character. | 两轮各 16 球，对照实际数量与理论期望；生成新组与撤销。 |
| 06 · A different leaning. | p=0.25/0.50/0.75 各自启动新 64 球实验，保留上一轮。 |
| 07 · Same rules. Different evenings. | 三轮固定序列，查看 16/64/128 前缀，保持统一刻度；手机采用纵向排列。 |
| 08 · A portrait of 256. | 仅延长中间一轮到 256 个唯一样本；按槽位与编号查看真实路径。 |
| 09 · Give chance a set of rules. | n=4/8/12、p=0.25/0.50/0.75、N=16/64/256；运行、重放、恢复与 SVG 导出。 |
| 10 · Still worth watching. | 用同一规则追加一球，同步样本数、计数与导出；返回工作台及开头。 |

全部九个相邻交接均有实现。特别处理了四层扩展到八层的统计语义、中间一轮到 256 球的样本身份，以及最后一章中只有一组观测柱形接管画面的连续过渡。

Lenis 由单一动画循环推进。低动态模式保留章节与结果，使用原生滚动和完整定帧。滚动、缩放、选球、重放或画面接替不产生新实验。

## 四、数学与状态

每轮保存 seed、n、p、N、全部路径及计数。路径中的向右次数就是终点编号；所有槽位计数之和等于 N。

八层公平模型的精确路径权重是：

```text
1, 8, 28, 56, 70, 56, 28, 8, 1
```

它们合计 256 条可能的方向序列，不能当成投下 256 球就必然得到的实测成绩。实际实验的理论参考使用 `N × P(K=k)`，与观察结果采用同一数量单位。16 球时中央槽的理论期望是 4.375，实际球数保持整数。

入口实验、偏向实验、三个教学序列和个人工作台分别保存。结束章若在尚未运行个人实验时追加，会明确继续 64 球演示到 65 球，不把此前演示冒充用户亲手运行的实验。使用同一 seed 重放是重复已保存的伪随机序列，不是预测未来。

数学与技术来源、用途及限制见压缩包中的 `docs/research.md`；页面模型说明也提供来源链接。

八张完整参考图可在 `artwork/index.html` 独立查看。原始提示词、实际工具、文件、选用理由及转换记录在 `docs/image-generation.json` 和 `docs/material-generation.json`。工具没有返回生成 seed，记录没有编造该字段。

网页不把生图中的钉阵、球数或公式当成正式数据；准确几何、标签、控件和结果由代码绘制。桌面截图已形成蓝板、橙球、奶油底与留白的方向，但板的实际画面占比、颗粒与钉柱实体感仍弱于 IMG-04，不能声称完全兑现照片质感或 55%–62% 的板宽目标。
