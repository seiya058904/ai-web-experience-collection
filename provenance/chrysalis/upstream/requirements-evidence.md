# CHRYSALIS — Requirements and evidence ledger

Reviewed 9 November 2026 (UTC). This is the acceptance record for the supplied Edition 2.0 build brief. The complete source is delivered, but **the strict H1–H9 contract is not accepted**: the browser environment could not provide several mandatory input, lifecycle, zoom, network and continuous-motion observations. Those limits are explicit below. A scoped PASS does not turn an unobserved requirement into a success.

Statuses use the brief's vocabulary: `NOT STARTED`, `IN PROGRESS`, `READY TO TEST`, `PASS`, `FAIL`, `BLOCKED`, `NOT TESTED`. Timing diagnostics are described as observations, not assigned a performance PASS. The [QA report](docs/qa-report.md) explains actual results and failure lineage; the [evidence index](docs/evidence-index.md) maps them to retained files.

## Exact limits that remain

- **BLOCKED:** standalone native Playwright execution; five official download attempts returned invalid empty archives.
- **BLOCKED:** true browser UI zoom. Native shortcuts were attempted and the observed viewport/zoom signals did not change; the harness's effective reflow dimensions remain only reflow evidence.
- **BLOCKED:** actual OS motion-preference emulation and touch input, continuous scroll recording, and a confirmed hidden-to-visible background cycle. The supported controls did not expose these capabilities or produce the required state.
- **NOT TESTED:** physical devices, Safari, other browser engines, full screen-reader/assistive-technology coverage, native scrollbar dragging, a real throttled/slow-network run, real delayed/missing font responses, actual reordered network responses, and bfcache restoration.
- **NOT TESTED:** final cold-start/LCP/INP/CLS budgets, high-refresh-rate hardware, or repeated-tour memory behavior. Historical frame samples timed out and cannot establish smoothness or its cause.

These limits are not mitigated by deleting story sections, substituting generic placeholders, relabeling CSS sizes as devices/zoom, or discarding failed runs. The source and reproducible checks are delivered so the remaining gates can be completed in a capable browser environment.
