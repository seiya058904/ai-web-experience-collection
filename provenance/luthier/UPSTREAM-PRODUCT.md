# LUTHIER — The Anatomy of a Violin

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose

A complete, local, immersive digital artwork about a silent wooden object becoming sound. The visitor follows Object → Craft → Tension → Resonance → Sound through nine scenes. The user supplied the subject, narrative, visual priorities, interaction requirements, and delivery constraints in full.

## Stack

Implementation choice for this brief: vanilla TypeScript and Vite, one Lenis instance synchronized with GSAP/ScrollTrigger, original Canvas/SVG motion and a selective Three.js structural study. Photography-like assets are generated specifically for the work. HTML owns every text and control.

## Fixed commitments

- Presence, Wood, Craft, Inside, Tension, First Bow, Resonance, Sound as Space, Return; none may be omitted.
- STRING and CURVE persist across chapter handoffs.
- Hero is a monumental crop, not a distant object on a pedestal.
- First Bow is the narrative ignition; motion must follow actual hair/string contact.
- Gallery black, warm ivory, real wood character, amber varnish and restrained light.
- Smooth scroll has one authority; forward/reverse, pause, resize, restore, keyboard, mobile and reduced motion all retain the story.
- No deployment, hosting account, external write, public preview, analytics or runtime network service.
- Deliver exactly one ZIP containing source, production assets, selected AI originals, model source, configuration, build method, licenses, attribution and provenance. Exclude dependencies, caches and temporary QA artifacts.

## Accessibility

Keyboard-operable controls, visible focus, an explicit optional sound control, native reduced-motion preference, a short readable nine-chapter reduced-motion route, semantic headings and meaningful media descriptions.

## Evidence and honesty

Primary-source research is recorded in docs/RESEARCH.md. This is an unnamed synthetic instrument, not a scan or photograph of a Stradivari. Acoustic time, displacement and contour fields are illustrative. Audio is original procedural sound design and begins only following a user's sound-on action.
