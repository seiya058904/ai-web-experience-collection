# PAPERSUN — rights and attribution

Reviewed **2026-11-09** against the installed package metadata and licence files, the generated-art records, and GSAP's official terms. Project-specific content and third-party components are identified separately; this document does not relabel every dependency as MIT.

## Original project material

PAPERSUN's story, Mira, chapter copy, scene arrangement, SVG character/props, exact fragment geometry, interface, and procedural sound were authored for this requested project. The tale is original fiction, not an adaptation attributed to a historic tradition. The chimes and paper rustle are generated by `src/audio.ts`; no music recording or downloaded sound sample is included.

The raster scenes were generated with the available built-in image tool for this project. They were not retrieved from a stock-photo or illustration site. The prompts did not request a named artist, studio, franchise, celebrity, or recognizable existing character. The deliverable makes no exclusivity or independent third-party-rights-clearance claim for generated imagery.

The exact prompts, actual returned dimensions, known parameters, selection decisions, and derivative hashes are preserved in:

- `art/concepts/provenance.json` — the three opening candidates.
- `art/concepts/prompts-refinement.json` — the refined desktop and portrait compositions.
- `art/concepts/prompts-main.json` — the two advanced scene studies and transition midpoint.
- `art/extra-backgrounds.json` — additional attic, market, and valley environments.
- `art/clean-plates.json` — production image edits that remove baked moving props.
- `art/asset-derivatives.json` — distributed WebP derivatives and integrity metadata.

See [the artwork record](assets.md) for the eight mandatory image outcomes and the production selection. Historic generation-working paths in those records are provenance, not missing runtime dependencies. No undocumented model name, seed, or generation setting is asserted.

## Transitive build dependencies

`licenses/dependency-inventory.json` records **every non-root package entry in this archive's lockfile**, with the exact version, declared licence, development flag, and optional flag. It includes platform-specific optional packages that are not all installed on one machine. It is an inventory of the locked dependency graph, not a claim that every binary is shipped inside the source ZIP.

That graph includes, among others, Lightning CSS under MPL-2.0, picocolors under ISC, and source-map-js under BSD-3-Clause. Playwright adds `playwright-core` 1.62.1 under Apache-2.0; its exact-version runtime licence and notice are retained as `licenses/playwright-core-APACHE.txt` and `licenses/playwright-core-NOTICE.txt`. Its optional macOS `fsevents` 2.3.2 dependency is MIT, separately recorded from the other locked `fsevents` version. The inventory contains all 67 non-root lockfile entries at this checkpoint, with lockfile paths to distinguish repeated package names.

The installed Vite and TypeScript notice files contain their own bundled-dependency notices. Installed dependency directories are excluded from the source archive and are restored by `npm ci`, including their upstream licence files. Browser executables and the isolated build-session Chromium package are not distributed in the source ZIP. Installing a Playwright browser for optional QA is a separate user setup action; the normal application and production build do not require that executable.

Retain relevant notices when redistributing compiled runtime libraries or font assets. A project-level licence choice does not replace these component terms.
