# DOSE — 实际验收记录

验收日期：2026-10-12 UTC。本文记录实际执行的检查、发现与修复，以及尚未验证的范围。机器可读数据在 `QA-RESULTS.json`；两轮独立复审原文在 `reviews/ENGINEERING.md` 和 `reviews/ART-DIRECTION.md`。

## 1. 本次结论与适用范围

七章可以在本地独立运行。最终源码检查、8 组纯逻辑测试、15 项浏览器功能检查，以及六种指定视口的 42 个章节画面检查均通过各自的检查条件。人工艺术复审发现的模型与文字遮挡已经调整，并重新查看受影响的截图。

这些结果来自 **Linux、Node.js 24.19.0、Chromium 153.0.8010.0、Playwright 1.62.1、ANGLE / SwiftShader 软件渲染**。浏览器插件在该环境不可用，因此实际浏览器由 Playwright 启动。六种视口是浏览器窗口模拟，不能写成六种真实硬件已经验收。

**真实显卡上的 30/60 FPS 目标尚未验证。** 软件渲染环境的实测吞吐较低，具体数值保留在第 6 节。源码可运行和交互检查通过，不代表硬件性能预算也已通过。

### 已发现并完成的修正

- 平板 Surface 和手机 Release 的模型侵入正文；上移构图并约束裁切边界，逐张重看。
- 手机 8–9px 的说明和图例过小；提高到 11px，非交互 CGI 标记为 10px；对换行后布局再次精修。

### 保留的视觉取舍

这是交互式程序化 CGI。Hero 和 Surface 有可见孔隙与边缘颗粒，但白色原料团聚体偏雕塑化，青色晶体和粉体保留多边形切面；压机高光比概念图更接近镜面，剖切面和碎块较平整。Surface 的矩形局部裁切是当前构图，交接结合位移/尺度与透明度合成，液体由克制的接触环暗示。结尾保留散开的固体形状，没有显示全部物质凭空消失。

不将这些画面描述成摄影、真实扫描、连续材料变形、流体求解或检测数据。详细五维对照保留在艺术复审文件；没有虚构设计评分。

## 6. 性能实测与限制

以下为最后一次**单浏览器**测试，每个场景在 1440×900 稳定状态观察约 5 秒；此前有并发渲染负载的短观测不用于性能结论。

| 场景 / 画质 | 提交帧 / 观察时间 | 约提交帧每秒 | 同步 CPU 提交均值 / P95 | 三角面 / draw calls |
| --- | --- | ---: | --- | --- |
| Prologue / high | 62 / 5.005 秒 | 12.39 | 0.55 / 0.90 ms | 25,090 / 3 |
| Distribution / high | 42 / 5.003 秒 | 8.39 | 0.82 / 1.10 ms | 123,602 / 5 |
| Distribution / low | 63 / 5.008 秒 | 12.58 | 0.95 / 1.40 ms | 41,522 / 5 |
| Evidence / high | 35 / 5.008 秒 | 6.99 | 0.60 / 1.10 ms | 111,640 / 4 |
| Release / low | 62 / 5.004 秒 | 12.39 | 1.06 / 1.50 ms | 34,706 / 25 |

提交帧率是应用在观察窗口内提交的绘制次数，**不是物理显示器已经完成呈现的 FPS**。同步 CPU 时间也不包含整个软件 GPU 执行时间。这里测得的软件渲染吞吐约 7–13 帧/秒，不能据此声称 30/60 FPS 达标，也不能直接预测真实显卡速度。

轻量模式已验证将 Distribution 从 1,020 个粒子降至 340 个，三角面从 123,602 降至 41,522；像素比例和总量受限。默认自动减负依据 CPU 提交耗时，不能完整识别“提交很快但 GPU 很慢”的情况，所以 About 中保留手动 Light rendering，另有 Quiet motion 和完整 Canvas2D 版本。

## 7. 证据解释与明确未验证项

开发中的第一批对话框测试把原生浏览器 UI 的 Tab 边界错误当作焦点逃逸，抛错后留下打开的 modal，导致后续交互级联失败；隔离测试解决了这一测试假设。另一轮初始脚本对滚动动画和触摸惯性等待不足。它们没有混入最终通过数量，后续真实条件重测的结果才进入功能表。严格 PNG 断言的一像素差异已在第 4 节单独说明。

未验证：Windows 原生执行启动器；Safari / Firefox；真实 iOS / Android；硬件 GPU、120/144Hz 触控板与显示器的帧时间；长时间重复导航的堆/GPU 内存变化；无障碍读屏软件逐字体验及完整 WCAG 合规性。Windows `.cmd` 已采用 CRLF、正确切到自身目录并检查 Node；实际启动验证仍发生在 Linux。

科学上未验证且不属于本项目的内容：真实处方适用性、粒子接触力学、压实压力与弹塑性、孔隙尺度、含量均匀性检测、流体运动、溶出动力学或临床结果。来源阅读深度和引用边界在 `SOURCES.md`。
