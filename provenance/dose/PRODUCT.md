# DOSE

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Implementation choice within the uploaded independent-execution brief: static HTML, CSS and JavaScript modules; local Three.js and Lenis assets; dependency-free Node local server. No hosting integration, public deployment, external repository, or runtime network dependency.

## Users

Viewers exploring a flagship immersive web design showcase. The commissioning user wants a complete, locally runnable source ZIP with documented validation.

## Product Purpose

Reveal the deliberately designed material structure of one hypothetical tablet, through continuous changes of scale. This is an artistic scientific visualization, not a medical service, medicine advertisement or manufacturing SOP.

## Capabilities and Constraints

Seven scenes: prologue, material, distribution, press, surface, evidence, release. Retain one object's identity, reversible scroll, stable compositions, an observation-depth interaction, readable English, reduced motion and non-WebGL fallbacks. Validate 360×780, 390×844, 768×1024, 1440×900, 1920×1080 and 3840×2160. Explicitly report unverified environments. Deliver complete source, assets, sources, licenses, README and actual QA records in ZIP. Do not deploy, push, create PRs, or edit the user's existing collection.

## Brand Commitments

DOSE / THE ARCHITECTURE OF A TABLET. Quiet precision: warm porcelain, laboratory gray, stainless steel, smoke glass, restrained mineral teal; photographic material quality; one tablet and a continuous circular observation motif. No generic medical blue, glowing molecule decoration, invented scientific data, or glass-card template.

## Evidence on Hand

The user's complete specification is upload/03-DOSE-The-Architecture-of-a-Tablet(1).md. The scientific route is an implementation choice the brief permits: hypothetical uncoated immediate-release tablet made by direct compression. All geometry, motion, composition and material-color encoding are conceptual CGI, not measured imagery or test results. Scientific copy requires traceable primary sources.

## Product Principles

1. The material leads; interface controls recede.
2. Every visual transformation retains object identity and a clear change of scale.
3. Scientific statements stay conditional and traceable; no dose, formulation or operating parameters.
4. Quality includes responsive reading, usable interaction and graceful failure.
5. Verification claims describe work actually executed.
