# PAS 交付说明

**记录日期：2026-11-09。** PAS 是一部可通过滚动、章节导航和逐步观察阅读的原创双人舞作品。Cen 穿锈红色上衣，Cheng 穿沙灰色上衣；网站正文、按钮与状态提示使用英文。

核心流程、最终动作资源与下列浏览器交互已完成，G6 冷启动入口也已复测通过。第六节仅保留正式 ZIP 标识及封包后核验的包外记录位置。视觉实现采用插画化 CGI，具体差异和未验证范围见第五节。

## 二、在 Windows 上启动

安装 **Node.js 22.12.0 或更高版本（含 npm）**，将整个源码压缩包解压到普通文件夹。可双击根目录的 `start.cmd`：脚本检查 Node 版本，在缺少 Vite 时安装锁定依赖，并打开本地开发服务器。

也可在含有 `package.json` 的目录打开 PowerShell 或命令提示符：

```powershell
npm ci
npm run dev
```

打开终端打印的地址，通常为 `http://localhost:5173`。使用期间保留终端；按 **Ctrl+C** 停止服务。首次 `npm ci` 需要联网下载依赖，安装后网站使用随包提供的本地资源。

生产构建与本地预览：

```powershell
npm run build
npm run preview
```

构建输出在 `dist/`，预览地址通常为 `http://localhost:4173`；以终端实际输出为准。请通过本地 HTTP 服务访问，不要直接双击 `index.html`。如果 PowerShell 拦截 `npm.ps1`，可改用 `npm.cmd ci`、`npm.cmd run dev`，或使用命令提示符。

附加代码检查：

```powershell
npm test
npx tsc --noEmit
```

Python、EGL、ModernGL 等只用于可选的素材再生成，正常安装、构建和观看网站不需要它们。详细说明见源码根目录的 `README.md` 和 `docs/REPRODUCTION.md`。

## 五、已知差异与限制

- **视觉风格：** 最终动作人物是插画化 CGI。首屏照片感图像切换到 CGI 动作时，风格差异可见；面部、皮肤与衣料细节未完全复现视觉原稿的照片感。
- **镜头：** 每种布局使用固定全景机位，通过同姿态手足近景补充观察。原说明中的多段镜头下降、退出与推进没有逐项复现。
- **停留状态：** 叙事进度暂停时没有独立的呼吸微动。
- **第6章到第7章的交接（TR-06）：** 交接开始时人物已经朝外，随后通过落脚、靠拢形成背部接触；这一段没有另加一次明确的轴向转身。
- **服装与局部表现：** 衣服采用骨骼蒙皮，未做真实布料仿真；TR09 可见 Cheng 肩袖处较硬的折痕／明暗变形。TR04 的松手与手臂下降集中在交接末段，TR08 竖版外侧手掌靠近画面边缘，相关观察已保留在交接复核记录中。
- **动作可信度：** 已进行了动作、骨骼和部分实际网格检查，但没有舞蹈专业或生物力学验证。本作品用于观察，不作为动作教学。
- **WebGL：** 本轮可用浏览器无法创建 WebGL 上下文，默认体验采用已完成的同骨骼渲染序列。源码中的可选实时 Three.js 路线未在该环境中完成视觉验收。

这些限制保留在交付记录中；已完成的代码检查、图像核对及指定交互测试，不自动覆盖全部原始要求或所有设备。

### 最终归档标识与包外核验记录

正式源码包为 **`PAS-source.zip`**。对应的 **`PAS-source.sha256`** 提供完整 SHA-256；**`PAS-verification.json`** 按该校验值记录最终 ZIP 的文件数量、完整性、解压后的文件一致性，以及重新安装和构建的实际命令结果。二者与源码包一同提供，避免要求压缩包包含自己的校验值。

源码内的 `docs/package-reproduction.json` 保留候选包和后续源码更新的复现过程，其候选包校验值与最终交付 ZIP 分开注明。最终生产浏览器记录与截图分别位于 `docs/evidence/pas-production-verification-1794194026505.json`、`docs/evidence/pas-production-counterweight-1794194026501.jpg`。

项目以本地源码形式交付；没有部署或发布，也没有修改现有托管站点或 Collection。
