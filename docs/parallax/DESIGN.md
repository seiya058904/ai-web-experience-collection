# PARALLAX — Design system

The selected ivory-gallery hero governs this installation. See `docs/VISUAL_BIBLE.html` for the visual reader and `docs/VISUAL_BIBLE.md` for the per-scene production matrix.

## Identity

One original architectural frame. Primary: black polished stone. Secondary: chrome fracture surfaces. Signature: one fine ivory incision. The asymmetry and empty oblique aperture remain recognizable across all chapters.

The hero establishes monumental scale before the visitor learns the structure. Later states use space, viewpoint, optical surfaces and light to reveal the same object. The order is intentional: OBJECT → FRAGMENT → ALIGNMENT → REFLECTION → RIFT → MEMBRANE → CHROMA → HALO → REASSEMBLY → THE MUSEUM.

## Type

Bodoni Moda 400 is the Roman display face. Manrope 400/500 supports functional text. The opening title deliberately exceeds ordinary interface display sizes, as required by the brief. Chapter copy is restrained and leaves the sculpture clear. Body text uses modest tracking; wider tracking is reserved for the short identity and chapter labels. All functional labels are at least 11px; phone explanatory copy is at least 12px.

## Field and composition

The ivory field is #e9e2d6. Normal ink is #171611. Dark scenes use #080809 and warm ivory ink. The warm gallery palette comes from the selected target, not from a generic interface theme. Coloured accents belong to optical material behavior.

Desktop page margins are approximately 3.2vw. Portrait phone margins are 22px, reduced to 18px on narrow screens. The opening places the large object over the wordmark at the right. Portrait phones and tablets use a centred silhouette; tablets retain their own text scale. Landscape crops are bounded so the introductory copy and navigation remain readable. Chapter headings, controls and footer occupy consistent positions, with scene-specific placement where it protects the image.

## Controls

The Index is a full-page native dialog with ten chapter links, a Reduced motion preference and Focus artwork. Links are plain editorial rows with fine rules; no cards or dashboard shell. The interface retains visible keyboard focus and touch targets. Align view and its range input make the singular viewpoint reachable without a mouse.

## Motion and materials

The work owns no perpetual spin or particle layer. One Lenis instance smooths wheel input on the existing on-demand RAF; the document position directly samples authored geometry and camera states. Touch/dialog scrolling remains native; reduced motion and restoration are immediate. Reverse traversal is part of the same choreography. The hero pulls back before a short, scale-matched transfer to persistent geometry. Real mirror and refraction captures respond to the live scene. Ordinary chrome receives warm architectural reflections with narrow dark and bright bands inside the cut faces; the composed CHROMA and HALO states retain their original studio field.

## Review decisions

The first local review rejected flat gray mirrors, an imperceptible membrane, overlit black stone, hard block shadows, bright fracture seams and a long mismatched hero overlap. The implementation was revised through local paused-frame review. Selected references remain the original design targets; runtime screenshots and temporary review artifacts are excluded from the delivery.
