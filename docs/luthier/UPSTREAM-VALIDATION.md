### 从实际画面完成的精修

Craft 调整了画面裁切边缘、手机结构图例位置和短屏段落间距。减少动态模式的底部导航改为正常文档流，避免长文档中持续遮挡内容。Ebony 分别处理顶部导航与底部提示的对比。

手机 Inside 在顶部导航后增加局部遮光；Tension 的底部提示获得局部暗部承托。Space 使用 Canvas 的 `destination-out` 在小字与输入附近逐渐减弱曲线密度，为阅读留出空间；减少动态的静态声场使用相同处理。更新后的画面与控件经过复核，没有把整章图像统一压暗。

### 源码自动核验

最终源码的 `npm run verify` 已通过类型检查及 **9 组不变量检查**，覆盖 **27 个图像文件、3,650 个叙事映射取样、342 个绘制帧输入**。这些检查包括素材来源与路径、章节映射、反向定位、接触阶段、琴桥槽位注册和像素预算。绘制帧检查读取程序化 Canvas 指令，是确定性逻辑核验，不是 GPU 帧率测量。可在 Node 24 环境按 README 重复执行。

| 05 Tension | 四条实时弦线对齐保留图像中的琴桥槽位；收紧初始弧垂，使用琴桥遮挡轮廓处理前后关系，高光沿同一根弦移动。 |

| 08 Sound as Space | 同一琴体轮廓转为空间曲线装置；展开滑块控制开合程度，移动端减少曲线密度、重新安排中心位置，并局部减弱小字与输入周围的曲线。减少动态模式保留相同阅读空间。 |

## Web Audio：独立模块的实际信号

通过可信按钮手势启用未修改的 `src/audio.ts`，在最终输出前插入左右声道 analyser。每个状态读取 12 个时间窗口，每声道每窗口 512 个样本，窗口间隔 20 ms。所有 **20 项检查通过**。

| 状态 | 左 / 右声道 RMS | Master gain |
| --- | --- | ---: |
| First Bow 之前，已启用声音 | 0 / 0 | 0 |
| First Bow 中，无接触 | 0 / 0 | 0 |
| 首次接触 | 0.04913 / 0.05183 | 0.11985 |
| Resonance 盛放 | 0.07897 / 0.08861 | 0.18500 |
| Return 渐弱 | 0.02485 / 0.02520 | 0.06253 |
| Return 结束、反向回到接触之前、恢复到接触之前 | 均为 0 / 0 | 0 |
| Disable 释放完成 | 0 / 0 | 0 |

全部取样的最高绝对峰值为 **0.14417**。共读取 **208,896 个声道样本**，其中没有削波、NaN 或 Infinity。2,000 次连续 update 及再次启用后，仍只有一个 AudioContext、三个 oscillator 和一个噪声 buffer source；累计启动四个音源，没有持续增加。Dispose 关闭 context 并停止全部音源。模块检查没有浏览器异常、console error 或失败请求，源码前后哈希一致。

`frame.hidden` 驱动实际 AudioContext 挂起，音频时钟停止而用户选择保留；恢复后仅此前启用的用户继续输出。关闭之后隐藏再恢复，仍保持关闭。挂起时 analyser 与 `AudioParam.value` 可能保留最后一次渲染值，因此另行记录零增益调度，并确认恢复至接触前状态后的实时输出为零。

**范围：**这是独立模块信号检查，隐藏状态通过模块输入模拟；它不代表整站 `visibilitychange`、滚动同步或真实音频设备已经验证。Headless 输出静音，未通过实体扬声器或耳机试听，也不据此评价主观音色。声音为原创合成纹理，不是小提琴录音。

## 本地静态服务与最终生产构建

此前已用实际 HTTP 请求验证交付服务器：GET / HEAD、图像及字体 MIME、ETag 304、本机绑定、错误 Host 拒绝、写入方法拒绝、隐藏路径和目录穿越拒绝、越界符号链接拒绝、缺失资源 404。服务仅绑定 `127.0.0.1`。

最终源码自动核验与 `npm run build` 均成功。正式构建经交付的 `scripts/serve.mjs` 启动后，实际加载 HTML、字体、图片、主脚本与延迟三维模块；主要路径的 22 次请求未报告资源或 CSP 错误，生产页面没有开发诊断 API。构建配置显式启用 `emptyOutDir`；归档时再次按入口依赖图剔除过期哈希文件，交付中的 `dist` 只保留当前构建的 22 个文件。

主入口约 **169 kB**（gzip 约 **63 kB**），CSS 约 **31.6 kB**（gzip 约 **7.5 kB**），延迟三维模块约 **592 kB**（gzip 约 **152 kB**）。三维模块触发 Vite 默认 **500 kB** 分块体积提示；构建成功，该提示作为既知体积取舍记录。Three.js 按需加载，避免把完整三维模块加入开场主入口。

## 分辨率与未验证范围

主要 AI 图像母版为 **1672 × 941**，弓为单独的竖向透明素材。4K 画面会放大这些摄影式素材；DOM 文字、SVG 和 Canvas 系统依据视口重新布局与绘制，不能把这种缩放称为原生 4K 摄影细节。图像尺寸与处理关系见 [PROVENANCE.md](PROVENANCE.md)。

本记录没有实测实体手机、Safari、Firefox、不同显卡或真实触控硬件；没有证明真实 GPU 下稳定 60 fps，也没有进行屏幕阅读器完整审计。软件渲染的可见画面、控件状态和数值结果，仅支持上述明确写出的结论。
