## Verification limits and source integrity

- The camera numbers above are models, not physical GPU frame rates. Actual browser coverage used Linux Chromium141, DPR1 and ANGLE/SwiftShader. No real iOS Safari, Android touch hardware, native GPU or120/144Hz result is claimed. Event-driven CDP captures do not represent every display frame; software readback stretches requested input timing.
- The original3200px WebGL width cap is retained. CSS3840×2160 therefore uses a3200×1800 WebGL buffer, while DOM/layout/compositor screenshots retain the CSS viewport. This is an inherited limit, not a new precision reduction.
- The R6 original and resumed desktop recordings were interrupted; a later input-only phase saved45 checks/754 camera observations but no compositor frames. Their exact samples remain useful; they are not combined into a fictitious complete temporal recording.
- Regional Landsat and fine orthophotography differ in source date/resolution, visibly aroundp≈.598–.625. Registration and real coordinates remain intact. Uniform8m building heights, windows/night lighting, route observation and scale choreography are authored interpretations. Natural Earth `50m` means1:50,000,000 map scale, not50m raster resolution.
- The supplied archive is a compiled runtime without editable src/package. Readable source was reconstructed only after fixed-reference correspondence checks. Forty-five mapped static files and normalized HTML matched; all11 runtime bundles were not proved whole-program equivalent. Current23 geographic assets remain byte-identical. Earlier work/evidence lost in the workspace reset is disclosed in [RECONSTRUCTION.md](RECONSTRUCTION.md), not counted as fresh validation.
- Original notices retain a historical relative link to an absent supplied `PROVENANCE.json`; this package's root [SOURCE-PROVENANCE.json](SOURCE-PROVENANCE.json), font derivation and optics records are the current provenance authority. No source ZIP contains browser captures or debug evidence.

Relief and Orbit are the two accepted report comparisons: original uploaded native runtime versus actual frozen R9 1440×900 Quiet Motion frames. Their small actual progress differences are retained; Orbit's camera scale intentionally differs, and a still image is not proof of motion quality. The separate delivery report provides archive identity and independent extraction/install/test/build results. No public deployment or remote repository mutation was performed.
