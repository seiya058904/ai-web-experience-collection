# URUSHI — Collection architecture

The supplied eleven-chapter journey retains one persistent original elliptical lacquer vessel, authored shaders, bilingual copy and every original control. `pages/urushi/index.html` is an independent Vite document. `experiences/urushi/src/main.js` owns its sole animation frame; the lazy `LacquerRenderer` never starts a separate clock. Story state remains a pure function of measured document position, without an additional scene easing layer.

One Lenis instance uses interpolation 0.105, `syncTouch: false` and `autoRaf: false`. Reduced motion disables smooth wheel input, animated navigation and autonomous material/pointer time. Native dialogs retain their own scrolling and suspend background input. Resize measurements are queued on the existing frame, preserve actual chapter/local position and restore immediately. Fresh deep links land immediately in the authored composition. Each scene's measured `scroll-margin-top` gives native fragment navigation the same 16-percent chapter landing as the artwork's controls, so later browser anchor passes retain readable copy. This adjusts the anchor destination without changing section geometry, adding a clock or retrying scroll commands. Reload and history entries skip an explicit hash jump and retain the native browser's actual arbitrary reading position.

Visibility cancels the owned frame and aligns Lenis to the document on recovery. Persisted `pagehide` keeps the runtime for BFCache; terminal `pagehide` marks disposal, cancels its frame and destroys Lenis/renderer resources. Late imports, profile reads, sources and still callbacks cannot resurrect the disposed runtime. Renderer readiness draws the current document state before exposing the canvas. Failed WebGL initialization releases partial resources and retains the original eleven local chapter stills and readable narrative.

Runtime media, original models, texture, local fonts and notices live in `public/urushi/`. Latin Bodoni Moda and Manrope bytes came from the supplied `dist/assets/` because the package imports had no separate font files; only these independent font assets were imported from `dist`. The compiled application and duplicated public files were omitted. No package, lockfile, standalone server or build configuration was added.

The page owns its original stylesheet and the shared visible Collection exit. Its no-JavaScript summary retains a native text return link with an inherited font, so the shared compact mobile arrow rule cannot hide that separate fallback label.

`DESIGN.md`, `EXPERIENCE.md`, `research/` and `visual-bible/` preserve the supplied design/research identity and original prompts. Their original root-relative source paths describe the delivery; the corresponding scoped locations are recorded in `provenance/urushi/IMPORT.json`. Original README, PRODUCT, PROVENANCE, checksum manifest and read-only verification/export source records remain in that provenance boundary. `UPSTREAM-VALIDATION.md` is the supplied historical report, not current Collection acceptance.

The actual runtime and fallback images are original procedural renders. AI studies are design references only. Material values and the model's units remain artistic approximations; no measured lacquer BRDF, museum accession, scanner data or universal workshop recipe is claimed. There is no audio.

Graph tools were unavailable during intake (`Transport closed`), and this new source was not indexed. Architecture/security review therefore used actual source files and independent source/runtime audits, rather than graph-derived claims.
