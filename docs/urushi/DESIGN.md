# URUSHI — 视觉与动效设计

**Surface becoming depth.**

这件作品把注意力集中在同一只低矮椭圆漆盒的表面：木纹逐渐收拢，地层填平孔隙，
薄漆改变光的走向；研磨使倒影破碎，反复涂覆与抛光再让它连续。金粉直到后段才
获得重量。观众始终通过同一器形、同一道光，辨认表面发生了什么。

## 1. 创作选择

### 一个持续存在的物体

器物是为本作创建的低矮、封闭、带微拱盖面的椭圆形体。圆肩与细接缝为画面提供
尺度，也让极近裁切时仍能辨认出同一件东西。它没有对应某件馆藏、现实工坊产品
或某位艺术家的作品。

`public/models/vessel-profile.json` 保存轮廓，`src/geometry.js` 用同一轮廓生成
实时网格与模型导出。木纹、地层、涂覆前沿、研磨、朱色、金纹和研出遮罩都以
物体坐标为依据。章节变化不会替换网格，也不会把器物拆成零件。

### 一道持续改变的反射

长而柔和的环境反射是整段旅程的主要视觉线索。木胎阶段它弱而散；地层与漆膜
逐渐让光聚拢；湿磨暂时打断它；抛光让它重新连续。物体本身的大部分区域保持
暗色，让反射、边缘与极低对比度的次级光共同构成深度。

实时反射在 `lacquer.frag.glsl` 中由视线、法线与反射方向求值。环境包含一条
长窗形光源和更暗、更宽的墙面反射。其形状与粗糙度响应经过美术设计，是解析
着色近似，没有使用扫描得到的真实漆材 BRDF、现场测量的照明环境或光谱数据。

### 色彩按材料出现

界面基础黑为 `#0b0a09`，文字为暖象牙色 `#eee4d6`。材质使用棕黑、暗褐地层、
暖木纹与朱色，避免把整件器物照成灰色。朱色集中在既有形体的局部，在之后的
黑色中留下较弱的低部弧线。金色属于后段的金粉与曲线图案，不进入开场导航或
标题，也没有独立的发光效果。

## 2. 逐章材质变化

| 章节 | 实际表现 | 与下一幕的联系 |
| --- | --- | --- |
| **00 — Black without edge / 无边之黑** | 近乎隐没的黑色漆盒位于右侧，一道长反射显出盖面与肩部。没有金粉。 | 小幅反射移动之后，漆面退回木胎，开始回溯它的形成。 |
| **01 — Core / 木胎** | 同一形体显出暖木纹；地层前沿逐步降低纹理可见度，建立致密暗面。 | 保留轮廓与接缝，把变化集中在表面吸光与光泽。 |
| **02 — First coat / 初涂** | 薄而受控的漆膜边界横向推进，表面变暗，边缘短暂显出液态感。 | 反射开始聚拢，但表面尚有微弱扰动。 |
| **03 — Cure / 固化** | 场景稍微收拢，背景变暗，极弱的空气场与逐渐稳定的表面暗示荫室与等待。 | 固化进度由滚动控制；不需要真实等待若干小时。 |
| **04 — Abrade / 研磨** | 研磨遮罩沿表面推进，细痕与粗糙度上升，反射断开。 | 通过一次明确的“暂失光泽”，为再次涂覆建立理由。 |
| **05 — Layers / 层积** | 三次压缩的涂覆、固化、研磨节律改变光泽；肩部短暂出现放大的层次示意。 | 剖面仍属于同一表面；随后回到完整曲面。 |
| **06 — Vermilion / 朱** | 浓而克制的朱色出现在局部漆面，沿用同一道反射。 | 颜色收束后，观众重新注意表面如何获得清晰倒影。 |
| **07 — Polish / 抛光** | 细痕和粗糙度逐渐退去，长反射由断续转为完整。相机变化很小。 | 文案称 **A first clarity / 初次清晰**，并未宣告工序全部结束。 |
| **08 — Maki-e / 莳绘** | 有限的金粉接近漆绘区域，表面逐步留下三条细弧线及少量周边粉点。 | 飘落表现完成后，由固定在物体坐标中的金纹继续承担画面。 |
| **09 — Reveal / 研出** | 新漆遮罩盖住金纹；随后移动的研磨边界让图案再次显现，光泽同时恢复。 | 通过局部遮蔽和显露建立第二次高潮。 |
| **10 — Depth / 深处** | 构图回到完整器物；黑面、连续反射与稀疏金纹共同收尾。 | 观众可用滑块移动光线，也可以回到开场。 |

详细章节文案和状态曲线以 `src/story.js` 为准。

## 3. 实际视觉系统

| 系统 | 实现位置 | 职责与边界 |
| --- | --- | --- |
| 持续器形 | `src/geometry.js`、`public/models/vessel-profile.json` | 原创轮廓采样、法线、封闭网格与表面位置求值；单位是艺术单位。 |
| 表面微结构 | `src/material-textures.js` | 固定种子生成材料噪声场；没有使用木材或文物摄影扫描。 |
| 漆、木、地、朱与反射 | `src/shaders/lacquer.frag.glsl` | 局部颜色、微法线、粗糙度、非金属 Fresnel 近似、涂覆与研磨遮罩共同变化。 |
| 荫室空气 | `src/shaders/background.frag.glsl` | 用极低强度的背景场暗示封闭与静候，不计算真实湿气传播。 |
| 附近的地面 | `src/shaders/floor.frag.glsl` | 提供受控接触阴影与微弱反光，是构图性的近似。 |
| 金粉接近 | `src/renderer.js`、`src/shaders/gold.*.glsl` | 固定数量、固定到达顺序的短距离粉点运动；不做流体、碰撞或空气动力学求解。 |
| 金纹与研出 | `src/shaders/lacquer.frag.glsl` | 独立金属色反射响应，以及依次涂覆、遮蔽、研出的物体空间遮罩。 |
| 故事状态 | `src/story.js` | 从位置直接求值，不依赖曾经滚过哪些章节或已等待多久。 |
| 滚动与界面 | `src/main.js`、`src/style.css` | 单一滚动权威、章节导航、语言、动态偏好、键盘交互与降级显示。 |

着色器里的湿度、时间、粗糙度、层数和粉末大小用于控制视觉，不是工坊测量、
材料参数数据库或施工配方。层积剖面是放大示意；真实漆膜厚度没有被据此标定。

## 4. 滚动、连续性与交互

Lenis 是唯一平滑滚动实现。页面从实际滚动位置计算章节位置，再直接调用
`getStoryState(position)`；渲染器不会对故事进度追加第二次缓动。输入因此能
立即改变涂覆、反射与研磨，画面仍可通过短距离运动保持耐心的节奏。

状态只由位置决定，纹理与粉末到达序列采用固定种子。正向、倒退、目录跳章与
尺寸变化使用同一套求值逻辑，金粉不会因为观众看过后段而残留在木胎或开场。
主画面的章内编排遵循进入、稳定构图、材质停留、交接与退出；文字的出现和
离开从属于材质事件。

指针只轻微改变光的方向，不改变章节进度。结尾的光线滑块也支持键盘操作。
Index 提供逐章进入；About 提供作品说明、真实来源与完整文本阅读。语言和
动态偏好保存在当前浏览器，没有账号、追踪或远程内容更新要求。

## 5. 排版与不同屏幕

桌面将叙事放在左侧负空间，把器物放大到画面右部；接近表面时，器物可自然超出
视口。手机使用同一器形的肩部、接缝和反射裁切，文字移到上部，避免把整个对象
缩成小型商品图。横屏、窄屏、中文标题和较低高度另有排版规则。

英文标题使用 Bodoni Moda，正文与控件使用 Manrope。中文使用本地 Noto Serif SC
子集，文件内部家族名为 **URUSHI CJK**；子集保留本站所需字形，具体来源、字符
范围与修改记录见 `public/assets/fonts/urushi-cjk.provenance.json`。所有运行字体
随包自托管。

减弱动态遵循系统偏好，也可在目录中主动切换。它关闭平滑滚动、指针跟随与
自主材质时间变化，同时保留全部章节。没有 WebGL 或渲染失败时，使用同一
原创渲染器生成的章节静帧与文本；静帧版不声称具有连续的材质交互。

实时绘制对 DPR、像素预算和可见粉点数量设上限。网格和纹理被复用，页面隐藏
时停止动画帧请求；资源销毁与 WebGL 上下文丢失也有处理。性能目标服务于材质
可读性，具体测试结果与设备边界见最终验收记录。

## 6. 研究事实与艺术压缩

| 采用的事实 | 作品如何使用 | 依据 |
| --- | --- | --- |
| 漆树液可用于直接涂覆，也可施于准备好的地层。工艺存在不同方法。 | 选择带地层的木胎作为本作叙事，不声称所有漆器必须相同。 | [Japan Kogei Association](https://www.nihonkogeikai.or.jp/en/urushiwork/) |
| 漆膜硬化包含漆酶参与的氧化与聚合，并受湿度和氧气等因素影响。 | 以荫室氛围和表面稳定表达固化；时间被滚动压缩。 | [Kenjo, 1973, J-STAGE](https://www.jstage.jst.go.jp/article/shikizai1937/46/7/46_419/_article/-char/en) |
| 木炭湿磨与反复擦漆、细磨可以形成呂色光泽。 | 镜面为 **roiro-inspired**；研磨必须先破坏反射，再恢复清晰。 | [轮岛漆艺美术馆](https://www.art.city.wajima.ishikawa.jp/exhibition-guide/gl-en)；[Japan Artisan Foundation](https://artisanfoundation.jp/wajima/articles/roiro) |
| 研出蒔绘存在覆漆后以炭研磨显出图案的过程。 | 后段用局部移动遮罩完成覆盖与显露；前段 Polish 只是一次表面整理。 | [e-Museum / 京都国立博物馆](https://emuseum.nich.go.jp/detail?content_base_id=101134&content_part_id=022&content_pict_id=0&langId=en&webView=0) |

梨地被纳入视觉研究，用于理解金属粉与半透明漆的关系；最终黑漆主体没有铺满
梨地颗粒，也没有把这种做法等同于所有莳绘。真实工艺的更多来源与区别见
`docs/research/RESEARCH.md`。

确定构图、材料与章节情绪。实时旅程由程序化模型、纹理与 GLSL 生成；没有把

研究；最终生产海报 `surface-black.webp` 与章节降级静帧均来自同一实时渲染器，
