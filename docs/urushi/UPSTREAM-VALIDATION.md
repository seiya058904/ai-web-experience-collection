## 材质与时间线

检查点覆盖全部 11 章，并额外比较抛光开始／结束、金纹遮蔽／研出等中间状态。

| 要求 | 核对方式与结果 |
| --- | --- |
| 同一件器物 | 全程复用相同网格、轮廓、接缝与物体坐标。没有按章换模型。 |
| 黑色具有层次 | 对照主反射、后缘掠射光、下腹弱环境倒影与低对比背景；避免整件器物变灰。 |
| 受控薄涂 | 漆膜以物体坐标中的局部前沿推进，未使用倾倒、瀑布或全屏色彩覆盖。 |
| 湿度固化 | 暗室、静候与表面稳定构成一章；没有日晒干燥的表现。 |
| 研磨造成“倒退” | 研磨前沿提高粗糙度，打断长反射；其后抛光使反射恢复连续。 |
| 层积 | 三次压缩节律和短暂的薄层示意均可到达，随后返回同一曲面。 |
| 朱色是一次转调 | 桌面和手机均能看见浓朱色进入局部曲面；手机保留黑色左肩。 |
| 金粉晚出现 | `phase <= 8.03` 时金色参数严格为零；抛光恢复先于金粉沉积。 |
| 金属于表面 | 金粉数量有限、到达顺序固定，三条细弧线与物体坐标绑定，无发光和爆炸。 |
| 覆盖与研出 | 图案被局部覆漆遮罩遮住，再由移动的研磨边界显露；不是整张图淡入。 |
| 来回滚动 | 状态是位置的纯函数。任意跳章和逆向滚动不保留之前的粉末、涂层或磨痕历史。 |

固定时间、指针与光照参数后，桌面和手机的“开场 → 后段 → 开场”截图逐字节一致。
4K 返回画面的器物区域像素一致；整张截图仅有 81 个文字抗锯齿像素出现单级差异，
不据此声称跨字体栅格器或跨 GPU 的截图必然完全相同。

网格包含 24,511 个顶点与 48,000 个三角形。顶点、法线数值有限，索引没有越界，
法线长度的最大误差低于 `1e-7`。模型和纹理已通过 `npm run model` 从同源定义导出。

## 视觉对照与已处理的问题

对照基线为 `docs/visual-bible/01-hero.png`，并结合各章材质研究和真实运行画面。

| 视觉要点 | 最终处理 |
| --- | --- |
| 开场层级 | 保留左上字标、右上 Index / About、左侧三行主标题与右侧巨大器物。 |
| 字体与留白 | Bodoni Moda 与 Manrope 本地加载；1672 × 941 下，主标题约 95.3 px，副文案约 22.6 px。 |
| 后续章节标题 | Core、Cure、Layers 的长标题原本压到曲面；收小标题并限制文字栏后，均与器物分开。 |
| 黑漆长反射 | 将均匀灰带修成外沿较明确、内侧柔和衰减的光源形状；左端较亮，右端收窄淡出。 |
| 暗部体积 | 用后缘微光和宽弱墙面倒影保留曲率，消除腹部孤立的灰色刷痕。 |
| 研磨纹理 | 减少高频采样造成的摩尔点阵，保留细磨与失光的差异。 |
| 金纹线宽 | 改用切平面梯度换算曲面距离，避免金纹在平顶处扩大成三角形；进入平顶前逐渐收束。 |
| 手机朱色 | 扩展同一曲面中的着色范围，让朱色进入手机可见裁切；没有给手机换成另一件器物。 |
| 平板构图 | 窄横屏为器物提供额外横向空间；竖向平板使用完整竖屏取景，使反射位于文案以下。 |
| 加载连续性 | 加载海报与实时开场来自同一渲染器，避免概念图与模型之间的轮廓跳变。 |
| 中文 | 补入本地 URUSHI CJK 子集，覆盖四份界面源中的 393 个所需字符码点；调整手机关于标题，去掉孤行。 |

参考图提供的是构图与材料目标。实时器物、反射、木纹和金纹由原创网格与着色器
构成，不声称逐像素复现生成照片，也没有采用实测漆材的光谱或 BRDF 数据。

## 交互、后备与本地启动

已验证目录跳章、原生弹窗的 Escape 关闭和焦点恢复、结尾光线滑块的键盘操作、
重播、语言偏好、动态偏好，以及改变视口尺寸后保留所在章节。

手机无 WebGL 时，11 张本地章节静帧可以顺序切换，中文完整阅读和重播可用；
不能改变静帧的光线滑块会隐藏。WebGL 上下文丢失后转入静帧，恢复后重新使用
实时渲染。减弱动态关闭平滑滚动、指针跟随与自主材质时间变化，保留全部章节。

生产静帧使用 1440 × 900、时间 0、居中指针与光照 0.5 捕获，采用无损 WebP。
`public/assets/stills/provenance.json` 记录逐帧参数、文件 SHA-256，以及 13 个
渲染源文件的 SHA-256；初始海报与 `hero.webp` 完全一致。

最终验收还通过随包的 `scripts/serve.mjs` 实际启动 `dist/`，修正了根目录尾部
分隔符导致正常资源被拒绝的问题。修复后两次独立生产入口验证均成功，模型、
字体、动态模块与静帧的 HTTP 状态和 MIME 正确。预览服务器只监听本机回环地址。

## 实际限制

本次没有进行 Safari、Firefox、iOS 真机或真实 GPU 的帧率、功耗认证。软件 WebGL
用于验证渲染正确性；不能把其运行结果当成手机硬件性能成绩。不同显示器的黑位、
环境亮度与色彩管理也会影响暗部可见程度。

漆层、固化、研磨和金粉使用为视觉叙事编写的近似。时间、厚度和粒径经过压缩或
放大，不属于材料实验或通用制作配方。工艺事实和引用见 `research/RESEARCH.md`。

一次性测试页面、校准截图、调试脚本和被拒绝的图像草稿不进入交付包。保留的
`scripts/check-delivery.mjs` 是可复用的交付检查入口。成品仅作为本地 ZIP 提供，
没有部署到 OpenAI Sites 或任何公共托管服务。
