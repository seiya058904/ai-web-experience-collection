# SILICON — From Sand to Signal

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The brief delegates the implementation mix: Lenis, GSAP / ScrollTrigger, Canvas, SVG and WebGL where they serve the scenes. The implementation uses a local Vite / TypeScript project with one Three.js stage. No service accounts, hosted dependencies at runtime or deployment are required.

## Product Purpose

A continuous, scroll-controlled digital exhibition: material becomes wafer, pattern becomes structure, structures connect, a package assembles and an electrical signal travels through it. The visitor experiences the manufacturing narrative through original geometry, cutaways and light choreography.

## Users

The commissioned audience is a visitor exploring an immersive semiconductor design showcase on desktop or mobile. The user explicitly requires 1080p, 1440p, 4K and mobile compositions.

## Capabilities and Constraints

- Eight scenes: Material, Pattern, Build, Transistor, Interconnect, Package, Signal, Silicon.
- Every major scene has its own code-built visual system and enter / stable composition / living hold / handoff / exit lifecycle.
- Scroll direction must be reversible. Fast navigation, resize and tab restoration must preserve scene state.
- Scientific sources inform visual simplifications. This is an illustrative composite, not a foundry process recipe or a drawing to scale.
- Local ZIP only, including source, dependencies manifest / lockfile, all runtime resources, README, licenses and a current production build. Do not deploy or register a site.
- No shop, corporate site, encyclopaedia, generic image sections or HUD dashboard aesthetic.

## Brand Commitments

SILICON — From Sand to Signal. Precise, layered, luminous, engineered, microscopic, cinematic, authored, alive. Dark exhibition space, wafer iridescence, silicon and silver, restrained copper and optical violet. English exhibit copy follows the supplied title and chapter system; documentation includes Chinese setup instructions.

## Accessibility & Inclusion

Keyboard-operable navigation and inspection controls, reduced-motion mode, useful non-WebGL fallback, semantic narrative text and high contrast controls. Motion is silent and user-controlled.
