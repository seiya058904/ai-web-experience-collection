# THRUST — Anatomy of a Jet Engine

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose

A continuous, scroll-controlled journey following air through one original high-bypass turbofan. The machine, airflow and energy transfer are the experience. This is neither a commercial engine catalogue nor an encyclopedia.

## Confirmed brief

Ten beats: intake, fan, bypass, compression, combustion, turbine, blade, machine, thrust, flight. Preserve an internally consistent shaft and flow architecture, distinct cold bypass and hot core streams, rotor/stator rhythm, annular combustion, cooling detail and a directed exploded assembly. Major scenes have enter, stable composition, living hold, handoff and exit.

## Delivery

One standalone ZIP containing source, production assets, build configuration, README, attribution, licences and provenance. No deployment, hosted preview, account registration or publication. Exclude dependencies, caches and test capture debris. Verify a clean extraction can install, build and run.

## Implementation decisions

The brief explicitly delegates rendering choices. Use a small Vite application with Three.js and native DOM/CSS, original procedural meshes and shader-driven flow. English exhibition copy follows the supplied English titles. Documentation includes Chinese setup instructions. These are implementation choices, not claims about an existing product.

## Accessibility and operation

Keyboard navigation, visible focus, motion pause, native scrolling, reduced-motion support, responsive mobile compositions, context-loss recovery and no automatic audio. Support desktop 1080p/1440p/4K and purpose-designed mobile framing. Performance figures must be measured, never claimed from intent.

## Engineering truth

Original schematic direct-drive twin-spool engine, not a manufacturer replica or engineering simulation. NASA primary references ground topology and qualitative physics. Any display values are explicitly illustrative. The hot section is controlled combustion, not an afterburner. Compressor bleed supplies blade cooling.
