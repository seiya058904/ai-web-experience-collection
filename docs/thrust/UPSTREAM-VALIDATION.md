### 页面生命周期的可验证边界

发出 CDP 冻结 / 恢复命令并将页面带回前台后，渲染恢复。此 headless 环境切到另一个标签时，原页的 `document.hidden` 仍为 false，且没有收到真实 `freeze` / `resume` 事件。因此这项结果不等同于实体电脑最小化、操作系统休眠或手机后台恢复已经实机通过。

代码处理 `visibilitychange`、`pagehide`、`pageshow` 和支持时的 `freeze` / `resume`，离开时停止计时和音频，返回时重置时钟。事件选择参考 Chrome 的 [Page Lifecycle API](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)。

## 视觉复核与取舍

最终浏览器画面与 Intake、Compression、Combustion、Blade、Machine、Flight 六张内部构图研究进行对照。这些研究用于确立光色、布局和镜头气质，未作为经用户确认的工程模型。验收以原始需求、同一台机器的连续性和工程参考为准。

| 对照点 | 最终实现与复核结果 |
|---|---|
| Intake：巨大入口与左侧标题 | 保留右侧占主体的进气口、左侧大标题和稀疏冷色气流；收紧标题尺寸，避免与入口轮廓拥挤。22 枚原创后掠叶片替代概念图中不可复用的随机几何。 |
| Compression：向内推进的轴向秩序 | 摄像机沿打开的压气机走廊掠入，能辨认重复的转子 / 定子和逐级变化；修正了初版前景叶片遮挡。镜头位置与概念图不同，以实际模型中的有效视线为准。 |
| Combustion：受控暖色 | 保留冷端到热端的转变，将过亮的粉橙色内衬改成深色金属；18 处喷射位置产生受限火焰和下游热流。没有使用概念图里的照片式满屏大火。 |
| Blade：尺度反转 | 独立原创翼型、孔口、三段折返冷却通道和可关闭剖切形成真实可交互微距；与整机内 HPT 的位置关联。保留左侧标题和右侧冷却结构，几何细节采用自身模型。 |
