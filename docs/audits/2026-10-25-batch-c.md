## T08 有界实验：关闭，不采用

仅在仓库外向 CHRONOS / LUTHIER 注入跨文档 View Transition，使用双方名称与各自背景，180ms 时长，保持原生链接。实施依据是 Chrome 的 [cross-document View Transitions 官方说明](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document)。正式源码没有加入试验代码。

结论为 **NOT_ADOPTED**：收益不足且存在异常边界，按 T08 允许的关闭路径收束。真正不支持该 API 的另一浏览器未运行；禁用 opt-in 的回退检查不冒充另一浏览器验证。
