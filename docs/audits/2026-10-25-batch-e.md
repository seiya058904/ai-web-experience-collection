# Batch E — five supplied websites, integration and review

Date: 25 October 2026. Scope: `RELAY_Source.zip`, `SUPERCELL_Complete_Source.zip`, `PELAGIC_Source.zip`, `BACKSTAGE_Source.zip`, `MURMURATION_Source.zip` — integrated as `/relay/`, `/supercell/`, `/pelagic/`, `/backstage/` and `/murmuration/`.

## Method

Inventory before extraction (bytes, SHA-256, entry count, modification time, traversal, nested archives, `dist/`, lockfiles, startup scripts, licence records) → extract outside the repository → audit source, assets and claims → choose the smallest import boundary (`experiences/<route>/`, `pages/<route>/`, `public/<route>/`, `docs/<route>/`, `provenance/<route>/`) → register route and identity → verify. Per-work records: `docs/<route>/{DESIGN,ARCHITECTURE,RESEARCH,ACCEPTANCE}.md`, `provenance/<route>/{IMPORT.json,upstream/}`.

All five: one expected top-level directory, no traversal or absolute paths, no nested archives, supplied licence or generation records present. ZIP hashes and every entry hash are in `provenance/deliveries/import-manifest.json` and `provenance/<route>/IMPORT.json`.

## Findings and decisions

| # | Kind | Work | Finding | Action |
| --- | --- | --- | --- | --- |
| 1 | Real layout defect | BACKSTAGE | The single-column stage grid sized itself from its widest row: at 390–424px the masthead clipped “Call the cue” and the five-act footer lost its last items (measured 400px content inside a 342px box). | Fixed in `pages/backstage/index.html` with a shrinkable grid track and a compact masthead below 520px. No overflow at 320/360/390/425/768/1024/1440/1920/2560px. |
| 2 | Portability defect | MURMURATION | `renderer.js` loaded the sky via `new URL('../public/sky.webp', import.meta.url)` — a source-tree path that cannot survive another output layout or base. | Replaced with a base-aware `import.meta.env.BASE_URL` URL; the recording fetch was namespaced the same way. |
| 3 | Portability constraint | RELAY, SUPERCELL, PELAGIC, BACKSTAGE | Stylesheets used origin-root URLs (`/fonts/`, `/assets/`); PELAGIC and MURMURATION resolved art and data from their own app root. | Rewritten into each route's namespace so the project-path deployment serves them. |
| 4 | Test hygiene | RELAY, MURMURATION | Model suites wrote evidence files next to themselves; MURMURATION's propagation check read an upstream QA artefact. | Ported suites are read-only; the propagation check stays upstream and is recorded as not ported. |
| 5 | Documented limitation | RELAY | The delivery's own `KNOWN-LIMITATIONS.md` records three noncritical FAILs for forced inline font-size scaling (125/150/200% overrides). Native browser zoom passed upstream. | Not re-run; carried into the acceptance limits instead of being claimed as fixed. |
| 6 | Dead asset | PELAGIC | `public/art/first-frame.webp` (25 KB) is listed in the supplied manifest but never requested; the first frame is an inline SVG. | Kept unchanged and documented rather than deleting supplied artwork. |
| 7 | Evidence weight | all five | 27–46 MB of QA screenshots, videos and design-reference rasters per delivery. | Not imported; entry hashes and the omission are recorded in provenance. |
| 8 | Dependency drift | all five | Each pins its own Vite/TypeScript/Playwright versions and Lenis 1.3.27 against the locked 1.3.26. | Root lockfile reused, no dependency change; the Lenis difference is documented per work. |
| 9 | Notice gap | BACKSTAGE | Font licences shipped, but no separate Three.js/Lenis notices. | MIT notices added from identical existing Collection copies and recorded in `public/backstage/licenses/` and the notice. |

## Collection changes

- Five independent documents and routes, sitemap entries and build identities; the shared return control sits inside each work's existing navigation without displacing supplied controls.
- Entrances 33–37 with interface-cleaned captures of the running works, 640/960/1280 WebP previews, a native Index row each and a sixth README table.
- New homepage font requests: only Anton and Source Sans 3. Archivo, Manrope Variable, DM Sans, Cormorant Garamond, the Cormorant italic and Fraunces reuse existing URLs whose binaries are byte-identical.
- Records updated together: `pages/index.html`, `collection/styles.css`, `pages/credits.html`, `README.md`, `PRODUCT.md`, `AGENTS.md`, `ATTRIBUTION.md`, `docs/collection/DESIGN.md`, `package.json`, `public/licenses.txt`, `vite.config.ts`, `scripts/verify-build.mjs`, `tests/collection-index.test.mjs`, `provenance/deliveries/import-manifest.json`, `provenance/collection/responsive-previews.json`.
- Nine ported suites: RELAY model; SUPERCELL field and volume; PELAGIC state; BACKSTAGE state, geometry and clearance; MURMURATION model.

## Verification actually run

- `npm test`: **451 passing, 0 failing**.
- `npm run build` + `npm run verify:build`: passed at `/`, then at `--base=/ai-web-experience-collection/` (1232 HTML/CSS asset references resolved).
- Chromium 1248, project-path preview: five routes at 1440×900 and 390×844 with no console error, page error, failed request or 4xx; local fonts loaded; no horizontal overflow; direct load, reload and return-to-Collection (hash + focus) verified per route.
- Primary controls in production: RELAY delivery play/pause; SUPERCELL index dialog; PELAGIC observation advance; BACKSTAGE scene/view/light cues (NIGHT → SEA, slider value text); MURMURATION live-field Hold → Resume.
- Reduced-motion contexts at 1440×900 for all five: no errors, no overflow.
- Home: 38 world links, 37 Index rows, “THIRTY-SEVEN WORLDS · ONE COLLECTION”, five new entrances, no console errors.

## Remaining risks

- Physical touch, iOS Safari, Firefox, high-refresh hardware and screen readers were not tested.
- Real background-tab suspension was not re-verified for these routes; RELAY claims it upstream.
- SUPERCELL's synthesized wind, MURMURATION's fieldprint download and BACKSTAGE's `?static=1` edition were kept available but not exercised as files beyond the reading path.
- The gallery grew from 32 to 37 entrances. It was reviewed at 390, 900, 1440, 1600 and 2560px (contact sheet inspected at 2560, where the right-hand cue labels appear); 3840px was checked for overflow only, not frame by frame.
