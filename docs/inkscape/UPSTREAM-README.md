# INKSCAPE — Paper, Water, Ink

一件可以用滚动展开的数字艺术作品：清水形成边界，墨进入纤维，笔触穿过留白，纸面最终展开为空间。

作品由八个连续的材料章节组成。六张专门生成的材质图像提供细节；Canvas、SVG、纸面几何和滚动控制共同生成水缘、墨晕、笔毫、纤维、折叠与印记。画面行为是艺术性的材料解释，不是经过实验标定的流体或宣纸物理模拟。网站界面以英文呈现。

## 直接运行随包成品

需要 **Node.js 22.12.0 或更高版本**。ZIP 已包含生产构建 `dist/`。

在项目根目录打开终端：

```bash
npm run serve
```

也可以直接使用 Node，无须安装任何项目依赖：

```bash
node scripts/serve-built.mjs
```

然后打开 **http://127.0.0.1:4173**。Windows 也可以双击根目录的 **`START-PREVIEW.cmd`** 启动本地预览。结束时在终端按 `Ctrl+C`。

运行随包成品不需要 `npm install`、账户、API Key 或互联网连接。请通过本地 HTTP 服务访问；直接双击 `index.html` 或 `dist/index.html` 使用 `file://` 打开，会受到浏览器 ES module 与资源加载规则限制。

## 开发、构建与预览

第一次安装开发依赖需要网络。在项目根目录执行：

```bash
npm ci
npm run dev
```

开发地址为 **http://127.0.0.1:5173**。

重新生成成品：

```bash
npm run build
```

构建结果写入 `dist/`。预览刚生成的生产构建：

```bash
npm run preview
```

预览地址为 **http://127.0.0.1:4173**。`npm run serve` 和 `npm run preview` 使用同一端口，请先停止其中一个再启动另一个。

`package-lock.json` 锁定开发与构建依赖。修改源代码后需要重新运行 `npm run build`，随包的 `dist/` 才会更新。

## 如何体验

滚轮、触控板或触摸滚动控制材料的演变；在任意位置停下可以观察完整构图。章节目录与页脚箭头提供直接移动方式。

| 操作 | 作用 |
| --- | --- |
| 顶部 **Index**、左下章节名称 | 打开八章目录；选择章节直接进入 |
| 右侧章节刻度、页脚左右箭头 | 在章节之间移动 |
| `←` / `→` | 页面主体处于键盘操作状态时，进入上一章 / 下一章 |
| `Home` / `End` | 进入第一章 / 最后一章 |
| `↑` / `↓`、`Page Up` / `Page Down`、空格 | 沿用浏览器的滚动操作 |
| `Tab` / `Shift+Tab` | 在可用链接、按钮和控件之间移动焦点 |
| `Esc` | 关闭 Index 或 About 对话框 |
| **INK — Add a drop** | 加入一滴墨；Water、Ink 的画面空白处也可以点击或轻触 |
| **TRACE — Dry / Wet** | 调整 0–100 的笔触湿度，观察干笔裂隙与湿润边界的变化 |
| **FIBER — Look closer / Step back** | 切换纤维的放大程度；移动指针可探索材质 |
| **MARK — Make your mark** | 留下朱色几何印记；启用后可在该章画面空白处继续盖印 |
| **Clear marks** | 清除当前印记 |
| **Still mode / Motion on** | 在安静的静态构图模式与流动模式之间切换 |
| **Begin again** | 返回开篇 |

章节快捷键不会接管已聚焦的按钮、链接或输入控件；滑杆聚焦时，方向键保留调整数值的原生作用。目录和 About 使用原生对话框，打开时焦点保持在对话框内。

个人印记最多同时保留六枚，继续盖印会替换最早的一枚；印记会进入终章。湿度、放大状态、印记和手动动效选择仅保存在当前页面内存中，不写入 `localStorage`、`sessionStorage` 或服务器。刷新页面会重新开始这些状态。章节链接使用 URL hash，支持浏览器后退、前进。浏览器自身的 `history.state` 只记录旅程的相对进度，以便刷新、返回及动效模式引起滚动长度变化后仍能回到原位置；其中不保存个人印记或交互偏好。

初次进入时遵循系统的 `prefers-reduced-motion`。Still mode 使用更短的滚动行程、直接滚动与静态材料构图；交互控件仍可操作。

## 八个章节的视觉系统

| 章节 | 网页生成的核心视觉 |
| --- | --- |
| **01 — WATER** | 不规则水分边界、多层淡水痕与指针扰动，清水逐渐接上墨色 |
| **02 — INK** | 毛细轮廓、墨粒沉淀和可追加的墨滴，生成图像与程序边缘共同参与扩散 |
| **03 — PAPER** | 三张独立的薄纸平面，层间分离、倾斜、折起与受控投影 |
| **04 — TRACE** | 沿笔势推进的揭示路径、干湿材质混合、笔毫裂隙和吸水边缘 |
| **05 — FIBER** | 带固定种子的纤维几何、细节层与可操作的材质放大镜 |
| **06 — SPACE** | 带铰接关系的纸面、透视和折线，展开形成留白空间 |
| **07 — MARK** | 竖向干笔材质、程序笔痕、原创几何朱印与访客印记放置系统 |
| **08 — INKSCAPE** | 纸层、墨迹、纤维和访客印记的重组，形成完整终章构图 |

场景按 **Enter → Stable Composition → Living Hold → Handoff → Exit** 组织。滚动决定场景进度；时间只为稳定画面增加细微的材料运动。一个 sticky 舞台承接整段旅程，Lenis 与 GSAP 共用动画时钟，Canvas 和纸面层分别负责材料与空间表现。

移动端使用独立构图规则：文字与材料上下分配，调整裁切、纸层布局与交接节奏。Canvas 限制像素预算，并控制昂贵场景的活动数量。无 JavaScript 时，HTML 中的章节文字仍可阅读。
