# INKSCAPE — Paper, Water, Ink

An immersive digital artwork commissioned by the user. A single evolving sheet of xuan-inspired paper carries water, ink, fibers, brush traces, folds, negative space, and a final seal impression. The visitor scrolls to make materials evolve, and can make a personal ink trace.

## Audience and experience

Art and digital-design audiences on desktop and mobile. The work itself leads; navigation recedes. Success means coherent, tactile, quiet but striking compositions with continuous reversible material-driven motion. No commerce, educational encyclopedia, traditional ornament template, or image slideshow.

## User commitments

- Warm ivory, carbon ink, diluted greys, a controlled vermilion seal accent.
- Eight material chapters: Water, Ink, Paper, Trace, Fiber, Space, Mark, Inkscape.
- Each has an authored visual system, a stable composition, a living hold, and a material handoff.
- High-quality original generated texture/photographic assets supplement real code-driven visual systems.
- Desktop 1080p, 1440p, 4K and mobile need deliberate layouts; reduced-motion support.
- Mature scroll stack; dependable reverse/rapid scrolling, resize, restore, touch and keyboard behavior.
- Final delivery is only a clean, complete, runnable ZIP with source, assets, configuration, build, README and attribution/license.
- No publication, hosting registration, OpenAI preview page or external repository actions.

## Platform

Browser frontend, Vite + JavaScript modules, CSS, Canvas/SVG and GSAP/Lenis. No backend, account, remote API, or user data submission.
