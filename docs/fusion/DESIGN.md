# FUSION — Design & implementation

## 核心对象

整站把同一台反应堆作为连续叙事的主体。滚动改变相机、外壳、磁场、等离子体与控制状态；章节文字提供短暂解释，结构本身完成主要视觉表达。

贯穿全程的对象是环形腔体、D 形线圈、磁场路径、受约束粒子、能量脉冲、剖面和仪表轨迹。结构露出、后退、升温和重新稳定时，这些对象保持空间关联。没有图片章节，也没有用预渲染影片替代主要交互。

## 视觉语言

深石墨背景与暖白排版建立安静的外部空间。金属使用石墨、钛灰、铜色绕组和深色紧固件；冷蓝与紫色描述场和控制，橙白表现高能核心。发光集中在反应堆内，保留大面积低亮度区域供眼睛停留。

### 字体与构图

**Manrope Variable** 用于标题和说明，以可变字重、紧凑字距和宽阔留白构成主要节奏。**IBM Plex Mono 400** 用于编号、仪表、单位与工程标记。两个字体均为随包的 Latin WOFF2 文件。

桌面把主要文字放在左侧，将反应堆重心置于右侧；导航和仪表退到画面边缘。视口变大时同步放大字级、间距与结构细节，而不是在 4K 屏幕中央放置一个固定宽度的小网页。版面不依赖照片的裁切维持构图。

## 八章视觉系统与交接

| 章节 | 自建视觉系统 | 完整画面中的持续运动 | 向下一幕的交接 |
| --- | --- | --- | --- |
| Ignition | 低能电流、可辨认的机械环和初始光路。 | 环内粒子和脉冲维持轻微流动。 | 结构从整体轮廓变为可拆解组件。 |
| The machine | 18 个 D 形线圈站位、分段真空室、中央结构、极向环与下部组件。 | 场和等离子体在机械层内部继续运行。 | 剖面打开，实体层减弱，磁场成为主体。 |
| Confinement | 三组独立磁场路径与环面上的方向性流动。 | 磁场信号沿选定路径传播，粒子保持约束关系。 | 视线靠近等离子体，场线让位给温度与发光层。 |
| Plasma | 参数化等离子体曲面、多层 GLSL 发光、细丝与加热响应。 | 亮度呼吸、细丝流动、同步温度变化。 | 升温后的完整环面逐渐出现边界波动。 |
| Instability | 协调的边界位移、扰动脉冲与 Canvas 诊断波形。 | 波动和读数持续变化；额外扰动会增强偏差。 | 参考包络与控制提示进入同一空间。 |
| Control | 目标包络、反馈参数、趋稳的等离子体边界与诊断曲线。 | 控制状态持续调节波动；可手动解除与接回反馈。 | 系统恢复秩序，聚焦稳定的发光核心。 |
| Star | 高亮的受控环、粒子流、D–T 反应表达与平衡标记。 | 稳定状态仍有内部运动和微弱能量调制。 | 相机后退，工程装置再次成为整体。 |
| Future | 重新聚合的反应堆与 SVG 热能路径网络。 | 光脉冲沿能量路径传播。 | 保留最终完整构图，并可返回点火场景。 |

每章遵循 **Enter → Stable Composition → Living Hold → Handoff → Exit**。关键构图占据章节中段，前后用于交接；不是滚动刚进入便立即退出。Hold 中维持粒子、场、微弱镜头和数据运动，滚动也会继续改变轻微的镜头深度。

## 状态与滚动契约

`src/timeline.ts` 将滚动范围归一化为 `p ∈ [0, 8]`。`deriveState(p, time, controls)` 是共享状态计算：能量、热、场、结构、剖面、失稳和反馈从相同输入得到，仪表与主视觉读取同一状态。

固定 `p`、`time` 和控件输入时，得到相同结果。章节姿态按 `p` 插值，反向滚动直接回到对应构图；粒子的生命运动仍按共享时间前进。用户控件有意保留其当前选择，不会因为经过章节边界而被随意重置。

主体使用单个固定舞台与长滚动范围。ScrollTrigger 读取进度，避免为每一章建立相互竞争的 pin 容器。一个 `gsap.ticker` 回调负责调用 `lenis.raf(time * 1000)`、派生状态和绘制；`Lenis.autoRaf` 为 `false`，两个反应堆渲染器都不拥有第二个 RAF。

场景文字的透明度、可见性与可交互性分开处理。交接可以短暂重叠，但只有当前有效章节的控件能接收焦点。对话框打开时暂停背景旅程，关闭时恢复并还原焦点。

字体就绪、页面恢复与尺寸变化会同步 Lenis 和 ScrollTrigger。窗口尺寸变化前记录当前进度，重新测量后恢复到相同章节位置。隐藏标签页不会继续执行应用绘制；返回时重新同步，单帧时间增量也受到限制，避免把离开页面的时间一次性追赶完。

实现依据见 [SOURCES.md 的技术资料](SOURCES.md#技术一手资料)。

## 程序化结构与材质

WebGL 主渲染器使用带拉长率与三角形变的环面截面，统一机械与等离子体的基本轮廓。D 形线圈沿完整路径生成，并共享站位变换；绕组、夹持件与连接细节随组件一起运动。真空室由真实分段几何组成，剖面只打开相关区域，避免把整个装置无差别消隐。

等离子体由多层参数化曲面和着色器构成。场线有独立的环向、极向与组合路径；粒子位置由环面坐标计算。扰动以协调的模态位移作用在几何上，控制参数压低波幅，保持清楚的因果关系。

反射环境在内存中由 Canvas 生成，再交给 Three.js 的环境处理。运行时不加载照片、HDRI 或纹理站素材。光晕主要由发光材质、透明层与有限的几何层次形成，避免把大面积逐帧 CSS 模糊作为主要效果。

## 手机、性能与降级

手机竖屏采用上方标题、中央反应堆、下方说明与交互的构图，主对象横向居中。短竖屏增加镜头距离并收紧字级；横屏使用文字与主对象并列构图。装饰注释减少，章节导航收为底部入口，触控按钮保留可点击面积。总滚动范围由桌面的 `1700svh` 调整为 `1350svh`，不只是等比例缩小桌面排版。

WebGL 的像素比与粒子数量受质量档、视口大小和设备像素比限制。重复机械部件使用实例化；每帧主要更新 uniforms、变换与少量界面读数，没有框架级整页重渲染。未显示的章节不保留可交互元素；诊断波形仅在相关章节绘制。

Canvas 回退保留同一个 `ReactorFrame` 接口，使用投影 D 形线圈、环面细丝、移动粒子和方向性磁场。它限制路径数量和 DPR，呈现清晰的二维发光结构；金属反射、体积层次与三维遮挡不与 WebGL 模式等同。`?renderer=canvas` 可用于直接验收此路径。

`prefers-reduced-motion` 默认冻结持续运动、移除滚轮惯性。用户仍可以按滚动位置检查构图、阅读文字和操作控件，并可主动恢复持续运动。Pause 保留当前构图；未发生交互时，不重复绘制相同的暂停帧。

## 声音

声音使用正弦振荡器与固定种子的本地噪声，经过增益、滤波和压缩器组成低频声景。能量、磁场和失稳参数改变音高与滤波，和视觉读取同一状态。AudioContext 只在点击声音按钮后创建；隐藏页面时暂停。没有音频文件、麦克风权限或外部音频请求。

## 科学可信度与验收

工程拓扑参考 ITER、DOE 和 PPPL 的一手资料；实际模型仍是原创艺术构型。温度、激励百分比、偏差、疏密、颜色与速度均为示意。完整边界和逐项来源见 [SOURCES.md](SOURCES.md)。

验收应覆盖完整构图、持续运动、交接连续性、快速与反向滚动、暂停、标签页恢复、尺寸变化、控件因果关系，以及 WebGL / Canvas / reduced-motion 三条路径。最终完成的构建与浏览器验收见 [VALIDATION.md](VALIDATION.md)；本文记录设计和实现，不把未测量的设备帧率写成保证。
