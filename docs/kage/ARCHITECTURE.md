# KAGE / VOID — 架构说明

## 模块与数据流

项目采用 TypeScript、Vite、Three.js 和一个手动驱动的 Lenis 实例。没有前端框架、后端或运行时远程素材请求。依赖版本和 Node.js 要求记录在 [package.json](../../package.json)，安装解析结果由 `package-lock.json` 固定。

| 模块 | 职责 |
| --- | --- |
| [index.html](../../pages/kage/index.html) | 静态首屏、语义章节、控件和原生目录对话框 |
| [src/score.ts](../../experiences/kage/src/score.ts) | 章节数据、纯函数姿态采样与减少运动快照 |
| [src/sculpture.ts](../../experiences/kage/src/sculpture.ts) | 创建和更新 Three.js 场景；不自行拥有动画时钟 |
| [src/main.ts](../../experiences/kage/src/main.ts) | 输入、滚动归一化、动画循环、界面同步和生命周期 |
| [src/style.css](../../experiences/kage/src/style.css) | 固定视觉层、响应式排版、交互状态和 CSS 后备几何 |
| `provenance/kage/KAGE-VOID.html` | 保留的原始离线交付版，不参与当前构建 |

页面的主输入是一个范围为 `[0, 1]` 的滚动进度 `p`。窗口原生滚动位置除以有效滚动距离得到它；Three.js 姿态、文字裁切、章节读数和进度条共同消费这个值。

## 章节与连续姿态

`CHAPTERS` 提供八个公开章节，`SCORE` 保存各关键位置的镜头、光照和五组几何参数。SILENCE 在到达终点之前另有一个内部关键点，用于将最终的窄框进一步收束为细线。

| 章节 | 目标进度 | 关键构图 |
| --- | ---: | --- |
| VOID | 0 | 斜向叠置的深色开口，地面与实体阴影 |
| LINE | 0.14 | 几何压缩成细线，进入深色背景 |
| FRAME | 0.28 | 连续排列的框架与纵深 |
| LIGHT | 0.42 | 镜头进入开口，光廊与远端发光门面 |
| MASS | 0.56 | 边条增厚，开口压缩，呈现实体重量 |
| SHADOW | 0.70 | 较高的视点、倾倒平面和方向性阴影 |
| FORM | 0.84 | 边条展开、错位并折叠 |
| SILENCE | 1 | 开口收束，留下细线与大面积留白 |

章节读数在相邻目标进度的中点切换，因此“当前章节”与“正好到达该章节关键姿态”是两个不同条件。目录导航前往表中的目标进度；例如 `#light` 对应 `0.42`。

### 纯函数采样

`samplePose(progress, mobile, reduced)` 每次从关键数据重新计算完整姿态，不积累上一次的旋转或位置。无效进度按起点处理，越界值限制在有效范围内。相邻关键姿态以平滑插值为主，混入少量线性变化，使关键位置附近仍能响应滚动。

这保证同一输入能恢复同一组镜头和几何参数。最终渲染还会加入两类幅度较小的变化：由主时钟提供的环境微动，以及桌面鼠标带来的镜头偏移。它们没有改变章节数据本身。比较截图时，应固定时间、指针状态或启用减少运动；单纯回到同一滚动位置不保证动态模式下逐像素相同。

减少运动时，姿态吸附到当前章节的目标进度，不再计算章节内部的连续飞行；文字只保留当前章节，关闭裁切位移、环境微动与鼠标视差。

### 黑白交接

当相邻背景明度差超过阈值时，空间变形照常进行，配色则在较短区间内切换。一块挂在镜头前方的平面同步横穿视野，其两侧带细亮边，遮住最明显的光照反相阶段。平面的位置由同一进度计算，因此也能随反向滚动恢复。

该遮挡发生在 3D 舞台内；界面的文字层仍独立存在。几何、灯光与文字通过共享滚动坐标配合，并没有建立多个独立章节动画播放器。

## 一次 requestAnimationFrame

`main.ts` 是唯一的动画调度者。Lenis 使用 `autoRaf: false`，渲染器只接收当前进度、经过时间、减少运动状态和指针值。

每帧的处理顺序是：

1. 检查页面可见性、目录状态和销毁状态。
2. 计算时间差；单帧增量上限为 50ms，恢复页面时不补算隐藏期间的时间。
3. 若有尺寸变化，重新测量并保留归一化进度。
4. 调用 `lenis.raf()`，再从 `window.scrollY` 得到实际进度。
5. 平滑指针输入；仅在进度改变或标记为脏时更新文字、读数和后备构图。
6. 将当前状态交给 `Sculpture.render()`。
7. 根据运动、平滑滚动和尺寸更新状态决定是否申请下一帧。

正常 WebGL 动态模式持续渲染，用于保持缓慢环境微动。减少运动与 CSS 后备状态主要按需更新；浏览器原生滚动事件会申请所需的帧。只有 Lenis 的 `isScrolling === 'smooth'` 会因平滑过程继续调度，避免原生滚动标记在边界处遗留时产生空转。

打开目录会暂停 Lenis 和动画时钟。关闭后恢复焦点与滚动，需要跳转章节时再执行跳转。隐藏标签页、`pagehide` 和 `pageshow` 也进入同一套暂停 / 恢复逻辑。

## Three.js 场景

场景复用一个单位立方体几何体。五个开口组分别含四根实体边条、一条亮棱和四条内缘；改变缩放和变换后，它们可以收成线、展开成框或增厚为实体。构件的宽度与厚度受约束，避免形成负尺寸。

地面接收方向光阴影。场景还有半球光、随背景明度同步的雾、地面光束、连续追踪线、远端发光开口和镜头前遮挡平面。主体使用标准材质，并在着色器中加入幅度很小的程序化微结构；没有外部纹理或模型加载。

输出采用 sRGB 色彩空间与 ACES Filmic 色调映射。`score.ts` 中的明度值是渲染参数，最终屏幕颜色还受材质、灯光和色调映射影响。不能把这些标量直接解释成 CSS 十六进制色板。

### 画质预算

画布像素比由设备像素比、1.75 的上限、视口像素预算和自适应系数共同决定。桌面预算约为 360 万像素，竖屏预算约为 190 万像素；最终像素比还设有 0.35 的下限。上述预算用于限制连续 3D 层，DOM 文字不跟随画布降采样。

渲染器对近期帧间隔做平滑统计，每 150 个有效样本考虑一次调整。较高耗时降低分辨率，较低耗时逐步恢复；自适应系数保持在 `0.55–1`。它不读取原生 GPU 利用率，也不是目标帧率保证。阴影贴图为 `2048 × 2048`，画布分辨率变化不会相应修改这一贴图尺寸。

着色器在显示画布前预编译。浏览器提供并行编译扩展时使用异步编译，否则使用同步编译。准备过程中先显示 CSS 构图；超时、构造失败或渲染异常均能保留该构图。

## 响应式与输入

布局、滚动距离与镜头使用相关但独立的条件：

| 机制 | 判定 | 行为 |
| --- | --- | --- |
| CSS 移动布局 | 宽度 ≤ 760px | 重排字号、图注、控件与目录 |
| 移动滚动距离 | 宽度 ≤ 760px | 有效行程为测量高度的 9.6 倍；其他尺寸为 11.6 倍 |
| 竖屏镜头与渲染预算 | 宽高比 < 0.85 | 减少横向位移、调整镜头目标与观察距离，降低画布预算 |
| 大屏标签 | 宽度 ≥ 2000px | 放大页首、图注与导航读数 |
| 矮屏桌面 | 高度 ≤ 620px 且宽度 ≥ 761px | 调整上下留白、大字和目录密度 |

竖屏镜头在大部分章节增加观察距离，但在 LIGHT 的进度附近撤回这段距离，使镜头真正进入开口。移动构图的展开幅度和镜头滚转也更小。横屏手机可以采用桌面镜头视线，同时继续使用适合其宽度的界面布局。

尺寸变化时，`measure()` 保存归一化进度、重建滚动距离并回到对应位置。移动浏览器地址栏引起的较小高度变化不会反复重置行程高度；明显的宽度 / 高度变化则重新计算。CSS 同时使用安全区域、动态视口和小视口单位。

滚轮在运动开启时经 Lenis 平滑；触摸使用原生滚动，未启用触摸同步惯性。页面保留原生键盘滚动，按钮和目录链接使用浏览器语义。鼠标视差只接受 mouse 指针，竖屏渲染与减少运动模式关闭这一偏移。

## 导航、无障碍与恢复

目录使用原生 `<dialog>` 与 `showModal()`，由浏览器负责顶层展示、背景模态约束和焦点范围。关闭按钮获得初始焦点；关闭后恢复到打开目录前的元素。目录支持 Esc 关闭，当前章节通过 `aria-current="location"` 标识。

舞台和视觉大字标为装饰层，正文保留页面标题与八个语义章节。章节变化通过 `aria-live="polite"` 简短提示，进度条提供百分比值。Tab 可访问跳转目录的跳过链接以及必要控件；隐藏的中段边缘操作从键盘顺序移除。

系统减少运动设置决定初始状态，并在后续系统变化时再次生效。用户可以显式切换当前模式；手动关闭的选择在允许本地存储时保存。存储访问失败不会阻断控件。

WebGL 上下文丢失时保留当前章节并切换到 CSS 构图；上下文恢复后重新测量和预编译，再显示当前姿态。后备构图有自己的黑白、侧面和开口变化，是简化表达，并不复现全部 3D 镜头和阴影。禁用 JavaScript 时仍有静态初始构图与说明。

开发环境热更新销毁会取消 RAF、清理超时、撤销事件监听、销毁 Lenis，并释放共享几何、材质、阴影贴图和渲染器。

## 原交付构建与离线版本（历史记录）

以下段落描述原交付包，当前 Collection 的 `npm run build` 执行共享 TypeScript/Vite 多页面构建，不再生成离线版；流程见 [README](../../README.md)。

原交付 `npm run build` 依次执行 TypeScript 检查、Vite 构建和单文件打包。Vite 的 `base: './'` 保留相对资源路径，构建目标为 ES2022，生产脚本关闭代码分割。正常 `dist/` 保留网页、脚本、样式和资源分文件的结构，便于本地 HTTP 预览。

离线脚本读取已生成的 `dist/index.html`，将模块脚本和样式表内联，将 CSS 字体与图标转换为数据 URL，移除不再需要的资源预加载。对这些已处理的脚本、样式和资源引用，它会拒绝外部地址、逃逸出 `dist/` 的路径、未合并的 JavaScript 导入和 CSS `@import`。检查不覆盖任意 HTML 媒体属性或 JavaScript 内的运行时网络调用；以后新增这类资源时，应扩展内联处理并重新验证离线运行。

生成结果为根目录 `KAGE-VOID.html`。源项目许可证、Three.js、Lenis 和三套字体的完整许可证文本也嵌在一个非执行的 JSON 脚本节点内；脚本会补充收集 `licenses/` 内其他 `.txt` 声明。脚本只依赖 Node 内置模块，不启动任何服务或部署。

修改源码后应重新执行完整构建；直接修改生成文件无法自动回写源码。开发所需的 `npm ci` 可能访问依赖源，已生成离线文件的运行不依赖这些服务。

## 验证与边界

本次 `npm run verify` 已通过 5 项纯状态测试、TypeScript 检查、Vite 构建和离线文件生成。测试代码在 [tests/score.test.ts](../../tests/kage-score.test.ts)。

| 测试 | 实际覆盖 |
| --- | --- |
| 数值和几何有效性 | 桌面与移动路径各采样 2501 个进度，检查有限数值、正尺寸及边条约束 |
| 反向返回 | 101 个进度的前向结果与反向重新采样严格比较 |
| 章节交接 | 在公开关键点及 0.965 的两侧以微小间隔取样，检查差值容限 |
| 减少运动 | 同一中间章节的目标进度两侧生成相同姿态 |
| 进度异常 | 负值、超出终点、NaN 及首末章节索引 |

这些测试验证 `samplePose()` 的数据行为，不执行 WebGL，也不覆盖全部浏览器生命周期或截图效果。阴影、裁切、控件可见性、目录交互、尺寸变化、上下文恢复和离线打开需要浏览器检查。

交互与生命周期的针对性浏览器检查已通过，具体观察如下：

| 检查 | 观察结果 |
| --- | --- |
| 滚轮任意位置停留 | 实际滚轮输入后停在约 `p = 0.33701`，观察期间位置稳定 |
| 反向交接 | 在 `0.35999 → 0.34499 → 0.32998 → 0.33701` 的方向变化中恢复对应状态 |
| 减少运动 | 滚动前后以及首尾边界的观察窗口内，动画回调数和待执行 RAF 数均为零 |
| WebGL 丢失 / 恢复 | 丢失时保留约 `p = 0.28001`；后备模式可滚至约 `0.32391`，恢复时保持该进度并可反向滚动 |
| 本地日文字体 | 4K 与移动视口的构建截图中，八字子集正常显示 |
| 应用控制台 | 上述检查中未记录应用错误或警告 |

这些观察验证了对应输入与恢复路径，不构成所有设备上的帧率或运动手感保证。

离线文件已通过实际 `file://` 打开检查，覆盖全部八个章节链接、重播、移动视口以及禁用 JavaScript 的静态版本；检查期间外部请求和控制台错误均为零。

本次浏览器检查使用 Headless Chromium 153、ANGLE / SwiftShader 软件渲染，视口为 1920 × 1080、2560 × 1440、3840 × 2160 与 390 × 844。该环境可以检查构图和交互结果，但不能代表原生 Windows GPU 性能、真实触控板惯性、iOS Safari 或高刷新率显示器的实机表现；这些项目尚未实机验证。

其他实现边界：

- Barlow Condensed、DM Sans 与当前使用的 Noto Sans JP 八字子集均本地提供。`[lang="ja"]` 使用 CSS 字体名 `Kage JP`；新增日文字符时需要补充子集。来源、覆盖字符与许可证见 [字体说明](../../public/kage/licenses/fonts.md)。
- 帧耗时统计来自浏览器的渲染调用间隔；不同机器、后台负载和图形驱动可能改变画质调整的时机。
- 纯几何路径可逆；动态模式中的环境微动和指针视差不承诺回滚到历史时刻的逐像素画面。
- CSS 后备与禁用 JavaScript 的静态版本保留作品的基本视觉关系，表现范围小于完整 WebGL 版本。
