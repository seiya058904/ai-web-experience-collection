# AETERNA · 交付验证

Historical standalone delivery record. Paths and verification claims describe the original package. Current Collection evidence is in [intake acceptance](ACCEPTANCE.md).

验证日期：2026-10-06。对象：ZIP 中的九幕静态展览、真实三维模型、随包资源和本机启动方式。

## 结论与运行范围

本地功能验证的 20 项检查通过，最终独立视觉复核通过。验证覆盖了原生滚动的往返与恢复、真实三维控制、主要响应式布局、减少动态偏好及图形故障回退。检查中发现的移动端模型与控件重叠、320px 窄屏信息冲突、浅色石面上的文字对比度问题均已修复并重新查看。

测试通过本机 HTTP 服务执行，浏览器为本地 Chromium，三维渲染使用 SwiftShader。所有普通运行请求均指向本机；未发生非预期页面错误或控制台错误。刻意禁止创建 WebGL 的测试产生一条预期的 `Error creating WebGL context` 信息，随后检查了静态回退与导航。生产构建的本机服务使用 Node 原生模块；展览资源无需在线 CDN。

最终 `npm run build` 成功。随后的交付检查逐一通过本机服务器读取 27 个构建文件，并与磁盘内容比对哈希；23 个公共资源的源文件与生产副本一致，13 项生成图像清单的大小与 SHA-256 一致。文档的 73 个内部链接均有目标。构建配置显式清理旧输出，最终包仅保留当前入口引用的代码与样式。

## 交互与状态验证

| 检查组 | 已确认的行为 |
|---|---|
| 原生滚动 | 慢速滚轮可以停在连续的组装中间态；17 次快速前进/后退跳转后，章节和画面正常收敛。停留时按需渲染停止增加帧数。 |
| 停留与刷新 | 在一幕约 63% 进度刷新，章节进度和滚动位置恢复；展厅模型查看状态及灯光值也可恢复。 |
| 窗口与历史 | 改变窗口高度后保持当前章节进度；浏览器返回按章节/进度恢复，而非使用旧视口的绝对像素位置。 |
| 页面恢复 | 使用浏览器生命周期接口实际冻结并恢复页面，章节、滚动位置和组装控制值保持。 |
| 目录与弹窗 | 目录跳转正确；只有当前房间参与可访问交互；来源弹窗支持 `Esc`，关闭后焦点返回有效触发器。 |
| 三维控制 | 组装与断裂控制实际网格的位移和旋转；浮雕控制实际镜头的观察角度及接近程度；展厅灯光支持直接输入与方向键。手动控制后可用 Follow the scroll 返回滚动时间轴。 |
| 减少动态 | 切换偏好时保持章节；停止自动镜头运动，仍允许明确的手动操作。浮雕两个手动位置产生不同的真实渲染结果；Look closer 即时放大石材。 |
| 图形异常 | 实际触发 WebGL 上下文丢失后，展厅恢复静态图、保留返回按钮；上下文恢复后重新显示模型。完全无法创建 WebGL 时，备用图、来源和章节导航保持可用，相应模型滑杆禁用。 |
| 资源与布局 | 图片和字体加载完成，已检查桌面与手机横向溢出；模型及 Draco 解码文件随包提供。 |

滚动架构集中于 `src/scroll.js` 与根级更新循环。浏览器负责滚动，单一进度状态驱动场景；三维模块不另建独立动画循环。恢复逻辑使用章节与归一化进度，避免窗口高度变化时跳回旧像素位置。减少动态样式使用零时长，避免布局测量落在过渡中间态。

已将选定的 Hero 参考与真实浏览器中的桌面首屏、4K 静态首屏对照，并复核整场的材料、光线、尺度与文字关系。

| 视觉锚点 | 成品中的对应 |
|---|---|
| 巨像与极端裁切 | 开场面孔压至右侧及画面边缘，保留强烈的尺度感；手机使用适合竖屏的裁切。 |
| 深色留白 | 首屏、肖像和纪念碑保留供实时文字阅读的暗区；局部遮罩在必要位置保护文字对比度。 |
| 文字与雕塑的空间关系 | AETERNA 是 HTML 文字；独立透明前景层与雕塑边缘形成遮挡关系。 |
| 石材细节与侧光 | 宏观眼窝、肖像、残片和建筑分别使用选定的生产图；材质纹理与斜向博物馆光线贯穿。 |
| 古典字形与清晰信息层级 | Bodoni Moda 承担展名和章节标题，Manrope 承担控件及记录；桌面、4K、手机分别检查比例与断行。 |
| 暗室与象牙白展厅的节奏 | 第八幕转换为明亮的收藏/保存语境，结尾回到深色大空间与微小半身像。 |
| 有体积的重组与断裂 | 同一件扫描衍生人体的 36 块真实分片贯穿组装、断裂和展厅查看；新增断面为数字制作。 |
| 浮雕的真实深度 | 生成开场图转入 Met 井栏扫描，以真实镜头变化显露雕刻深度；两个对象的身份在说明中区分。 |
| 手机的观看秩序 | 标题、模型、控制区、来源依高度分区；来源按钮缩为 Details，完整记录仍可访问。 |

这些对应说明实际选择与实现方式，并不意味着每幕都逐像素复制概念图。真实馆藏模型保留其自身形态；生成的躯干参考未被误作馆藏扫描的最终外形。

## 对比度与有界修正

对高风险图像背景上的 40 处文字区域进行了像素取样：比较正常画面与隐藏文字后的背景画面，识别字形区域，并按前景色与实际背景计算对比度。抽查区域均达到相应阈值；普通文字的最低抽查值为 5.44:1，大字最低为 3.81:1。此项是指定阅读区域的检查，不是全站自动化 WCAG 认证。

首次视觉复核提出的三个问题均在同位置重新查看后通过：移动端模型进入控制区、紧凑屏幕文字/控件冲突、亮石面上的文字对比度。修正集中于画布布局、模型取景、阅读区遮罩和移动来源说明，没有扩展成无关的界面改版。

设计检测器只执行了一次。目录悬停使用 padding 过渡的机械性问题已移除。检测器对源 HTML 给出的“标题/正文均为 16px”与浏览器实际字体计算和画面不符：样式由应用模块导入，静态分析未完整读取。石材、暗室及象牙白场景中的局部颜色变体保留，并结合真实图像背景检查阅读效果。

## 交付边界

- AI 生产图原始宽度约为 1672px，具体尺寸、生成提示和哈希见 [AI_ASSETS.json](AI_ASSETS.json)。4K 检查表示在 3840 × 2160 视口查看了成品，不表示源图原生 4K。文字与实时三维按浏览器视口绘制。
- 验证使用 Chromium 与软件图形渲染，没有将其描述为所有浏览器、实体手机、Safari 标签恢复或实际显卡帧率的全面测试。
- 本机服务器完成过启动与 HTTP 行为检查；Windows 批处理启动器进行了静态检查，未在原生 Windows 系统执行。macOS/Linux 的通用 Node 启动路径在当前 Linux 环境验证。
- 最终修正后的减少动态、移动端、4K 与故障测试已运行；部分正常桌面功能证据保留自具有相同 JavaScript 的前一构建。此后唯一界面变更为移除目录悬停的布局过渡，并重新生成生产构建。
- 本包保留源代码、生产构建、实际使用的生成图像、两份选定视觉参考、模型、字体及许可。测试截图、浏览器轨迹、临时素材、调试数据、`node_modules` 和缓存不属于交付内容。
