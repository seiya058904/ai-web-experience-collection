# GLAZE — 设计说明

## 让颜色成为器物的一部分

本作品以“器口是一扇开口”为构图线索：从完整器物进入釉面，再借圆孔、弧形边缘和高光进入下一种材料。七个场景在同一固定舞台内交换画面，底层保留有语义的章节，视觉上形成一次连续观看。

研究中的三个判断决定了方向：[TORTUS](https://tortus.dk/pages/craftsmanship) 的手工痕迹说明器物需要有控制的变化；[Dzek / ExCinere](https://dzekdzekdzek.com/excinere/) 的近照说明同一种釉色内部也应有颗粒与反射差异；[大阪市立东洋陶磁美术馆](https://www.moco.or.jp/en/facilities/point/) 对展示光线的重视，说明背景与照明应帮助观者看清材料。GLAZE 将这些判断转化为自己的器物、画面和运动顺序。

## 七场景如何接力

| 场景 | 主构图与观看重点 | 通往下一幕的媒介 |
| --- | --- | --- |
| **Celadon** | 巨型青瓷瓶压在粗重的 `GLAZE` 字样前；厚口沿、云状釉色与开片首先建立材料感 | 器物放大并向肩部推进，圆形区域扩张为釉面微距 |
| **Crackle** | 斜向高光跨过曲面，裂纹与微孔成为主角，观看尺度由器物变成表皮 | 斜向遮罩接过画面里的光带，露出钴蓝器物 |
| **Cobalt** | 环形瓶占据大部分屏幕，文字在器物后方并从环孔中露出 | 镜头向圆孔推进，红色画面从相近的圆心扩张 |
| **Oxblood** | 红黑釉面与左上暖光建立全站最重的一幕；火的意象集中在色泽和光束里 | 左上的暖光区域展开为明亮椭圆，进入白瓷 |
| **Ivory** | 折叠碗沿形成长弧；较薄的暖色边缘、粗细变化与微孔放大“轻”的感受 | 左下曲面接出琥珀色画面，亮边的温度得到延续 |
| **Amber** | 环形器物回到较完整、落地的形态；土色足部与长阴影强调重量 | 斜向边界带入暗部，以阴影关系衔接铁黑碗沿 |
| **Iron** | 巨幅深色碗沿横贯画面，矿物斑点与褐色边缘保留最后的光 | 构图缓慢推进后停留，以重播回到最初的器口 |

这些接力是通过画面形状和光色组织的剪辑关系，并非真实器物变形的物理模拟。火被合并进 Oxblood，令红与白之间的明暗变化成为叙事转折；单独加入窑炉视频会改变已有摄影语言，因此最终保留七幕。

## 摄影语言与素材取舍

所有器物图像均为 **AI 生成的摄影风格作品**。统一方向包括单体器物、无缝背景、左侧或左上方主光、可辨认的口沿厚度、接触阴影，以及釉层里受控制的斑驳与不均匀。红釉收窄暖光，白瓷把主光移到左后方，琥珀加强投影；这些变化服务于同一观看方向和明暗节奏。

采用生成底图保留材料细节，运行时只改变画面位置、尺度、角度和遮挡。光影留在底图中，没有使用实时三维重打光。大标题与小标注使用同一 Archivo 字族：首屏和钴蓝以较粗字重参与轮廓构图，其余画面用较细字重留出器物的呼吸空间。

Celadon 使用透明器物与代码绘制的背景、阴影组合。Cobalt 以前景遮罩让文字进入器物后方；前景仍取自同一张 `cobalt.webp`，遮罩只控制可见范围，避免另一张生成图的釉色与底图错位。手机上重新安排标题和器物，红釉、白瓷、琥珀使用独立竖幅素材，钴蓝取消桌面前景遮挡层以保持字形完整。

## 运动方案的判断

[GSAP 官方 Scrub Animations 示例](https://codepen.io/GreenSock/pen/WNvVOWw) 与 [ScrollTrigger 文档](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) 提供了将滚动位置映射到时间轴的成熟模式。GLAZE 使用一个 pin、一条可逆时间轴；只对舞台内部元素做变换。每幕先进入、建立构图，再在继续滚动时轻微推进，最后交接。停下后画面收敛，方便观看。

[Lenis 官方集成方式](https://github.com/darkroomengineering/lenis#gsap-scrolltrigger) 决定了单一时钟：关闭 Lenis 自动 RAF，由 GSAP ticker 驱动，再将滚动同步到 ScrollTrigger。重建、退出和动效切换负责销毁旧实例与监听。布局刷新保留展览进度；切回标签页时清除隐藏期间累积的惯性。减少动效模式回到普通文档流，展示完整的七幅构图。

滚动停止后，当前 history entry 保存实际文档进度。刷新或非 BFCache 返回在舞台重建后即时恢复该停点，不将章节内的位置舍入到章节入口。新打开的章节 URL 仍直接进入指定研究。动效版章节的 URL 由控制器解析，DOM 场景使用 `-view` 后缀避免浏览器再次定位固定舞台；普通阅读流保留原生章节 id。history state 受限时继续提供原有导航与浏览器恢复能力。

[GSAP 的 preventOverlaps / fastScrollEnd 示例](https://codepen.io/GreenSock/pen/ZEyXPGj) 展示了独立触发动画在快速滚动时需要处理的结束状态。这里选择统一的 scrub 进度，不使用这些强制结束选项，保留快速反向时的中间构图。上述案例用于研究行为与架构，没有复制其场景代码、样式或素材。许可说明见 [ATTRIBUTION.md](../../provenance/glaze/ATTRIBUTION.md)。
