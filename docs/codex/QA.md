## 可逆性检查

两个视口均按顺序前进至每幕局部进度 65%，随后从终点反向返回完全相同的进度，共比较 20 对画面。

- 手机的九个实时材料场景整帧逐像素一致。
- 桌面的九个实时材料场景，物体、材料和阴影逐像素一致。一次 CASE 返回截图只有页眉保留旧墨色；专项复核的即时与稳定画面均与前进画面完全一致，页眉与页脚的计算颜色均为 `rgb(36, 37, 31)`，没有持续的界面状态错误。
- 桌面首幕整帧一致。手机首幕的 AI 书体图像出现小幅光栅差异，平均通道差异约为 0.071 / 255，最大为 8 / 255；文字、布局与书体位置没有变化。该图片未被记为逐像素一致。

关闭动态效果后的重绘检查发现并修复了一个实际问题：非居中的指针目标曾继续触发帧更新。修复后，在指针移动后的 700 毫秒观察区间内，桌面和手机视口的渲染计数均保持不变。

## 验证边界

这里的移动结果是触控与视口模拟，不是手机实机测试。没有将 Windows 实机、Android 实机、iOS Safari 或其他浏览器标记为已验证。

浏览器使用 SwiftShader 软件 WebGL。冷材质与普通动态模式曾使截图采集等待超时；同一稳定状态的后续采集成功，未观察到相应页面异常。截图采集与交互验证不构成真实 GPU 帧率基准，也不宣称所有设备达到固定帧率。

本记录覆盖具体画面、控件和构建行为，不是完整 WCAG 审计或所有浏览器的兼容性认证。
