# 工艺依据 / Craft sources

核对日期：2026-10-07。

CODEX 选择一册当代黑色书布精装书作为连续对象：纸张折帖、沿折背缝订、衬层整理书脊、独立书壳与书芯结合，再以环衬和克制的压印金饰完成。以下资料用于确认这种材料关系。它们是研究参考，不是项目图片素材来源。

## 结构选择

**书帖由折叠和嵌套形成。** 缝订线经过折背上的孔位，将各帖逐一连接；承托绳或带横跨书脊。CODEX 的主线采用带状承托，以便读出连接关系。依据：[Getty 的书籍制作介绍](https://www.getty.edu/art/exhibitions/making/)、[Getty 的 all-along 缝订术语](https://www.getty.edu/vow/AATFullDisplay?find=&logic=&note=&subjectid=300261540) 和 [伊利诺伊大学的装帧结构说明](https://psap.library.illinois.edu/collection-id-guide/bookbound)。

**书芯和书壳保留各自结构。** 当代 case binding 将独立制作的书壳与书芯结合；中世纪将承托结构穿入木封板的做法属于不同构造。衬层、缝线、封板与活动书沟不能混成一个刚性物体。依据：[伊利诺伊大学](https://psap.library.illinois.edu/collection-id-guide/bookbound)、[美国国会图书馆的书脊修复记录](https://www.loc.gov/preservation/conservators/diderot/treatment.html)。

**纹样形成与纸面转移分开。** Marbling 的颜色先在黏稠浴液表面形成，再转移到纸上。CODEX 以浴面梳理和纸面固定两个视觉状态表达这一点。依据：[大都会艺术博物馆](https://www.metmuseum.org/perspectives/marbled-paper)。

## 数字呈现的简化

- **时间与顺序：** 十幕是一段编辑后的工艺旅程。环衬制作、压印、书口装饰、干燥和压平在实际工作中的安排随装帧方式变化。终段集中表现 finishing，不宣称固定生产顺序。
- **纸张与书帖：** 为保持轮廓与运动可读，几何中的纸层数量、纸边间距和弯曲程度被缩减或放大。它们不用于量取纸厚或计算成书页数。
- **缝订：** 路径体现穿孔、进入折背、跨越承托和连接各帖的关系；不是某一种历史针法的完整教学录像。生成概念图中的装饰性线段不能取代结构依据。
- **书脊：** 书头带位于书芯头尾，衬层和外部书脊有不同作用。相关动画以可读性表达连接和活动，未求解真实材料应力。
- **Marbling：** 使用有来源记录的生成纹样与确定性 Canvas 变形模拟梳理；不是墨水、浴液、表面张力或吸水过程的数值求解。纹样转移后应随环衬固定。
- **金饰与字印：** Gold tooling、foil stamping、盲压、书口金饰是有关联的不同工艺。画面以精细的物体表面字印和局部反光表现，不把所有金饰动作视为同一操作。

## References in English

This project is an artistic construction study of a contemporary sewn cloth case binding. Museum, library, conservation and first-party craft sources informed the relationships between folded gatherings, sewing supports, spine linings, boards, endpapers and decoration. The sequence, dimensions, timing and simulation detail are intentionally simplified. No museum photographs were copied into the project.
