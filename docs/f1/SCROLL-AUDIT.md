# Scroll and motion audit

历史审计基准：2026-10-05，Collection 整合前。下方旧表保留为可追溯的基线，不代表本次发布参数；最新结果见文件末尾“Collection release”。用户本次明确要求消除旧 Hold 死区，因此旧的零位移验收标准已经被取代。

## 已确认的根因与约束

## 当前架构

- `experiences/f1/src/motion.ts` 拥有唯一 Lenis 与 GSAP ticker，负责可见时钟、导航、动效偏好、空闲重测和清理。触摸保持原生惯性，`syncTouch: false`。
- `experiences/f1/src/choreography.ts` 先建立物理阅读窗口，再测量完整文档坐标；重测先于 Lenis 尺寸更新与 ScrollTrigger refresh。动画帧只插值缓存点，不测量 DOM / SVG 路径。
- `experiences/f1/src/interactions.ts` 将气流、能量、赛道注册为三个可见场景循环。Canvas 上限为 1.5 DPR / 3,000,000 像素，SVG 路径预采样，移动标记使用 transform。
- `experiences/f1/src/main.ts` 处理幂等就绪、资源错误与 HMR 销毁。诊断 `window.__f1Motion` 仅开发环境存在。
- 全动态模式有 16 个直接 scrub triggers；桌面有六个正文章节 shell 和一条共享轨迹。手机无 shell；减少运动时触发器、shell 与轨迹均移除，控制状态仍可更新。

### Enter → Hold → Exit

桌面为引言及五个主要章节建立 CSS sticky 阅读窗口。sticky top 同时满足页眉避让与最后重要内容完整入屏，Hold 距离按可用视口、受保护内容高度、文字行数与控制项数量测量；说明展开、视口变化后重新计算。超出视口的章节先正常浏览前半部，再保护适合视口的结尾内容组。

内容使用 `enterStart → enterEnd`，转场使用 `exitStart → exitEnd`；Hold 内两者都不推进。`pinStart` / `pinEnd` 是测量后的 CSS sticky 范围，不是 ScrollTrigger pin spacer。正文 hold space 由正常流的 `::after` 提供；单纯 padding 曾被验证不能提供所需 sticky travel。

手机正文保持自然流。阅读窗口从最后内容完整入屏开始，到受保护首行接近页眉结束；下方背景出现不会提前结束阅读。前一章退出与下一章入场使用同一可逆时间轴，滚动方向不改变 z-index。

共享轨迹仅在 A Hold 结束后交接，在 B 入场完成时结束，稳定阅读期间隐藏。开场保留赛车推镜；气动、动力和轮胎的已有图像退出采用独立、明确的起止状态（`immediateRender: false`）。本次交接修正没有新增特效或依赖。

### Stacking context 与裁切

- 各场景 `isolation: isolate`；桌面 shell 为正常流 z-index 1，不随滚动切换层级，也没有负 margin 抢占上一章地面。
- aperture 限于本章节背景、z-index 0、无指针事件；正文 z-index 1。clip-path / transform 不裁正文。
- hero / pit 的负层图像、mask / overflow 限于隔离图像容器；正文不新增遮罩或裁切。
- 共享轨迹 z-index 5，但 Hold 期间 opacity 为 0；页眉、菜单与加载层保持自己的既有关系。
- 页眉明暗与导航范围包含整个 shell Hold。关闭动效会移除 shell、aperture、轨迹与触发器。

## 浏览器验证记录与边界

检查使用 Chromium 内置浏览器、真实 wheel dispatch、原生控制和截图。以下为 **CONFIRMED-RUNTIME** 的有界观测；不是实机触控板、触屏或显示器帧率证明。

- 八个边界逐个检查 Enter、完整展示、交接前、交接中、B 接管。开场与六个主章节覆盖慢滚、普通、连续滚轮、细碎输入、快速下滚后立即反向；尾章与页脚检查自然流与停顿。停止点正文 hit-test 未发现被相邻章节遮挡，六个 Hold 的 25% / 75% 采样构图位移为 0。
- 桌面往返同一位置的图像矩阵差为 0，文字 clip / transform 一致；最大 scrollY / 场景位置差约 0.57px。手机气动、策略、赛道反向复测同样一致。未观察到层级翻转、pin jump 或突变。
- 390×844、768×1024、1440×600、1440×900、1920×1080 检查逐章阅读窗口与水平溢出。手机自然阅读窗口约 207–635px。气动 / 策略说明展开后 Hold 自动增长，短屏采用适合视口的尾组；赛道切换、键盘滑块、导航与动效重建保留状态。
- 生产预览 1280×720 检查六个稳定构图，正文在页眉下 / 视口内、B 尚在下方、轨迹隐藏。开场 Hold 标题和主张 opacity 为 1；wheel 到页底误差约 0.71px，返回 scrollY 0；五张图片加载完成，未记录 warning / error，生产无开发诊断。
- 此前生命周期回归覆盖 90 次慢滚、100 次加载后立即输入、39 次快速往返，以及 20 次惯性期间排队刷新；没有观测到目标被刷新截断。重复构建销毁旧 owner，菜单导航恢复可滚动状态，手动 / 系统减少运动后控制仍可用。
- 此前 4K 路线在 SVG 标记改为 transform 后，128 次输入、1,520 个 rAF 回调 / 9.49s 内 P95≈6.3ms、P99≈6.4ms、最大≈6.6ms；没有该样本内的长任务。之前同类样本在赛道附近曾有 18.7–37.5ms 回调。该有界观测不保证相同硬件条件，也不是物理 GPU / 显示 FPS。

长批次中断与错误 wheel 比例的首次生产试跑未记为 PASS；校准、拆分后补齐检查。测试驱动的 wheel 比例必须针对当前 tab / 视口实测，不能盲用此前浏览器比例。截图、原始 JSON、运行日志和旧版本备份属于本地验证证据，不包含在公开仓库或运行资源中；这里保留可复现的方法与结果边界。

内置浏览器切换 tab 后仍为 `visible`，freeze 命令也没有建立真实后台状态，这些尝试不算后台验收。受控 hidden / visible 事件观察到应用时钟与目标 900ms 内不变并以有界 delta 恢复，仅证明受控事件路径。**真实外部浏览器后台往返仍未验证。**

**仍未实机验证**：iOS Safari、真实触摸 / 触控板动量、设备旋转，以及 120 / 144 Hz 显示节奏。响应式视口检查不证明这些硬件体验。用户的真人验收记录不被扩展为未说明设备已通过。

## Collection release — 2026-10-05

本节是合集版本的新验证记录；上面的数值与性能样本属于此前 F1 版本，不代表本次修改后的测量结果。

### Handoff 与排版

对照导入作品的独立内容 / 过渡进度与持续场景响应，F1 保留完整阅读窗口，缩短其后的额外 Hold。1440×900 下，开场 Hold 约 90px，六个章节约 127、156、129、107、159、176px。正常文档流、相邻章节保护和原有退出区间不变。Hold 内增加由同一滚动进度驱动的 12px 前景位移及现有图片的微量缩放；反向输入同步撤回，没有增加 RAF owner 或 Lenis 平滑值。

VERDANT 在 1920×900 的 Architecture 稳定构图中复现约 74px 的标题 / 正文相交。Architecture、Understory、Coda 改为组内正常流和明确间距，宽短屏使用两行 Architecture 标题，手机 Arrival / Coda 同样解除独立绝对定位。保留原有字体、图片和场景切换。导入两站的资源就绪重测排入各自既有时钟，等待惯性结束，避免加载期间重测截断输入。

### 本轮实际执行

- 生产子路径预览：1920×1080、2560×1440、3840×2160、390×844、768×1024、1440×900、1920×900；首页及三站共 161 个场景 / 视口采样。未记录 console error、page error、失败请求、损坏图片或 VERDANT 稳定文本相交。发现并修正 F1 4K 入场文字造成的水平溢出，针对性复测 document width = 3840px。
- 4K VERDANT Understory 首次过早截图尚未呈现懒加载图层；等待资源完成后重新截图并检查完整画面，蕨叶正常呈现。早期空白截图不作为通过证据。
- F1 四种桌面尺寸的开场与六个 Hold，共 28 组真实 wheel 前进 / 反向采样，进度持续响应，六章 60% Hold 行程对应约 7.2px 前景移动。保留稳定正文构图与可逆退出。
- 三站完整滚动链覆盖小量 / 普通 / 高频输入、快速下滚后反向、细碎连续输入、停止与 resize 后继续。F1 / VERDANT / ORBITAL 分别执行 105 / 120 / 125 个混合 wheel 事件。这里的 touchpad-style 输入是合成 wheel，并非实体触控板认证。
- 首页进入、返回、浏览器后退、子路径直接进入及刷新；F1 科普控制、键盘滑块、资料展开、赛道 / 周末切换、手机菜单和动效重建；VERDANT 导航与动效切换；ORBITAL 四个子系统、Moon、音效开关、章节索引和许可弹窗均执行。三个全新上下文的系统 prefers-reduced-motion 路径通过。
- 加载后立即输入 40×40px，三个站最终均到达 1600px；未观测资源就绪将目标截断。ORBITAL 正常 WebGL、禁用 WebGL 的 Canvas 后备，以及主动丢失 WebGL 上下文后的 Canvas 恢复通过。
- 九个模型测试、TypeScript / 生产构建、Pages-base 输出资源和许可检查通过。ORBITAL 独立延迟加载的 Three.js 场景块触发 Vite 500kB 提示；不会加载到 Collection、F1 或 VERDANT。该提示不等于本轮硬件性能测量。

自动化 Chromium 及独立 Chrome 的后台标签页尝试均仍报告 `visibilityState = visible`，没有建立真实 hidden 状态，**不计为后台恢复通过**。真实后台恢复、iOS Safari、物理触摸 / 触控板动量和 120 / 144Hz 硬件节奏仍需实机验证。截图与原始测试数据保存在仓库外，不随站点发布。本节记录本地生产预览；线上发布和资源字节核验以发布收口结果为准。

## 维护复现检查点

1. `npm ci`、`npm run verify`，然后 `npm run preview -- --port 4174 --strictPort`。完整浏览全部章节和科普控制，检查 console、失败图片 / 字体、资料许可链接与页面溢出。
2. `npm run dev`，正常滚动并反复反向。静止后 `window.__f1Motion.inspect()` 应为 unlocked / running、16 triggers、三个 scene loops、无待刷新；`handoffs.chapters` 必须有独立入场、完整内容、Hold 和退出区间。
3. 惯性期间多次调用开发诊断的 `refresh()`；目标不应被这些通知改写，刷新只在静止后合并发生。不要将主动导航中断误判为刷新缺陷。
4. 展开气动 / 策略 / 资料说明，切换周末和赛道，然后导航。窗口重新测量，不应抢画面或滚动跳转。
5. 在运动中跨越 760px 断点，静止并反向：手机 shell 为 0，桌面为 6；全动态共享轨迹只有 1，Hold 期间隐藏。
6. 章节中多次切换动效，检查阅读锚点与控制状态；减少运动时没有 trigger / shell / ribbon。单独检查无手动偏好时的系统减少运动路径。
7. 至少检查 390×844、平板、1440×900、2560×1440 与 3840×2160 的完整构图；每个边界任意停顿。外部浏览器 / 实机完成仍缺的后台、触摸、触控板与高刷新率检查，不以合成事件替代。
