It adds no clock, easing, threshold or delayed reconciliation.

Only this work's ticker is removed while hidden or in a persisted pagehide. Partial scene-construction failures release resources that have already been assigned.

Fresh chapter hashes use the original navigation destinations. Reload and back-forward keep browser restoration; no checkpoint store, fixed reconciliation loop or independent restoration clock was added.
