# CREMA — 1.1 refinement

本轮精修继续围绕同一个对象：穿过咖啡床的水。作品的章节、排版和冷钢／暖液体关系保持既定方向，改动集中于实时材质、空间深度与跨尺度连续性。没有增加线上服务、部署步骤或远程运行素材。

## 湿润之后，仍然是破碎的咖啡

颗粒被水润湿时，颜色与局部表面响应发生变化，粗糙的断裂结构仍然保留。材质采用更克制、分布不连续的水膜反光，避免让整颗碎片变成均匀光滑的外壳。颗粒内部的深度与细胞性凹处共同影响光照，孔隙不再仅靠颜色深浅区分。三向纹理投影代替球面 UV 采样，消除极点拉伸；中性的实例色调避免把原有图像反复染暗。

干湿边界仍在同一组颗粒上推进：边界、压实程度和饱和状态由滚动位置决定，没有用两张床层图片切换来替代湿润过程。程序化几何、细胞性高度纹理与单独的 AI 材质细节各有来源，记录于 [PROVENANCE.md](PROVENANCE.md) 和模型／纹理清单。

## 水显现在孔隙中

分叉与重新汇合的路径仍来自确定性的三维网络。水路的深度、截面与可见度沿路径变化，并被前方颗粒遮挡。局部移动的流束与反光提供流动方向，而持续存在的均匀管壁不再承担主要视觉表达。

颜色变化仍沿本作品跟随的水份展开：进入时清澈，带走溶解和分散的物质后逐渐变暖、变深。这与观察整个出口萃取过程的先深后浅是两个不同视角。网页没有把艺术化流路宣称为求解得到的 CFD，也没有将它用作渗透率或压力测量。

## 从一条微观路径，回到一个真实尺度的附着点

压力章节之后，透视镜头向已有孔隙路径靠近，并略微沿流动方向移动。近处颗粒与深处路径产生不同的位移，形成从剖面进入材料的空间感。

萃取末段的路径在床层坐标中向下汇合。随后，微观世界的投影位置与返回机器的液滴附着点对齐。颗粒先退出，温暖液体稍后交接给液滴，让路径的终点和下一幕的起点共享位置。该投影计算使用实际视口、相机和移动端构图，手机无需沿用桌面的水平偏移。

相机移动、路径汇合与场景退出都由滚动位置计算；时间只影响局部流束和微小光照变化。页面上的 9 BAR 仍是短暂的一章构图，伴随“经典参考、可变曲线”的限定。

## 细流之下，表面开始形成

Crema 的开端跟随实际细流的横向位置。先出现低矮的暗色液面，随后细密、不等大的气泡区域在连续液体中形成，并保持紧凑局部尺度，再过渡到选定的 reddish-brown 微距影像。程序化形成区在完整影像接管之前退场，不叠加为整页规则纹理。成熟表面的光学细节由经过筛选的生成影像提供，局部薄膜运动由实时 shader 负责。

这一短暂形成阶段没有独立漂浮的球体，也没有把油滴等同于 CO₂ 气泡。它是对复杂气液表面的视觉解释；科学依据与限度仍见 [SCIENCE.md](SCIENCE.md)。

## 代码与交付

| 文件 | 本轮职责 |
|---|---|
| `src/visuals/PorousWorld.js` | 颗粒表面、孔隙流束、透视路径与汇流投影 |
| `src/visuals/LiquidWorld.js` | 跟随细流的液面与泡胞形成，再进入完整 crema 表面 |
| `src/main.js` | 共享附着点、同一渲染时序与两个世界合计的绘制统计 |
| `src/styles.css` | 手机 crema 标题与说明的局部阅读衬底 |
| `production/models/`、`production/textures/` | 从最终程序重新导出的可复用几何和原始纹理 |
| `docs/QA.md` | 本轮实际浏览器检查、倒滚比较和环境限制 |

Lenis 继续作为唯一平滑滚动控制器。项目使用同一个 GSAP ticker 驱动滚动与渲染；精修没有加入第二个滚动时钟、依赖或重型后处理管线。最终 ZIP 只包含一份生产构建，临时预览副本、浏览器截图与测试过程文件均不进入交付。
