# CRAVE — Before the First Bite

**See the heat. Break the crust. Want the bite.**

一场关于「真正入口以前，视觉如何唤起食欲」的十一幕数字体验。

这是完整的本地项目交付：源码、可运行构建、九张正式 AI 食物原图、响应式图片、字体、来源记录与第三方许可均已包含。页面运行时不依赖外部图片、字体、接口或 CDN。

## 1. 直接观看

先完整解压 ZIP，保持目录结构。需要本机安装 **Node.js 22.12 或更新版本**；本次制作与验收使用 Node.js 24.19.0。

### Windows

双击 `START-WINDOWS.cmd`。启动器会打开本机浏览器，并保留服务窗口。关闭时按 `Ctrl+C`。

### macOS / Linux

在解压目录打开终端，运行：

```sh
sh START-MAC-LINUX.sh
```

也可以在任意支持的平台使用相同命令：

```sh
node scripts/preview.mjs
```

然后打开终端打印的本机地址，默认是 `http://127.0.0.1:4173/`。这个预览只绑定本机回环地址。若默认端口已被其他程序使用：

```sh
node scripts/preview.mjs --port 4174
```

**观看已附带的构建不需要运行 `npm install` 或 `npm ci`。** 不要直接双击 `dist/index.html`：浏览器对 `file://` 下的 ES modules 与媒体加载有限制。

`dist/` 仅保存一份编译后的 JavaScript、CSS 和 HTML；原本容易重复的图片与字体只放在 `public/`。预览脚本把两者作为同一个本地网站提供。因此请完整保留 `dist/`、`public/` 与 `scripts/`，不要单独拷走 `dist/`。

## 2. 观看方式与交互

滚轮、触控板和手机滑动控制叙事进度。任何时刻都可以停留、向前或反向观察。

| 操作 | 行为 |
| --- | --- |
| `Index` | 打开十一幕索引，直接跳到一个材质段落。 |
| 页底箭头 / 说明 | 进入下一幕；最后一幕的 `Once more` 回到开场。 |
| 键盘 `←` / `→` | 前一幕 / 后一幕；调节滑块时保持原生滑块操作。 |
| `Break the crust` | 从等待进入破壳与断面揭示。 |
| `Make the cut` | 进入刀缘、压力与分离的动作段。 |
| `Gold — Chestnut` | 单独控制表面的褐变，离开该幕后恢复滚动控制。 |
| `Thick — Flow` | 改变巧克力局部流动的速度与重量感。 |
| `Sound off / on` | 明确选择后才开启轻微的合成材质声音，默认静音。 |
| `Index → Motion` | 暂停装饰性运动；选择会保存在本机浏览器。 |
| `Esc` | 关闭索引并归还键盘焦点。 |

系统启用 **reduced motion** 时，页面保留完整图片、文字、章节导航和褐变调节，使用离散场景切换，暂停蒸汽、折射、跟随光和流动。此时巧克力流速控件明确禁用。

## 3. 创作结构

四种食物材料承担不同的观察任务：层酥、煎烤扇贝、厚巧克力、温热焦糖苹果挞。整盘摆放直到第九幕才出现。最后三幕使用同一只挞与同一只盘子的连续图像编辑，避免结束时忽然换一道食物。

| 幕 | 视觉任务 | 实现中的自建系统 |
| --- | --- | --- |
| 01 — Desire | 金色层片先于说明建立食欲。 | 透明层酥前景与 DOM 巨字穿插；克制的推进与表面光探针。 |
| 02 — Heat | 由接触油脂与细小表面变化感知热。 | 局部热扰动、接触区微泡、已有油脂高光的变化。 |
| 03 — Brown | 金色变成更深的褐色。 | 基于真实食物颜色和两块煎烤表面的选择性褐变场；滚动与滑块共同控制。 |
| 04 — Crust | 脆壳的等待、细裂、瞬间破开。 | 食物源图坐标中的不规则裂缝、短促 SNAP、受重力影响的少量碎屑。 |
| 05 — Inside | 与外壳相反的湿润、空气与薄膜。 | 独立断面素材、孔隙明暗与微小取景变化。 |
| 06 — Melt | 让流动具有重量。 | 限定于巧克力带及折叠处的向下运动场；可调流速。 |
| 07 — Glaze | 流动交接到包覆与反射。 | 重力方向的交接前沿、已有釉面高光的光探针。 |
| 08 — Steam | 密度降低，热度留在空气里。 | 两束稀疏、方向明确、逐渐消散的 Canvas 蒸汽。 |
| 09 — Plate | 材料首次成为完整的一份食物。 | 从微距到大留白的尺度释放，再缓慢准备切入。 |
| 10 — Cut | 刀缘、压力、分离。 | DOM 刀面、照片连续状态、切割前沿与少量落屑。 |
| 11 — Before the First Bite | 缺失的一角把最后一步交给想象。 | 同场景缺口、轻微残余蒸汽与最终取景释放。 |

完整研究、比较、拒绝与修订过程记录于 `docs/VISUAL-BIBLE.md`。研究来源与材料判断见 `docs/RESEARCH.md`。本作品采用视觉启发，不把褐变、流变或蒸汽表现当作科学模拟。

## 4. 修改与重新构建

只有编辑源码或重新构建时才需要安装锁定依赖：

```sh
npm ci
npm run dev
```

开发服务只监听本机。完成修改后：

```sh
npm run build
npm run preview
```

`package-lock.json` 锁定依赖。浏览器代码使用原生 JavaScript，未引入 UI 框架。

| 文件 | 职责 |

| `src/main.js` | 单一时钟、滚动距离、场景调度、导航、交互、可访问性与恢复逻辑。 |

### 唯一滚动与渲染时钟

Lenis 使用 `autoRaf: false`。只有 GSAP ticker 驱动 `lenis.raf()`、场景渲染、Canvas 与声音状态；Lenis 的 scroll 事件更新 ScrollTrigger。材质模块与空气模块自身均不启动 RAF 或 interval。所有破壳、交接和分离位置由滚动进度计算，反向移动会重建同一位置。

### 性能与恢复

- 一个 WebGL 画布，常驻纹理最多为当前图、下一张图和最近使用的一张图；无用的加载会取消。
- WebGL DPR 上限 **1.25**，最长边 **2400 px**，总像素上限 **400 万**。4K 视口不按设备 DPR 无限制分配。
- 气氛画布最长边不超过 **1500 px**；蒸汽只在相关段落存在，其他段落清空它。
- 停止滚动时，装饰运动有独立的绘制频率上限；所有模块仍由同一时钟调度。
- 隐藏标签页会停止滚动驱动、暂停声音与 ticker；恢复时重新同步实际位置。
- 浏览器未提供 WebGL、丢失上下文或某一图片规格失败时，会保留 / 切换到摄影图片；768 和 1536 两个规格可互相回退。
- 浏览器禁用 JavaScript 时，提供一条可阅读的静态图文叙事。

这些是资源分配与调度边界，不是对所有设备帧率的承诺。

## 5. 素材与许可

全部正式食物图像均为本项目的 **AI 生成素材**，不是声称来自真实餐厅、摄影师或现实拍摄的作品。未打包研究摄影师的图片、影片或其他未授权参考内容。

- 原生图像：**9 张 1536 × 1024 PNG**。没有把它们标为原生 4K，也没有为增加像素数而上采样。
- 浏览器图像：每张 PNG 对应两种 WebP 尺寸，保留透明前景；压缩参数见来源清单。
- 生成记录：**21 个已记录输出**，包括候选、六类研究拼图、段落概念和正式修订；只打包九张最终选用的原图及其正式导出。
- 没有视频文件、帧序列或三维模型；流动、破壳、热感和蒸汽由所列自建系统完成。
- 声音由 WebAudio 合成，没有第三方音乐或真实烹饪录音。
- Cormorant Garamond 和 Manrope 随附 SIL OFL 许可。Lenis、Vite 和 GSAP 按各自原许可归属；**GSAP 并非 MIT 许可**。

详细映射见 `ATTRIBUTION.md` 和 `licenses/THIRD-PARTY.md`。来源清单记录的是来源与加工事实，不替代各第三方的许可条款。
