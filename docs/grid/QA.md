## 字体加载与表面对比度

最终构建中，人工延迟本地 WOFF2 请求，分别检查 390 × 844 与 1440 × 900 的加载点和字体就绪后 ZERO 点。两者坐标最大差异小于 **0.012 CSS px**，属于小数像素取整。正式文字布局在三款字体准备完成后才显示，避免使用 fallback 字宽进行场景测量。

RAW、Electronic、Interface 相关交接在两种视口、六个进度位置共 **12 个实际浏览器画面**中，检查 subtitle、body、metadata、time/place 和 action 的文字颜色。测试读取计算样式、矩形、透明度，依照 paper → frame → RAW panel → 元素自身背景进行合成，并沿实际文字行采样。最低正常文字对比度为 **4.6788:1**。

该结果针对这些样本和合成表面，不是全站 WCAG 合规认证，也不是对抗锯齿像素逐点计算的对比度。展示字的轮廓、像素纹理和受控裁切属于另外的视觉规则；普通阅读文字与可操作控件保留独立的可读区域。
