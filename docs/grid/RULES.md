# GRID — Rules of the experiment

**Content stays. System changes.**

每幕从同一组内容出发，改变七类规则。一个 `h1` 和九个 `data-content` 节点保持身份；章节名、测量值和控制界面属于实验说明。下表规定作品的设计意图，不代替实际浏览器验收记录。历史依据见 [RESEARCH.md](RESEARCH.md)。

所有场景遵循 **Enter → Stable Composition → Living Hold → Handoff → Exit**。停留时的微调仍受当前系统约束；退出把现有元素交给下一套规则。可读副标题、正文、metadata 和 action 的信息不因展示字的实验裁切而丢失。

## 00 — ZERO

| 规则 | 决策 |
| --- | --- |
| Grid | 先只有一个 registration point 与一条基线的起点，让位置先于网格出现。 |
| Type | `GRID` 保留在画布中，以小尺度存在；第一次滚动再获得主标题的重量。 |
| Image | 摄影暂居最低视觉权重，不承担开场冲击。 |
| Spacing | 大面积留白；小元素之间的距离是主要构图。 |
| Color | 近白底、墨黑文字、一处克制的信号色。 |
| Interaction | 明确给出滚动入口，并允许直接打开章节索引。 |
| Motion | 点、线、字按可控时序获得秩序；不设置必须等待的开场动画。 |

## 01 — SYSTEM

| 规则 | 决策 |
| --- | --- |
| Grid | margin、baseline、columns 逐步成立；线是布局的可见依据。 |
| Type | 标题、数字与小字建立尺度层级，基线与关键左边缘形成联系。 |
| Image | 同一摄影进入矩形比例约束，与文字共用对齐线。 |
| Spacing | 间距来自统一单位及其倍数，空白被明确划分。 |
| Color | 白与黑负责结构，信号色标出正在成立的关系。 |
| Interaction | 滚动让观众观察基准建立；Rules 说明当前关系。 |
| Motion | 从点延展成线、从线建立列，内容连续迁移到目标位置。 |

## 02 — INTERNATIONAL

| 规则 | 决策 |
| --- | --- |
| Grid | 模块化、不对称构图；标题、图像与说明共享关键对齐线。 |
| Type | Grotesk、左齐、右侧自然参差；通过字级与行长建立清楚层级。 |
| Image | 客观摄影采用明确硬边裁切，比例由列结构约束。 |
| Spacing | 留白与内容块都可测量；移动端重新配置列数和行长。 |
| Color | 白、黑与少量红；红色只承担明确强调。 |
| Interaction | 章节跳转与当前系统读数保持精确、易识别。 |
| Motion | Align / Snap / Lock：快速抵达准确位置，稳定后保持纪律。 |

## 03 — BASEL / TENSION

| 规则 | 决策 |
| --- | --- |
| Grid | 栅格仍在；部分元素围绕可追溯的锚点越栏与偏移。 |
| Type | 受控旋转、拉伸、重叠或字距变化；保留读者判断偏离程度的参照。 |
| Image | 摄影被重新裁切、错开，使图文关系产生压力。 |
| Spacing | 一处收紧与另一处扩张相互补偿，避免均匀散乱。 |
| Color | 浅酸黄色画布、墨黑字形与少量红色参照，共同强化张力。 |
| Interaction | 滚动控制张力强弱；反向时回到原有锚点。 |
| Motion | Bend / Offset / Interrupt：不同元素有受控时差，仍指向同一稳定构图。 |

## 04 — TYPE AS IMAGE

| 规则 | 决策 |
| --- | --- |
| Grid | 字形轮廓成为构图边界；小字继续依靠可读的局部网格。 |
| Type | 同一 `GRID` 放大、硬裁切和位置重组，文字本身承担图像角色。 |
| Image | 摄影缩为辅助证据，减少对画面的主导。 |
| Spacing | 大字与小字构成强尺度差；为正文和 action 保留完整空间。 |
| Color | 用清楚的前景、背景关系凸显字形实部与空白。 |
| Interaction | 即使展示词被裁切，语义标题和核心阅读内容仍可访问。 |
| Motion | Scale / Crop / Shift：沿上一幕的张力继续推进，而非替换标题实例。 |

## 05 — EDITORIAL

| 规则 | 决策 |
| --- | --- |
| Grid | 用宽边距、正文列和图像出血安排阅读先后；移动端另行构图。 |
| Type | Instrument Serif 与无衬线、等宽小字分工，标题和说明呈现不同声音。 |
| Image | 同一摄影放大或出血；caption 与 folio 让图像获得出版物般的节奏。 |
| Spacing | 扩大呼吸空间，控制行长与段间距，使画面可以停留阅读。 |
| Color | 象牙白、墨黑与克制冷色，摄影色调保持安静。 |
| Interaction | 延长稳定构图的感受；导航和 action 不与内容争夺层级。 |
| Motion | Flow / Breathe / Pace：柔和连续的位移、裁切调整与尺度变化。 |

## 06 — RAW

| 规则 | 决策 |
| --- | --- |
| Grid | 暴露外框、分割边界与结构接缝，网格成为主动表达。 |
| Type | 大字、直接的层级、硬边裁切；碰撞围绕确定的边缘发生。 |
| Image | 明确的框线和直接裁切显露图像作为容器内容的身份。 |
| Spacing | 刻意压缩与释放同时存在；不能通过覆盖正文制造实验感。 |
| Color | 黑、偏白与一处酸性色强调。 |
| Interaction | 控件状态直接可辨，聚焦与点击区域保持完整。 |
| Motion | Cut / Slam / Interrupt：短促但有节制；中断的是节奏，不是元素身份。 |

## 07 — ELECTRONIC

| 规则 | 决策 |
| --- | --- |
| Grid | 模块量化为 cell、字符列与像素矩阵，媒介限制成为构图规则。 |
| Type | IBM Plex Mono 与像素化表达建立电子显示感；正文保持可读。 |
| Image | 对同一摄影实施受控 raster / scan 表现，继续保留相同主体。 |
| Spacing | 间距按离散单元组织，坐标、列边缘与字宽产生对应。 |
| Color | 黑底、冷白与克制磷光绿；少量信号色表达状态。 |
| Interaction | 让扫描、刷新和量化可被进度控制，保留常规导航与手动操作。 |
| Motion | Quantize / Scan / Refresh：短、离散、受控；避免大面积闪烁。 |

## 08 — INTERFACE

| 规则 | 决策 |
| --- | --- |
| Grid | 容器连续改变宽度；固定边距、流式列与断点约束共同作用。 |
| Type | 真正重新换行并调整字级关系，正文行长随容器改变。 |
| Image | 同一图片进入可响应的 media frame，比例与位置随布局调整。 |
| Spacing | 用一致 spacing 单位维持元素关系，窄容器中改变排列方式。 |
| Color | 中性表面配精确功能色，状态与装饰分工明确。 |
| Interaction | 宽度滑杆让观众亲自改变 frame，观察 desktop / tablet / mobile 的 reflow。 |
| Motion | Reflow / Resize / Respond：显示真实布局适应，不用缩放整张画布伪装响应式。 |

## 09 — VARIABLE

| 规则 | 决策 |
| --- | --- |
| Grid | 列比例与字形宽度相互呼应，小字和控件保留稳定锚点。 |
| Type | Roboto Flex 的 `wght`、`wdth`、`slnt`、`opsz` 四个实际轴连续变化。 |
| Image | 摄影保持辅助地位，以稳定对照突出字形的连续变化。 |
| Spacing | 字宽、tracking、行高与留白协调；变宽不以挤压正文为代价。 |
| Color | 浅冷色或近白表面、墨黑与一处克制紫色强调。 |
| Interaction | 四轴控制与 Reset 让观众比较字体状态，数值对应真实轴。 |
| Motion | Interpolate / Morph / Modulate：沿连续参数变化，避免仅切换预设字重。 |

## 10 — SYNTHESIS

| 规则 | 决策 |
| --- | --- |
| Grid | 共用精确基线与少量受控偏离；保持一套完整比例体系。 |
| Type | 当代可变字形承担主体，其他字级只承担必要的语义工作。 |
| Image | 同一摄影以最终裁切归位，与标题形成平衡。 |
| Spacing | Swiss 的纪律与 Editorial 的停顿合并为一个稳定节奏。 |
| Color | 重新收束中性与强调色，减少同时出现的色彩角色。 |
| Interaction | 仍能查看规则与返回章节；最终构图本身成为比较结果。 |
| Motion | 继承前面各幕的准确性、张力与连续性，完成统一的收束。 |

## 11 — NO GRID

| 规则 | 决策 |
| --- | --- |
| Grid | 逐条隐去辅助线，保留最终构图的坐标和比例关系。 |
| Type | 展示词、数字与小字完成层级，停留时仍是一张完整作品。 |
| Image | 摄影的最终裁切和位置保持稳定。 |
| Spacing | 空白不随辅助线消失而改变，证明秩序可以被感知。 |
| Color | 延续 SYNTHESIS 的最终配色，避免再引入一种新主题。 |
| Interaction | 允许停留、回看与返回开场；减少动效模式也保留这些入口。 |
| Motion | 只移除辅助关系的可见标记；最初的 registration point 回到原位，形成闭环。 |

## Continuous handoffs / 连续交接

| 衔接 | 同一元素如何改变规则 |
| --- | --- |
| ZERO → SYSTEM | registration point 延展出 baseline，再定义列；原有标题开始放大。 |
| SYSTEM → INTERNATIONAL | 未分化的列形成信息层级；摄影与文本吸附到明确的对齐线。 |
| INTERNATIONAL → BASEL | 保留基准，标题和摄影围绕各自锚点施加偏移与张力。 |
| BASEL → TYPE AS IMAGE | 扩大既有文字与裁切，让字形接管主体构图，摄影退居辅助。 |
| TYPE AS IMAGE → EDITORIAL | 同一词获得新的字体角色与阅读位置，空白打开，摄影重新取得空间。 |
| EDITORIAL → RAW | 边距转为可见边界，软节奏收紧，已有图文以硬裁切重新对峙。 |
| RAW → ELECTRONIC | 裸露边框细分为单元；同一图像量化，数字成为电子语境中的信息。 |
| ELECTRONIC → INTERFACE | 像素与字符列收束为可用容器，现有内容获得真实响应式约束。 |
| INTERFACE → VARIABLE | 容器关系保留，字体从适配屏幕进一步成为连续可调的材料。 |
| VARIABLE → SYNTHESIS | 字形状态与布局比例收敛至同一个完整构图。 |
| SYNTHESIS → NO GRID | 内容不搬家；线、测量、labels 依次退出，比例继续存在。 |
| NO GRID → ZERO | registration point 回到开场基准，让回看有明确的视觉联系。 |

这些交接不依赖整页淡出和下一页淡入。字体角色变化、图像处理与规则说明可以改变；核心内容和节点身份持续存在。反向滚动依据同一进度重建相同状态。
