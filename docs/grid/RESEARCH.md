# GRID — Research / 研究依据

Research date: 2026-10-07. 本文记录真实作品、来源与设计转译；后文的场景规则是本项目的原创判断，并非历史作品的复刻，也不是一条宣称设计必然线性演进的历史时间轴。

## 1. 最重要的研究结论

**规则应先于造型。** Karl Gerstner 的 *Designing Programmes*（1964）把字体、排版、图像与方法放在同一个设计程序中，是本项目最直接的思想参照。GRID 应固定内容，让比例、对齐、层级和媒介约束改变结果；“同一内容”的连续性比每幕的风格辨识度更重要。[出版方原版说明](https://www.lars-mueller-publishers.com/designing-programmes-0)

**Swiss 不是红、黑、Helvetica 的配方。** Müller-Brockmann 的 *Musica Viva*（1958）可用于研究节奏、几何与信息的关系；Ruder 的 *Typographie*（1967）强调结构、可读性、节奏与比例。Zürich 的构成秩序和 Basel 的教学实验有交集，不能把二者合并成“先死板，后自由”的故事。*Neue Grafik* 共十八期，出版于 1958–1965 年，其编辑集体为 Müller-Brockmann、Richard Paul Lohse、Hans Neuburg、Carlo Vivarelli；Ruder、Hofmann、Gerstner不应误列为该刊创办编辑。[MoMA](https://www.moma.org/collection/works/7233) · [Niggli](https://niggli.ch/en/products/typographie) · [Neue Grafik 出版方档案](https://www.lars-mueller-publishers.com/neue-grafiknew-graphic-designgraphisme-actuel-1958-1965)

**Basel 的张力来自对既有方法的熟练掌握。** Hofmann 的 *Giselle*（1959）提供文字与摄影、实形与反形的参照。Weingart 的字母、线条和叠片实验，提示我们先保留可识别的基线，再让字距、角度、裁切和图像分层向它施压。Museum für Gestaltung 的研究称他为尊重传统的创新者；他对新技术的态度并非全盘拥抱。因此本网站不应把他称作“数字排版发明者”，也不应把随机错位称作 New Wave。[SFMOMA 原作](https://www.sfmoma.org/artwork/2014.669/) · [Museum für Gestaltung 研究](https://museum-gestaltung.ch/en/article/wolfgang-weingart-typography-context) · [AIGA 档案实访](https://eyeondesign.aiga.org/museum-of-design-zurich-unveils-the-weingart-archive/)

**Editorial 的情绪来自节奏，而非换上衬线体。** Irma Boom 为 *Rijksmuseum*（2013）组织 Wijnanda Deroo 的建筑摄影；Julia Born 的 *An Ideal for Living*（2018）则以大小两级文字、满出血照片与较小物件图像的间隔产生阅读节奏。对 GRID 的转译是让同一摄影获得更长的停留、更大的边距与一处出血，让标题和说明承担不同声音；不新增内容伪造“文化感”。[nai010](https://www.nai010.com/en/product/rijksmuseum/) · [Centre culturel suisse](https://ccsparis.com/editions/an-ideal-for-living/) · [瑞士联邦文化局评述](https://www.schweizerkulturpreise.ch/en/an-ideal-for-living-3)

**Electronic 应显露媒介约束。** Crouwel 的 *New Alphabet*（1967）是对早期 CRT 显示限制的实验回应，不能误说成当时普遍使用的终端字体。MoMA 也记录其变体在 Joy Division 的 *Substance*（1988）封面中的应用，为电子音乐图形提供实际连接。Xerox Alto（1973）把位图显示与直接操纵界面结合；Susan Kare 的图标草图（1982–83）用方格纸的一格代表一像素。由 column → cell → pixel → interface 的变换，比“加绿色发光与扫描线”更有依据。[MoMA / New Alphabet](https://www.moma.org/collection/works/139322) · [CHM / Alto](https://computerhistory.org/press-releases/xerox-alto/) · [MoMA / Kare](https://www.moma.org/collection/works/188391)

**当代系统允许多样性，但共享关系。** Pentagram 的 MIT Media Lab 标识体系沿用七乘七栅格，让实验室与二十三个研究组的图形相互关联。IBM Carbon 的 2x Grid 则明确区分固定、流式与混合关系，并随断点重排。GRID 的收束应继承这种“关系连续”，而非拼贴所有历史符号。[Pentagram](https://www.pentagram.com/work/mit-media-lab/story) · [Carbon 官方规则](https://www.carbondesignsystem.com/building-blocks/foundations/2x-grid/overview)

## 3. Twelve scenes / 十二幕规则转译

所有章节使用一个 content set；章节名、测量值与轴值属于实验说明，不应替换正文。以下是设计提案，不是对上述作品形式的照抄。

| 幕 | 核心规则 | 构图与交接 |
| --- | --- | --- |
| 00 ZERO | 一个基准点定义空间 | 极小点与极细基线；大字尚未取得视觉权重。第一次滚动先产生基准，随后元素进入秩序。 |
| 01 SYSTEM | margin → baseline → columns | 线逐条成立；主标题、数字和说明找到同一组关键对齐线。只有关系被建立。 |
| 02 INTERNATIONAL | 不对称但可测量 | 左齐、明确层级、客观裁切；限制红色为一个信号。运动快速抵达精确目标。 |
| 03 BASEL / TENSION | 保留基准，扰动局部 | 一处旋转、一处字距扩张、一处越栏；其余元素作为参照，偏移才有意义。 |
| 04 TYPE AS IMAGE | 字形的轮廓承担画面 | 放大、裁切与重叠来自同一词；摄影缩成小证据。可读正文保持完整。 |
| 05 EDITORIAL | 用空白改变时间 | 衬线与无衬线分工；宽边距、一处摄影出血、细小 folio；移动端重新安排而非缩小跨页。 |
| 06 RAW | 暴露边界与层级 | 外框、分割、硬裁切成为主动构成。碰撞有明确锚点，action 保持可使用。此名称是项目命题。 |
| 07 ELECTRONIC | 连续空间量化为离散单元 | 栅格变 cell；图片变受控 raster；文字落在字符列。扫描只作用于媒介表面，非随机闪烁。 |
| 08 INTERFACE | 关系适应容器 | 同一元素随 desktop → tablet → mobile 的可见容器重新排布。保持阅读顺序和真实交互状态。 |
| 09 VARIABLE | 连续改变而非替换 | 字体实际支持的轴连续插值；字宽改变时边距和基线共同响应。轴信息可测，不假装所有字体都有全部轴。 |
| 10 SYNTHESIS | 留下有效决策 | 共用基线承载一处张力，边距控制节奏，细节精确；无需同时陈列所有历史特征。 |
| 11 NO GRID | 隐去辅助，保留关系 | 构图位置不变，辅助线顺序退场。最初的点回到同一基准，证明秩序已被内化。 |

## 4. Provenance / 使用边界

馆藏页面与出版物用于研究作者、作品、媒介及设计方法；本项目不把其图片或页面截图重新分发为素材。网站内的排版、栅格、几何标记和动效由原创 DOM / CSS / SVG / Canvas 构建。AI composition studies 只作为设计探索，不作为真实历史作品、字体字形或最终 UI。具体摄影与字体的文件来源、授权和处理记录应在交付包的 attribution / licenses 文件中单列。

研究保留一个区别：历史事实由以上来源支持；十二幕的配色、转场、尺寸和具体情绪是 GRID 的创作决策。网站没有宣称自己复原了任何时期的全部设计，也没有把某种电子显示颜色当作所有 CRT 的共同属性。
