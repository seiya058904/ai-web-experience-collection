# GRID

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vanilla TypeScript, semantic HTML, CSS Grid, SVG, a bounded raster Canvas, Vite, Lenis and GSAP ScrollTrigger. This implementation choice follows the brief's explicit DOM-first preference and single-scroll-authority requirement. No framework or 3D engine is necessary for the small persistent content tree.

## Users

Visitors exploring experimental graphic design on desktop, tablet and mobile screens. The mobile layout is part of the experiment.

## Product Purpose

Make the effect of design decisions visible by continuously rearranging one fixed content set. Success means the visitor recognizes the same information while its hierarchy, rhythm, material and emotional character change.

## Operating Context

Local development, local production preview, browser QA and a complete source ZIP. The user expressly prohibits all hosting, deployment and public previews.

## Capabilities and Constraints

- Twelve states, from ZERO through eleven systems, driven by deterministic reversible scroll progress.
- One content tree: GRID, its subtitle, 08, one paragraph, one photograph, one metadata block, one time/place, one action and one geometric mark.
- Real variable font axes, local legally distributable fonts and photography.
- AI composition studies precede implementation; no AI bitmap becomes website UI.
- Chapter index, visible rules, reduced motion, keyboard navigation and a meaningful no-JavaScript composition.
- Final delivery is one ZIP with source, assets, licenses, provenance, research and instructions. Dependencies, caches, debug artifacts and temporary QA captures are excluded.

## Brand Commitments

GRID — The Architecture of Visual Order. Content stays. System changes. Typography, composition, motion and rules are the work. The defined Swiss, Basel, editorial, raw, electronic, interface and variable directions are binding; they are not interchangeable proposals.

## Evidence on Hand

Research is recorded in docs/RESEARCH.md. This is an original visual experiment, not a real event or institutional identity. The fixed date/place and series metadata are authored specimen content, not claims about a physical exhibition. Photograph and font licenses are recorded separately.

## Accessibility & Inclusion

Semantic text remains accessible; actions are keyboard reachable. Focus, contrast, dynamic viewport resizing, system and in-app reduced motion, and no-JS fallback are required. The large display word can be deliberately cropped; the readable subtitle, body and action cannot.
