# Direction contract

**Mode: Experience.** User-pinned direction; this document records implementation choices inside the supplied brief, rather than offering substitute identities.

**THESIS.** A single persistent specimen changes under a program of design rules. Identity is demonstrated by uninterrupted physical movement of the same elements.

**OWN-WORLD.** Quiet instrument-like chrome surrounds an expansive typographic canvas. Local Roboto Flex, Instrument Serif and IBM Plex Mono form the material vocabulary. White, ink, signal red, ivory, acid yellow, phosphor green and restrained lilac are scene-level decisions.

**STORY.** A point becomes an alignment; alignment becomes order; order is questioned, published, exposed, quantized and made responsive; continuous type then resolves into a final composition whose guides vanish.

**FIRST VIEWPORT.** A near-white field, one registration point near the centre, a small word at the lower left and an explicit scroll invitation. The first scrolling movement draws the baseline and grows the existing word into a poster-scale heading. No full-screen waiting animation.

**FORM.** A bounded live poster, with fixed slim header, chapter rail and an optional rules sheet. The twelve named rules in the user brief are the binding source. AI boards are composition research, not pixel screenshots to embed in the application.

**SIGNATURE.** The same elements migrate without page crossfades. An interface viewport contracts through desktop, tablet and mobile proportions while the actual text reflows. Variable-font controls interpolate four real axes. Finishing removes the grid without displacing the final composition.

**FINISH.** The independent finish review resolved all six identified material fixes. The delivered system is documented in [DESIGN.md](../DESIGN.md), with measured verification scope in [QA.md](QA.md). Every shipped raster has provenance. Delivery is one local-only source ZIP with a single production build.
