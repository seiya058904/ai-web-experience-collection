# VEIL — Fabric in Motion

一个由纤维、织面、褶皱、透光与空间形体构成的交互式数字装置。滚动让同一件材料连续变形；停下时，织物仍有轻微的呼吸与光影变化。

完整源码、字体、三张辅助生成图、依赖锁文件和可直接预览的 `dist/` 均包含在交付包中。

## 直接打开作品

先完整解压 ZIP。需要 **Node.js 22.12 或更新版本，推荐 Node.js 24**；[Node.js 官方下载](https://nodejs.org/)。预览已有 build 不需要安装 npm 依赖。

- **Windows：** 双击 `START-VEIL.cmd`。
- **macOS / Linux：** 在项目目录执行 `sh start-veil.sh`。
- **命令行：** 执行下方命令，再访问终端显示的地址。

```sh
node scripts/preview.mjs --open
```

默认地址为 <http://127.0.0.1:4173/>。服务只监听本机，终端保持打开；按 `Ctrl+C` 结束。启动脚本会尝试打开默认浏览器；若未自动打开，复制终端地址即可。

端口被占用时：

```sh
node scripts/preview.mjs --port 4174 --open
```

请通过本地 HTTP 地址访问。直接双击 `dist/index.html` 会使用 `file://`，浏览器会限制 JavaScript 模块和资源加载。

## 开发、构建与预览

修改源码前，在项目目录安装锁定版本的依赖。`npm ci` 需要访问 npm；完成安装后，开发、构建和作品运行均不依赖在线 API。

```sh
npm ci
npm run dev
```

开发地址：<http://127.0.0.1:5173/>。

```sh
npm run typecheck
npm test
npm run build
npm run preview -- --open
```

`npm run build` 先执行 TypeScript 检查，再生成 `dist/`；`npm run preview` 使用同一份无外部依赖的 Node 静态服务器。构建采用相对资源路径，源码入口为 `index.html`，页面逻辑从 `src/main.ts` 开始。

## 如何体验

滚轮、触控板或触屏纵向滚动控制完整叙事，可随时停住或反向。右上角 **Index** 可直接进入任一研究；桌面底部有章节导航，手机底部使用前后章节按钮。桌面移动指针会轻微改变织物的空间响应。

| 章节 | 画面与交互 |
| --- | --- |
| Opening | 巨型 VEIL 字形与悬浮布料建立同一片空间。 |
| 01 / Thread & weave | 丝线汇成织面；**Weave** 滑杆改变织线密度。 |
| 02 / Drape | 织面形成悬挂褶皱；**Tension** 调整松弛与拉紧。 |
| 03 / Light | 暗色环境中多层薄纱承载光；**Light** 调节光线。 |
| 04 / Form | 平面形成雕塑般的轮廓；**Release the fold** 用 1.35 秒平滑松开褶皱，**Restore the fold** 恢复此前的张力。减少动态模式下直接切换。 |
| 05 / Detail | 拉近到立体经纬纱线与细丝，观察交错结构。 |
| 06 / Veil | 织物展开为完整空间；**Begin again** 返回开场，**About this study** 查看作品说明。 |

右上角的暂停按钮或 Index 内的 **Pause ambient motion** 可以暂停环境运动，滚动和材料控制仍然可用。此偏好只保存在本机浏览器。系统开启 `prefers-reduced-motion` 时，自动取消平滑滚动、持续呼吸和指针扰动，按静止构图呈现章节；页面中的暂停按钮会说明当前跟随系统设置。

作品需要 JavaScript。完整立体版本需要浏览器支持 WebGL 2；若 WebGL 不可用或上下文丢失，会显示带提示的轻量静帧版本，保留章节导航与内容，并隐藏需要实时三维渲染的材料滑杆和 Form 控制。可使用 <http://127.0.0.1:4173/?render=still> 主动查看该版本。

## 实现结构

- **连续几何：** 同一套参数化布料网格以 morph targets 串联主要形态，辅以可见纱线、经纬微观几何、缝线与多层织物。
- **材质与光：** Three.js `MeshPhysicalMaterial`、生成的丝织 albedo 样本、程序法线、丝绸 sheen、方向性高光和自定义薄纱着色；材质图加载失败时使用完整的程序织纹。形体、空间与光影由实时场景搭建，两张场景图用于初始画面和兼容版本。
- **时间与滚动：** GSAP ticker 统一驱动 Lenis、ScrollTrigger 与渲染器；滚动坐标决定场景，环境时间只负责微动。`src/timeline.ts` 定义 Enter → Stable → Hold → Handoff → Exit 的构图节奏。
- **适配：** 移动端使用独立构图、章节高度与导航；WebGL 像素比受限，不可见章节的独立几何停止绘制，页面隐藏时停止渲染。
- **资源：** 字体、脚本和图像全部随作品本地提供；无 CDN、账户、API key、后端、遥测或第三方服务调用。

形态与动态是为视觉表达设计的参数化艺术模型，**不用于预测真实面料的力学行为**。透明薄纱与光影是实时视觉近似。

| 路径 | 用途 |
| --- | --- |
| `src/main.ts` / `src/style.css` | 交互、滚动、对话框、响应式与页面视觉。 |
| `src/timeline.ts` | 可正向、反向和跳转采样的统一时间线。 |
| `src/visual/` | 布料、纱线几何、材质与实时场景。 |
| `public/` | 本地图片和网站图标。 |
| `tests/` | 时间线与必要回归检查。 |
| `scripts/preview.mjs` | 仅依赖 Node 标准库的本地预览服务器。 |
| `dist/` | 本次交付的生产构建；可由源码重新生成。 |
| `ATTRIBUTION.md` / `licenses/` | 参考来源、生成素材记录与第三方许可全文。 |

## 验收记录 / Validation

验收日期：2026-10-06。使用 Node.js 24.19、Chromium 153 与本地 HTTP 生产构建进行检查；浏览器使用 SwiftShader 软件渲染。交付的 `dist/` 为通过检查的生产构建。

- **构建与逻辑：** TypeScript、生产 build、9 项时间线测试通过。时间线检查包含生命周期边界、6,851 个位置的完整扫描、反向采样、跳转与退化输入。
- **逐屏构图：** 完成 17 张最终稳定构图的逐张检查，覆盖下表五种视口；未发现水平溢出、章节内容裁切或固定导航错位。
- **交互：** 章节导航、Index、说明面板、键盘 Escape、跳过链接聚焦、三个材质滑杆、Form 平滑展开及快速反复复原、暂停控制均通过。Form 恢复最后由滑杆设定的张力。
- **滚动与恢复：** 已检查极慢滚轮、高频滚轮、快速反向、Home / End 打断惯性、调整窗口后立即导航、导航途中调整窗口、加载后立即滚动，以及标签切换回程、浏览器冻结与恢复。1080p、1440p 和 4K 均完成全部章节的顺序滚轮遍历与反向返回。
- **移动与兼容：** 通过浏览器触摸事件执行真实触摸滚动路径；动态切换 `prefers-reduced-motion`、主动静帧模式、实际 WebGL 上下文丢失与恢复均通过。检查中未出现未预期的浏览器脚本错误、警告或资源加载失败。
- **Living hold：** 静止滚动位置下的画面持续微动已通过图像对比确认；用键盘暂停环境运动、保持指针不动后，两次画面像素一致。
- **本地启动：** 无 npm 依赖的预览服务器通过 36 项检查，涵盖静态资源、MIME、HEAD、错误请求、路径边界、端口与关闭行为。

| 390 × 844 | 全部七个构图；手机导航、裁切与控件位置。 |
