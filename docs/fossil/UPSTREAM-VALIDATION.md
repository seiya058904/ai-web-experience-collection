# FOSSIL — 最终验证记录

日期：2026-10-07。验证对象：ZIP 中的完整本地项目。

## 验证结论与范围

十章叙事、六套定制视觉系统与所有主要交互已完成浏览器验证。桌面 1586 × 992 和模拟触屏手机 390 × 844 各检查十个稳定构图；两组均无横向溢出、JavaScript 错误、资源加载失败或自动发起的远程请求。另行验证了本地文件打开、减少动态效果、4K 画布预算和禁用 JavaScript 的阅读模式。

浏览器为 **Chromium 153.0.8010.0**，通过 Playwright 执行真实页面点击、键盘、指针和滚轮操作并检查截图。云端浏览器无法连接执行环境的本地地址，因此采用与本地预览服务器处于同一环境的 Chromium。手机结果来自视口和触摸能力模拟；没有据此声称完成实体 iPhone、Android、Safari 或 Firefox 的兼容性认证。

独立视觉复核检查了桌面与手机十章、索引和档案界面，以及六套系统的实现。唯一阻碍交付的问题是桌面 Preservation 的 Mold 控件落在深色化石纹理上。修正为覆盖整个控件区的浅 limestone 渐变后，四种保存状态均重新截图复核；标签、编号和选中指示清晰，标本主要轮廓保留，未发现这次修正引入的直接问题。独立复核最终结论：**ship**。

## 数值数据与渲染一致性

这是一套**合成的解释性体数据**，没有将生成图像宣称为真实馆藏摄影，也没有将程序输出宣称为仪器采集 CT。

- 原始密度场为 **192 × 192 × 72** 的 uint8 数据，轴顺序为 Z / Y / X。
- **72 张 PNG** 与原始密度场对应截面一致；浏览器内嵌数据与原始文件一致。
- OBJ 和浏览器网格来自同一个等值面：**190,744 顶点、378,128 三角形**。
- OBJ / 浏览器网格对齐误差在 **0.00004 个无单位模型坐标**以内。
- 截面始终使用同一体积边框进行等比容纳；外缘较薄的切片不会被单独放大填满画面。
- WebGL 路径完成独立渲染检查，`glError = 0`，无 JavaScript 错误。
- CPU 路径使用同一网格的 **768 × 776** 深度与光照栅格，再合成轮廓；没有用放大的接触表缩略图代替体积。
- 扫描缓存限为 **12** 张。连续遍历所有 72 个截面后缓存仍受限。

机器可读证据见 [verification.json](../../public/fossil/data/verification.json)、[browser-verification.json](../../public/fossil/data/browser-verification.json) 与 [webgl-verification.json](../../public/fossil/data/webgl-verification.json)。数值一致性检查证明各文件表示同一套数据，不构成古生物学或医学准确性证明。

## 离线、可访问性与性能

| 环境 / 条件 | 验证结果 |
| --- | --- |
| 本地 HTTP 预览 | 无运行时外部依赖；主要交互、字体、图像与数据均来自项目目录 |
| 直接打开 `index.html` | Chromium 的 `file://` 模式下扫描、保存方式降级和记录下载可用；无资源或脚本错误 |
| `prefers-reduced-motion: reduce` | 环境运动关闭，导航即时定位，单个稳定章节可见；保留故事与手动控件 |
| 390 × 844 手机模拟 | 十章无横向溢出；减少同时出现的图层和标签；体积使用 CPU 路径 |
| 3840 × 2160 | 构图可用；单 Canvas 分配受约 2.8 百万像素预算限制，包含比例小于 1 的情况 |
| JavaScript 禁用 | 十章正文和本地图片仍可阅读；依赖脚本的控制不冒充可用功能 |
| 页面隐藏 / 对话框打开 | 根调度停止不必要的场景绘制；子系统没有第二套动画循环 |

Lenis 1.3.26 是唯一全局平滑滚动控制者。Canvas 子系统由根帧调度统一驱动。静态地质帧按相关状态变化重绘；切片缓存受限；重建仅在需要的场景参与渲染。原生按钮、range、对话框、可见焦点与屏幕阅读描述保留在 HTML 中。

一次 CPU 缓存绘制抽样的 20 帧合计约 109.3 ms，此数值只描述该次无头 Chromium 的已缓存绘制，不包含冷启动、完整页面合成和真实设备热状态，因此没有据此承诺 60 FPS 或所有设备的性能。

## 修正与发布检查

最终验证前已修正覆盖层拦截刷除指针、离线字体 preload 引发的 CORS 错误、手机文字与图像碰撞、若干小标签对比、图像比例和保存方式控制区背景。相关交互或环境均针对性复查。最终完整章节截图后只追加了上述桌面保存方式对比修正，并重新检查其四种状态。

项目附带以下可复现命令：

```sh
npm run verify
npm run build
python3 scripts/generate_volume.py --verify
```

前两项无需安装 npm 依赖。第三项使用可选的 [requirements-procedural.txt](../requirements-procedural.txt)。静态验证覆盖十章结构、本地依赖、离线脚本、连续场景权重、逆向确定性、单一滚动/帧调度、合成数据声明和授权文件；构建输出为可本地预览的 `dist/`。ZIP 保留完整源码、原始与正式图像、设计参考、数值文件、模型、来源和许可，不重复打包可由命令生成的 `dist/`。

完整文件散列见根目录 `CHECKSUMS.sha256`。本项目没有公开部署。
