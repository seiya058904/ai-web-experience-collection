01 / DESIGN INTENT

The object leads.The evidence follows.

物体先于说明，形态先于结论。

FOSSIL 的视觉重心是一件具有尺度、重量与缺损的石质对象。沉积覆盖它，矿物和印痕保存它，准备工作暴露它，切片和几何帮助阅读它，目录让它能够继续被研究。

整站采用同一套克制的博物馆语言：极近的物体尺度、缓慢的相机关系、宽阔负空间、细衬线与真斜体、少量有依据的标记，以及可以停下来的交互。

阅读本册

十张大幅场景图均标记为 Design reference / 设计参考。它们用于确定构图、光线、材质与排版，不是成品截图。正式素材已通过图像生成／编辑重新制作成无字 plate 或透明物体；文字、控件、遮罩、切片与重建关系由原生页面和程序重新建立。

02

Three worlds,三种观看方式，共用一套视觉秩序

Geology、Specimen、Imaging 共同围绕“痕迹如何变得可读”。章节之间可以交叠；物体的尺度、光线方向、细线语言和文字层级负责连接这些观看方式。

Geology

层、压力、包覆

石灰岩、页岩、铁褐色沉积与微小颗粒；以横向的床层、粗糙边界和岩石密度组织画面。变化来自沉降、压实、遮蔽与局部显露。

主要关联：Strata、Burial，以及 Preservation / Exposure 中的母岩关系。

Specimen

实体、光、静止

标本像雕塑一样占据画面。侧光读出肋纹，透射光进入琥珀，支撑物与抽屉恢复尺度。照片质感保持真实，素材身份保持明确。

主要关联：Specimen、Preservation、Exposure、Amber、Archive、Deep Time。

Imaging

剖面、轮廓、缺损

灰度、截面、空间间隔与部分等值面构成更严格的秩序。切片、轮廓和网格共享合成数据来源，缺失部分继续作为信息存在。

主要关联：Scan 与 Reconstruct，并通过轮廓进入和离开。

材质承担叙事

岩层、壳体、树脂、纸张与灰度切片各自保持可辨认的物性。

留白承担节奏

标题周围有完整的阅读区域；必要说明进入展签般的尺度。

缺损承担诚实

生成图像、解释性剖面和不完整重建始终保持清楚的身份。

04

Six native systems固定的六个系统，贯穿十章

各章共用系统，避免每一屏成为孤立的动画海报。以下名称保留原始设计 brief 的六项划分；滚动时序作为共同的组织方式，另列于下一节。

01

CHAPTERS 02 · 03

strata / layer system沉积层系统

用一套连续的层理语言组织沉降、压实、覆盖与章节交接。床层保留不规则边界、横向延展和不同材质，不把层厚等同于统一的时间刻度。

原生实现无字层理纹理映射到原生床面路径；沉降间隙收束后床面连续接合。按同一进度计算进入与逆向返回，保留相对床序。

strata.webp · geology.js

02

CHAPTERS 03 · 04 · 05

fossil reveal / mask system显露与遮罩系统

遮蔽、显露和材料替换作用于具体的石面与支撑关系。界面表达出“移除了什么、保留了什么”，让过程可以停下来观察。

原生实现沉积前缘、形态遮罩、局部基质 patch 与松散 dust coat 分层处理。刷扫只清除尘层，显露程度由原生控制驱动；重置具有明确含义。

FossilGeology · exposure.webp

03

CHAPTERS 01 → 10

specimen contour system标本轮廓系统

轮廓是石材、印痕、包裹物和成像之间共享的观察语法。它出现得少、细、断续，并始终有物体或数据来源。

原生实现材料章节使用与照片区域对应的形态路径；成像章节从合成剖面与几何中获得轮廓。进入 Scan 时以轮廓完成观察方式的交接，而不硬拼不同来源的半幅图像。

geology.js · imaging.js

04

CHAPTERS 07

CT slice system虚拟切片系统

“内部可读”来自一个明确的体数据，不来自照片变灰或装饰性的扫描光。当前剖面、缩略图和切片索引使用相同的切片来源。

原生实现包内保存 192 × 192 × 72 的合成标量场与 72 张无损灰度平面；浏览器脚本嵌入同一份数据，直接 file 打开也不依赖网络获取。索引只表示合成深度。

数据说明 · volume-metadata.json

05

CHAPTERS 07 · 08

volume reconstruction system部分体积重建系统

从切片关系进入不完整体积。外部肋纹、内部隔壁和作者指定的缺损保持区别；缺失区域不被自动补成完整生命。

原生实现网格由存储的合成体场提取。正常 WebGL 与 768 px CPU 栅格化回退读取相同的三角面与法线，保留同一组缺损；Outline 与 Volume 提供两种读法。

OBJ 网格 · 几何参数与缺损记录

06

CHAPTERS 09 · 全局记录

archive / catalog system档案与目录系统

把对象、碎片、保存状态和来源说明放在同一份可继续阅读的记录里。档案气质来自文字关系和尺度，不依靠密集界面。

原生实现无字抽屉照片与原生目录文字分离；语义化记录窗口保留来源与局限。内部研究编号与真实博物馆登记号保持清楚的身份说明。

archive-drawer.webp · PROVENANCE.md

05

One clock. Five phases.一个滚动时钟，五个镜头阶段

Lenis 是全局平滑滚动的单一组织者；主场景维护统一时钟，再把同一章节进度交给材质与成像模块。进度描述屏幕编排，不能被解释为地质年代或过程持续时间。

阶段参考区间设计职责
Enter0–17%继承前一章的亮度、方向或轮廓，为新物体建立位置。
Stable17–30%形成完整可读的构图；物体、标题、说明和控制都找到稳定区域。
Living Hold30–67%允许停留和观察；微动、模式比较或切片选择都不能破坏阅读。
Handoff68–93%让层、边界、光线或数据关系承担下一章的进入。
Exit90–100%撤回上一章的文字与交互目标，让新的观察方式完成接管。

参考区间允许交接与退出局部重叠。实际章节速度受内容、屏幕尺寸与减弱动态偏好影响；每章的构图与交接要求见后文。

正向与逆向都保有对应关系

沉积覆盖、材料显露与切片索引尽量由同一进度计算。观众往回滚动时，返回相应状态；手动控件的覆盖状态有明确的“恢复序列”入口。

模块不争抢动画权

地质与成像模块由主循环调用，不各自建立 RAF。非活动章节停止绘制，未变化的材质保留，后台页面和暂停设置约束持续工作。

主场景与交互 · 公共进度与混合函数 · 包内 Lenis

SPECIMEN WORLD

Specimen让物体先成立

章节索引 ↑
Life, held in the quiet of stone.

第一眼建立“博物馆里的石质雕塑”。菊石与母岩保留真实的重量感、自然断口和极近的尺度；大字、暗场和侧光一起定义安静的观看距离。

稳定画面近黑背景；巨大的 FOSSIL 与斜体副标题位于左侧，石板占据右侧大部分画面。字与物体各有完整的可读区域，留白承担节奏。

02Stable稳定构图

04Handoff交接

05Exit退出
文字退场，石质明暗延续到新的层面，不制造突然的空白。

02

GEOLOGY WORLD

Strata把时间读作层

章节索引 ↑
Time is not a clock. It is a layer.

通过不均匀的沉积层、水平延展和微小的压实位移，让观看者感知表面如何变成深度。图像中的厚度与编号只表达相对次序。

稳定画面上部保留浅色标题区，下方约三分之二由石灰岩、页岩和铁褐色床层组成。侧边刻度细而安静，与自然床面保持联系。

01Enter进入
先看见不同床层间的微小间隙，浅色负空间保持完整。
02Stable稳定构图
层面沉降并接合，形成连续、可信的岩层截面。
03Living Hold可停留的变化
可感知的变化主要来自细小压实与深度差，纹理保持自身尺度。
04Handoff交接
床层扩展至画面上方，明度转深，成为 Burial 的环境。
05Exit退出
刻度和标题撤离，横向岩面继续承载被遮蔽的形态。

PRODUCTION DECISION / 正式实现

正式场景把照片纹理映射到原生分层轮廓中；移动端保留纹理纵横比，缩减额外采样与位移。

strata.webp · 带自然透明上边界的无字层理素材。

GEOLOGY WORLD

Burial表面合拢

章节索引 ↑
The surface closes.

沉积遮蔽形态，但对象和周围母岩仍然保持连续。视觉重点是可见度逐渐改变，而不是一个标本忽然被替换成另一张图片。

稳定画面深色层理占满画面；左侧文字区保持低对比的安静背景。右下区域只留下若隐若现的菊石及边界。

GEOLOGY / SPECIMEN WORLD

Preservation留下形态的几条路径

章节索引 ↑
Form leaves. A record remains.

将保存机制落实到同一块石头上的孔隙、矿物、负形和正形。展签级说明保持简短，观众可以自己切换四种模式。

稳定画面奶油色博物馆对页；大尺度肋纹菊石位于右侧，左侧标题和说明清晰。下缘的四个模式形成一条细致的文字基线。

01Enter进入
沉积环境变亮，壳体、浮雕与印痕进入同一个画面。
02Stable稳定构图
保持同一标本的轮廓与母岩关系，建立可比较的静态构图。
03Living Hold可停留的变化
Pore infill、Replacement、Mold、Cast 改变材料与凹凸读法，文字同步说明。
04Handoff交接
把可比较的外缘交给准备工作的局部边界。
05Exit退出
模式控制离开焦点顺序，石面和纹理衔接到 Exposure。

PRODUCTION DECISION / 正式实现

四模式是解释性的材料处理。照片、原生遮罩和像素／滤镜变化共同工作，不把这些效果当作实测矿物分析。

preservation.webp + 原生孔隙痕迹、矿物线、轮廓遮罩和凹凸明暗。

05

GEOLOGY / SPECIMEN WORLD

Exposure少移除一点，多读出一点

章节索引 ↑
Remove less. Read more.

把准备工作表现为谨慎的局部阅读：先去掉松散颗粒，再控制局部基质的显示范围，始终保留支撑痕迹的岩石。

稳定画面菊石和母岩极近，左侧依次排列短说明、揭露程度与检视入口。细工具和散粒承担真实的比例参照。

01Enter进入
表面带有适度清晰的松散尘层，标本形态已有线索。
02Stable稳定构图
肋纹、母岩和准备边界同时可见，控件处于可操作的位置。
03Living Hold可停留的变化
暂停观察；拖动轻扫只清除松散尘粒，滑杆控制局部基质的渐次显露。
04Handoff交接
已显露的边界收束为一处微小痕迹，光线向琥珀的透射光过渡。
05Exit退出
退出检视状态，释放指针交互；需要时可恢复自动序列并重置尘层。

PRODUCTION DECISION / 正式实现

刷扫与基质揭露是分开的原生表面。刷子不会把完整硬岩魔法般擦掉；周边支撑母岩始终存在。

exposure.webp + 独立 dust coat、局部 patch masks 与 brush mask。

SPECIMEN WORLD

Amber另一种静止

章节索引 ↑
A different kind of stillness.

用透射光与内部深度展开另一种保存语言。巨大的不规则琥珀是物质本身；包含物只是一处微小而难以辨认的有机痕迹。

稳定画面左侧深黑、文字温柔克制；右侧占据大部分画面的蜂蜜色树脂从内部发亮。外轮廓自然，内部裂纹与杂质有深度。

01Enter进入

03Living Hold可停留的变化

04Handoff交接
细小的包裹痕迹与注册线把观察方式引向内部切面。
05Exit退出
琥珀整体淡出，留下秩序更严格的轮廓与成像坐标。

PRODUCTION DECISION / 正式实现

不赋予包含物具体物种身份，也不提出完整 DNA 或复活叙事。树脂图像仍属于项目创作的解释性素材。

IMAGING WORLD

Scan从完整表面进入完整切片

章节索引 ↑
Read beneath the surface.

由材质观看转向内部阅读。秩序来自一份真实存在于交付包中的合成体数据：缩略图、当前剖面与后续重建应彼此对应。

稳定画面暗场中显示一张完整的合成剖面；五张取样缩略图与 72 段的索引控件留在清晰的原生区域，文字明确标记 synthetic volume。

01Enter进入

08

Keep the reading intact.移动端、减弱动态与离线适配

适配的优先级是保留十章的阅读逻辑、可操作控件、材质比例与数据关系。屏幕更小或动态被关闭时，变化量与绘制成本可以下降，内容与关键控制仍然可达。

范围移动端 / Mobile减弱动态 / Reduced motion
构图与文字标题优先占据上部约三分之一；物体在中下部重新取景。大字按阅读区域重排，界面不依赖整屏图像缩小。直接呈现稳定构图。关闭持续漂移、相机式呼吸与非必要的长距离过渡，保留文字和对象之间的关系。
地层与材质保持照片纹理纵横比；减少边界采样、粒子与额外位移。低 DPR 使用可接受的下限，避免过度放大纹理或绘制负担。床层以稳定的压实状态呈现；保存模式仍可切换，揭露程度仍由可访问的控件调整。
表面检视滑杆是完整的替代操作路径。触控保留纵向滚动，精细刷扫只是补充；按钮保持足够的命中区域。检视、滑杆、刷扫和重置照常工作。尘层的变化由观众操作触发，不依赖自动运动。
切片与体积保留全部切片范围、代表性缩略图以及 Outline / Volume。降低渲染分辨率和持续更新频率，仍消费同一份数据。选择一张可读剖面与稳定视角；切片控制与显示模式继续可用。部分体积与缺损不会消失。
导航与焦点Index 提供直接章节跳转，底部章节信息保留；原生按钮、输入和记录窗口承担操作。跳转采用直接到达或短过渡。非活动章节退出交互焦点顺序，焦点样式保持清楚。
离线与回退字体、WebP、脚本与体数据均为包内相对路径。页面可直接 file 打开；网络不是阅读手册或基本展览的前置条件。局部像素读取受 file 安全限制时使用原生滤镜／轮廓回退；体积有同源 CPU 路径，图像加载失败时保留可理解的静态内容。

本册记录设计与实现约定，不给出正式性能或浏览器验收结论。实际运行以交付包中的页面、源代码及相应运行说明为准。
