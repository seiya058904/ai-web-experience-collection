# FACET — The Light Within

一场由宝石、切面、抛光、内部深度与光组成的连续数字展览。七个章节共享一个实时舞台，最后进入可逐件近看的六件标本展厅。

本交付包含完整源码、必要本地资源、依赖锁定文件与生产构建 `dist/`。不需要账号、API Key 或后端服务。

## 直接运行交付版

安装 Node.js 后，在解压后的项目目录打开终端：

```bash
node serve.mjs
```

在浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。该命令使用 Node.js 自带模块提供 `dist/`，无需执行 `npm install` 或 `npm ci`；终端内按 `Ctrl+C` 停止服务。服务只监听本机回环地址。

也提供便捷启动入口，仍需先安装 Node.js：

- **Windows：** 双击 `START-WINDOWS.cmd`。
- **macOS / Linux：** 在项目目录运行 `sh ./START-MAC-LINUX.sh`。

这两个入口与 `node serve.mjs` 使用同一服务，只在终端打印本机网址，不会自动打开浏览器。如果默认端口已被占用，可改用 `node serve.mjs --port 4174`，再打开终端显示的新地址。

请通过这个 HTTP 地址打开展览。直接双击 `index.html` 使用 `file://`，不能可靠加载模块与相关资源。

## 开发、构建与预览

### 环境

推荐 **Node.js 24.x**；也可使用 **Node.js 22.18 或更新的 22.x**，并使用随 Node.js 提供的 npm。

锁定的 Vite 8.3.3 在其 `package.json` 中声明 Node.js `^20.19.0 || >=22.12.0`。项目测试直接使用 Node.js 的 TypeScript 类型剥离能力，因此全流程统一建议上述 Node.js 版本，不以仅满足 Vite 要求的 Node.js 20 作为开发环境。

### 第一次安装

```bash
npm ci
```

`npm ci` 按 `package-lock.json` 安装确切依赖版本。首次下载依赖通常需要访问 npm；生产构建在浏览器中运行时使用随包提供的本地资源。

### 启动开发服务

```bash
npm run dev
```

打开终端显示的地址，通常为 [http://127.0.0.1:5173](http://127.0.0.1:5173)。源码修改会触发开发服务更新。

### 测试与类型检查

```bash
npm test
npm run check
```

`npm test` 运行项目的 Node.js 测试；`npm run check` 单独执行 TypeScript 检查。

### 重新构建

```bash
npm run build
```

该命令先执行 TypeScript 检查，再生成新的 `dist/`。修改源码、字体、静态资源或许可文件后，应重新构建，使交付版与源码保持一致。

### 预览重新构建的版本

```bash
npm run preview
```

打开终端给出的地址，通常为 [http://127.0.0.1:4173](http://127.0.0.1:4173)。也可以停止预览服务后重新使用 `node serve.mjs`。不要让两个服务同时占用同一端口。

| Light | 光起 | 光从黑暗中揭示宝石，建立第一眼构图。 |
| Facet | 切面 | 真实切面边线、结构拆解与重组；可调整展开程度。 |
| Polish | 抛光 | 同一宝石表面上的连续抛光前沿；可比较未抛光与抛光状态。 |
| Depth | 深处 | 内部反射、透光深度与阶梯式切割；可选择红宝石或蓝宝石。 |
| Color | 色泽 | 玉石的柔和透光与玛瑙的程序纹层、实体切片；可切换材质并调节透光程度。 |
| Brilliance | 火彩 | 改变光的入射角，观察白光、切面明暗与局部色散。 |
| Exhibit | 展境 | 红宝石、蓝宝石、钻石、玉石、玛瑙与水晶组成完整展陈；选择标本进入近看。 |

## 本地资源与离线使用

JavaScript、样式、字体与静态备选图像均包含在交付目录中。生产页面不依赖运行时字体 CDN、图片 CDN、外部模型下载或在线 API。取得 ZIP 后，可在断网环境中使用 `node serve.mjs` 打开随包的构建。

字体采用 Instrument Serif、DM Sans，以及供当前中文界面使用的 Noto Serif SC 子集。中文子集文件为 `public/fonts/facet-cjk.ttf`，不是完整中文字库。新增中文文案时，应同时检查新增字符是否覆盖；可从 Google Fonts 的 Noto Serif SC CSS2 接口按新的界面字符清单获取 `text` 子集，或换为完整官方字体，并保留 OFL 许可。字体来源与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

`public/images/gallery-still.webp` 是为本项目生成的静态展览构图，用于实时画面无法使用时的备选呈现。研究参考网页中的摄影与图表没有作为资源嵌入网站。

## 渲染、动态效果与备选呈现

实时宝石使用 Three.js 与程序化几何。切面材质在宝石的凸多面体边界上进行有限次光线求交，结合入射折射、Fresnel 反射、内部反射及路径长度吸收。色散采用共享内部路径的 RGB 出射方向近似；摄影棚反射环境、反射次数与末端光量估计也经过艺术化处理。

玉石采用独立圆润形体、内部云絮与柔和透光近似，玛瑙采用独立实体切片与程序纹带。它们不是将透明钻石简单染色。切面拆解、抛光前沿、剖解与材质交接服务于观看，不代表经标定的加工、光谱或宝石评级模拟。研究依据与具体边界见 [docs/REFERENCES.md](docs/REFERENCES.md)。

浏览器的 `prefers-reduced-motion` 会减少持续动态与滚动过渡；页面也提供环境动画暂停按钮。切换到后台时停止昂贵的画面绘制，返回时更新视口状态。

实时画面依赖浏览器可用的 WebGL 渲染能力。初始化失败、渲染失败或上下文丢失时，页面会切换到静态展览构图与文字内容；此时不能获得实时光学和三维观察效果。上下文恢复时会尝试重新建立实时舞台。
