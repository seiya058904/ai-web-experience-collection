# FACET — 场景编排说明

七章共享一个连续展览舞台。滚动控制物体、材质、光与观看距离；章节文字提供停留点。前一幕留下的切面、光路或纹带，应继续成为下一幕的构图依据。

本文件记录视觉任务与编排约定，供修改作品时使用；不作为构建、设备或浏览器验收记录。

## 时间轴约定

章节与阶段标签定义于 [src/narrative.ts](../../experiences/facet/src/narrative.ts)。每章局部进度采用以下区间；相邻章节的视觉混合跨过边界，不要求各图层在整数位置同时切换。

| 局部进度 | 阶段 | 任务 |
| --- | --- | --- |
| 0–15% | Enter | 从前一幕已有的光或形体建立进入关系。 |
| 15–36% | Stable Composition | 完整建立主构图，让宝石、文字与空间都可辨认。 |
| 36–76% | Living Hold | 留出观看时间，通过高光、内部细节或轻微镜头运动保持生命感。 |
| 76–94% | Handoff | 让宝石本身产生下一幕的介质。 |
| 94–100% | Exit | 撤去已完成任务的图层，同时维持下一幕的连续空间。 |

Hold 应保护最美的构图，不持续放大或旋转到无法观看。反向滚动应回到对应的结构与材质状态，不依赖只能播放一次的动画。

## 01 — LIGHT / 光起

**核心视觉系统：受控展览光场与实体宝石的反射。** 黑暗是展示空间，宝石有真实轮廓、切面反差与受光关系。低调光束和稀少反射为第一颗宝石建立尺度。

- **Enter：** 狭窄光带先出现，再逐渐揭示宝石边缘。
- **Stable Composition：** 主石与主标题形成完整的第一眼构图，保留大面积安静空间。
- **Living Hold：** 光源缓慢移动，宝石只作很小幅度的姿态变化；高光提供持续观察的内容。
- **Handoff：** 被照亮的边缘变成可读的切面构造线，物体继续占据同一个空间锚点。
- **Exit：** 开场文字与环境光淡出，切面边与宝石身体保留。

## 02 — FACET / 切面

**核心视觉系统：程序生成的明亮式切面、真实边线与结构拆解。** 按台面、冠部、腰部和亭部理解形体；辅助线表达面与面的关系，避免显示三角剖分的多余对角线。

- **Enter：** 上一幕的亮边扩展成完整线框，外形仍能被识别。
- **Stable Composition：** 展开角度与间距保持克制，主轮廓与切面组同时可读。
- **Living Hold：** 分组切面轻微转动或呼吸式分离，边线亮度随光变化。
- **Handoff：** 分离结构重新靠拢；一条明确的表面边界成为抛光的起点。
- **Exit：** 构造说明逐渐撤去，保留将被加工的同一颗宝石。

## 03 — POLISH / 抛光

**核心视觉系统：横跨同一模型的连续抛光前沿。** 通过粗糙表面与清晰光学表面的对照，让抛光的结果直接可见。它应表现为表面发生变化，不能只是换一张图片。

- **Enter：** 从已重组的形体开始，保留少量粗糙感与表面颗粒。
- **Stable Composition：** 抛光前沿停在便于比较的位置，两种表面同时成立。
- **Living Hold：** 前沿继续缓慢推进，清晰反射与内部深度逐步显露。
- **Handoff：** 完整抛光后的大台面接住光，成为进入内部的视觉入口。
- **Exit：** 表面加工线撤去，观看重心交给有色宝石的宽阔台面与内部深度。

## 04 — DEPTH / 深处

**核心视觉系统：红、蓝宝石的阶梯式切割、厚度吸收与内部轮廓辅助线。** 宽阔台面与阶梯切面提供不同于圆明亮式切割的观看入口；低亮度的嵌套轮廓与细小内部线条辅助表达深度，不将其写成额外的实体剖切系统。

- **Enter：** 从抛光后的透明宝石过渡到红宝石的阶梯式形体，沿用前一幕的空间锚点。
- **Stable Composition：** 深红内部、清晰台面与白色表面反射形成完整构图，轮廓辅助线保持从属。
- **Living Hold：** 观看距离轻微推进，红色逐步转为蓝色，内部明暗随光变化；观众也可使用 Ruby / Sapphire 按钮手动选择。
- **Handoff：** 有色透明材质逐渐让位于玉石的圆润轮廓，空间由深色转为浅色。
- **Exit：** 阶梯式宝石与内部辅助线一起退出，下一幕以温润材质继续叙事。

## 05 — COLOR / 色泽

**核心视觉系统：玉石与玛瑙的独立形体、材质和空间交接。** 玉石以圆润身体、云絮与柔和透光表达温润；玛瑙以有厚度的切片、自然偏心的程序纹带与层间视差表达结构。两者在浅色空间中形成材质对照。

- **Enter：** 玉石接过前一幕的位置与光，圆润表面替代透明切面的锐利反差。
- **Stable Composition：** 玉石的完整轮廓与柔和内部层次建立，侧向出现的玛瑙为接替提供方向。
- **Living Hold：** 玉石逐渐退向一侧，玛瑙转向正面并展开切片；观众可用 Jade / Agate 按钮选择材质，以透光控件改变光感。
- **Handoff：** 玛瑙纹带呼应地面的细小纹光，浅色展览空间逐渐收回深色光场。
- **Exit：** 玉石与玛瑙退场，完整透明宝石与白光重新建立下一章的观看中心。

## 06 — BRILLIANCE / 火彩

**核心视觉系统：受控反射环境、白光返回、稀疏色散与移动明暗切面。** 三种效果应能区分：明亮度建立主体，明暗变化形成闪烁，小范围色散提供火彩。

- **Enter：** 承接玛瑙场景的纹光与空间方向，清晰的透明宝石回到深色展览光场。
- **Stable Composition：** 以完整钻石和少量角度明确的光为主，保持轮廓与切面可读。
- **Living Hold：** 高光掠过时，局部出现短暂的彩色分离；避免持续铺满彩虹。
- **Handoff：** 出射光在空间中拉开，逐渐建立最终展陈的照明方向与底座位置。
- **Exit：** 单颗宝石的近景缩回展览尺度，光路辅助退出，展品仍保留在空间内。

## 07 — EXHIBIT / 展境

**核心视觉系统：六件标本、独立底座、空间光影与 Inspect 近看。** 钻石、红宝石、蓝宝石、玉石、玛瑙和水晶共同出现；各自保持自己的形体和材质语言。

- **Enter：** 由上一幕的光拉开展陈空间，底座与展品陆续建立。
- **Stable Composition：** 六件标本成为完整展览构图，文字与底座提供定位，宝石保持主角。
- **Living Hold：** 光与宝石姿态仅作轻微变化；观众可点击或轻点宝石本体，也可使用原生名称按钮进入 Inspect，近距离观察后返回整体。
- **Handoff：** 观看权交给观众：从连续叙事进入自主选择，再通过章节导航回访。
- **Exit：** 展览在完整构图中收束，末尾保留可操作的展示空间，不让画面被强制清空。

## 修改时应保留的关系

- **桌面：** 让物体、留白与标题共同构图，扩大屏幕时增加呼吸空间，不单纯把全部元素等比放大。
- **手机：** 重新安排宝石位置与文字区域；展示切面时减少同时出现的解释线；最终展品选择应有明确、可触达的入口。
- **减少动态效果：** 保留完整构图与章节信息，减少持续旋转、细碎闪烁和大幅镜头运动。Inspect 的选择与返回仍应可理解。
- **素材：** 辅助图像只能补充质感和研究参考。每章的主要视觉任务继续由形体、材质、光或空间系统完成。
- **章节节奏：** 调整时先检查 Stable Composition 与 Living Hold 是否足够，再增加转场。宝石本身应持续提供下一幕的入口。
