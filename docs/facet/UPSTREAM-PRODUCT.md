# FACET — The Light Within

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
A continuous, scroll-directed digital exhibition about gemstones themselves: purity, facets, polish, internal depth, color, light and exhibition space. The artwork leads; the interface recedes.

## Users
Visitors exploring a premium visual artwork on desktop or mobile. Desktop compositions must accommodate 1080p, 1440p and 4K.

## Capabilities and Constraints
Every main chapter contains its own authored visual system. All scenes follow Enter → Stable Composition → Living Hold → Handoff → Exit. Include diamond, ruby, sapphire, jade, agate and crystal. Support forward, reverse and rapid scrolling, touch, resizing, reduced motion and keyboard navigation.

## Brand Commitments
FACET — The Light Within. Pure, luminous, luxurious, precise, spatial, cinematic. Gallery, optical and gemstone material language. No jewelry retail, sales, checkout, brand advertising or encyclopedia structure.

## Stack
Implementation choice delegated by the explicit technical brief: mature Canvas/SVG/CSS, GSAP, Lenis, optional Three.js/WebGL. The implementation will use Vite + TypeScript and Three.js for a portable static build. No backend is needed.

## Delivery
A complete, clean, runnable ZIP including source, necessary local assets, locked packages, build/preview methods, README, attribution and license, and a production build. No hosted publishing, site registration, node_modules, caches, traces, logs or temporary screenshots in the ZIP.

## Product Principles
- The gem is the protagonist.
- Media conveys material; real-time geometry and light build the experience.
- Each scene becomes the medium for the next.
- Beautiful compositions stay long enough to be seen.
- Controls are real and the final build works without runtime third-party network requests.

## Accessibility
Reduced-motion support, semantic chapter navigation, visible keyboard focus, controls with meaningful accessible names, and readable fallback content.
