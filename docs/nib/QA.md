# NIB — 验收记录

验收日期：**2026-10-07**。本记录描述实际执行的本地检查，不代表所有硬件与浏览器的兼容认证。

## 验收结论

最终整站浏览器回归包含 **56 项断言，全部通过**：十个桌面场景、十个移动场景、滚轮连续性、快速反向、暂停、尺寸变化、刷新、浏览器冻结与恢复、原生触摸输入、阅读视图、对话框、减少动态效果和无 JavaScript 正文。运行期间 **0 条控制台／页面错误，0 次外部运行资源请求**。

此外，生命周期专项先复现并修复了阅读章节不同步、键盘焦点时序、对话框后无效重绘和深层刷新偏移。随后用**自由滚动而非章节链接**增加了四个严格回归：桌面滚动与缩放后刷新、手机滚轮后刷新、同一任务内滚动并立即刷新、干燥结尾停止重绘，均通过。

## 材质与构图检查

十个章节均在桌面与手机上停帧检查，并与精选 Visual Bible 对照。还抽查了金属进入储墨器、通道转入平衡、狭缝进入弯月面、弯月面转到纸张，以及纸面缩放与干燥的中间状态。

最终修正包括：手机开场独立肖像素材中的附着悬墨、裁切与标题比例；弯月面使用独立液体光学材质；微观纸张使用有纵深的纤维材质，细小染色路径沿纤维间隙前进，凸起纤维局部遮住湿墨；漆面笔杆接缝；移动端墨迹与结尾文字间距；顶部文字在漆面与纸张上的对比度；金属到纸张转场中的双笔尖重叠。最后的镜头沿附着的液面进入光学近景，再拉回有真实金属弧面和笔舌厚度的斜侧笔尖；这一姿态直接延续触纸与书写，没有平面压缩或两个笔尖的叠化。触纸之后，吸收、书写与干痕始终使用同一条几何曲线。

设计检测器运行一次。已修复小于 11 px 的功能标签和基于高度的刻度动画。刻度改用 `scaleY`；原本的章节外边距提示不适用于独立固定排版，实际文字使用 25 px 以上的安全边距。顶部采用差值混合以适应金属、黑漆与纸张，不能仅用静态 CSS 前景／背景配对推算其最终对比度；对应像素已实际查看。

## 可访问性与状态

- 十个章节的标题和短文由语义 HTML 提供；画布属于装饰层。
- 章节目录与 Colophon 支持键盘、关闭按钮和 Escape；关闭后返回触发控制。
- 键盘跳转先解除目标章节的 `inert`，再把焦点移到标题。
- 阅读模式更新当前章节与明暗主题，返回影像时停在阅读者当前所在章节。
- 对话框覆盖页面时不重绘背景；减少动态效果静止时和充分干燥的结尾均为 **0 次无效画布重绘**。
- 减少动态效果的标题、章节标记和材质画面使用同一个离散章节索引。
- 资源和字体就绪后再开启连续影像；初始化失败时保留正文。

## 性能与构建

生产构建为 **25 个文件，2,148,039 bytes（约 2.15 MB）**，包含全部运行图像、字体、脚本和样式；无需安装依赖。11 个运行 WebP 共 **1,816,290 bytes**。PNG 原件和 Visual Bible 仅供交付与后续制作，不作为页面运行资源加载。

主画布设定约 **440 万像素**的上限。3840 × 2160 的大屏检查中实际画布为 **2797 × 1573**。移动端设备像素比 2 时，390 × 844 对应画布 **605 × 1308**，符合 1.55 的移动上限。离屏材质与纤维缓存在就绪／尺寸变化阶段准备；场景不创建独立计时器。

纸面模块在软件 Chromium 的专项观察中，多数稳定帧约 1–5 ms；极近距离笔尖处为约 10–18 ms。它们是该环境的模块采样，**不是完整页面在真实设备上持续 60 fps 的承诺**。本包保留适合复查的清晰源代码与像素预算。

`npm run check` 与 `npm run check -- --dist` 均通过：**10 个 JavaScript 文件、37 个本地引用、5 条第三方完整性记录**。构建只复制必要运行文件，固定时间戳，并为有序文件树输出 SHA256。最终运行树标识为 `92c636674386dc9fdf093e63dc7df25ced5a46d63c125a136b6a4d2a1a50ebde`。

## 明确未覆盖的环境

真实 iPhone／Android 硬件、Safari、Firefox 和厂商触摸驱动未在本环境中运行。后台标签页在无头 Chromium 中仍报告 `visibilityState = visible`，所以切换标签本身没有重现所有浏览器的真正后台节流。实际执行了浏览器冻结／恢复协议、刷新和历史返回检查，恢复处理程序也经过源码审阅；这些证据不等于所有移动系统的后台恢复验证。

需要在特定设备上复核时：本地运行后，依次缓慢滚动、快速前后滚动，在弯月面、初次触纸和吸收时停住，旋转屏幕、刷新、切换到另一标签再返回，最后启用系统“减少动态效果”。重点观察笔尖接触位置、墨线边缘、文字安全区和恢复后的章节位置。
