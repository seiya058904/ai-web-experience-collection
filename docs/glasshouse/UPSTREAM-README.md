# GLASSHOUSE — Light Through Matter

一座由实时玻璃、光束、折射、镜面、透明层和镜头运动搭建的数字空间装置。滚动推进同一个连续世界：**Light → Surface → Refraction → Reflection → Layers → Glasshouse**。

本项目交付完整源码和预先构建的 `dist/`。场景由实时几何、光学着色与程序化运动建立，配合一张为本项目生成的局部光投影纹理；没有建筑摄影、视频或运行时 CDN 请求。所需纹理与字体随生产构建一并提供。

## Windows：解压后直接体验

1. **完整解压 ZIP**，保留目录结构。不要直接在压缩包内部运行。
2. 确保系统已安装 [Node.js](https://nodejs.org/)。推荐满足 `package.json` 要求的 Node.js LTS；项目要求为 `^20.19.0 || >=22.12.0`，可使用 Node.js 22.12+ 或 24.x。
3. 双击 `START-PREVIEW.bat`。
4. 保持弹出的终端窗口开启，在浏览器打开 **http://127.0.0.1:4173/**。
5. 在终端按 `Ctrl+C` 停止预览。

这条路径直接运行 ZIP 中的成品，**不需要 `npm ci`、`node_modules` 或互联网连接**。启动器不会安装依赖、重新构建或发布网站。如果 Node.js 不存在、端口被占用或缺少 `dist/index.html`，终端会显示明确原因。

也可以在解压目录的终端运行：

```powershell
node tools/serve.mjs
```

不要通过双击 `dist/index.html` 使用 `file://` 打开。浏览器模块和资源应通过上面的本地 HTTP 服务加载。

## macOS / Linux

macOS 可运行 `START-PREVIEW.command`。如果系统不直接执行它，在解压目录打开终端运行：

```sh
sh START-PREVIEW.command
```

macOS 和 Linux 也都可以直接使用：

```sh
node tools/serve.mjs
```

启动脚本仅使用 Node.js 内置模块。它以脚本自身位置定位 `dist/`，不会把项目源码目录作为网站根目录。

## 修改源码与构建

在项目根目录依次运行：

```sh
npm ci
npm run dev
```

`npm ci` 按 `package-lock.json` 安装锁定版本；首次安装需要访问 npm。开发服务地址以终端显示为准，项目默认使用端口 `4173`。

完成修改后运行：

```sh
npm test
npm run build
npm run preview
```

`npm run build` 将当前源码构建至 `dist/`；`npm run preview` 使用 Vite 预览这份构建。若只想查看已构建的成品，可继续使用无需依赖的 `node tools/serve.mjs`，或 `npm start`。

| 命令 | 用途 | 是否需要安装依赖 |
| --- | --- | --- |
| `node tools/serve.mjs` | 预览已交付的 `dist/` | 否 |
| `npm start` | 同上 | 否，系统需有 npm |
| `npm ci` | 安装锁定的开发与运行依赖 | 需要联网安装 |
| `npm run dev` | 开发服务与热更新 | 是 |

| `npm run preview` | 使用 Vite 查看生产构建 | 是 |

## 本地预览选项

默认服务仅监听本机 `127.0.0.1:4173`。端口被占用时：

```sh
node tools/serve.mjs --port 4174
```

构建使用相对资源路径 `base: './'`。可以在本地检查子路径运行：

```sh
node tools/serve.mjs --base /studies/glasshouse/
```

然后打开 `http://127.0.0.1:4173/studies/glasshouse/`。指定的子路径才会映射到 `dist/`；服务器不会为无关 URL 回退到源码或列出目录。

需要在同一局域网的手机上测试时，可明确开启局域网监听：

```sh
node tools/serve.mjs --host 0.0.0.0
```

手机访问 `http://这台电脑的局域网IP:4173/`。电脑和手机需在同一网络，Windows 防火墙需允许该次本地连接。关闭终端即可停止。这不是部署步骤，项目没有远程发布脚本。

## 体验与操作

- **滚轮 / 触控板 / 手指滑动**：向前或向后穿过空间。每一章具有稳定构图、轻微的持续光影运动和与下一章相连的交接。
- **底部章节导航 / Index**：进入所选章节的稳定构图；Index 打开完整目录，`Close` 或 `Esc` 关闭。
- **Surface — Clear / Frosted / Mirror**：选择居中的材质，对比同一背景经过透明、磨砂和镜面处理后的变化。
- **Refraction — Light angle**：调整入射光的方向；**Glasshouse — Sun position**：调整最终建筑场景的日光方向。
- **Motion**：暂停或恢复环境中的持续运动；页面仍然可以滚动和阅读。系统开启减少动态效果时，此开关保持关闭。
- **Begin again**：返回开场构图。
- **键盘滚动**：`↑` / `↓` 小幅移动，`Page Up` / `Page Down` 翻动，`Home` / `End` 到达旅程两端；`Space` 向下、`Shift+Space` 向上。这些页面滚动输入统一交给 Lenis。
- **键盘控件**：使用 `Tab` 定位导航、按钮和滑块，`Enter` / `Space` 激活按钮；滑块获得焦点后可用方向键微调。表单、按钮和可编辑区域保留原本的按键操作，不被页面滚动接管。
- **系统减少动态效果设置**：页面响应 `prefers-reduced-motion`，缩短滚动旅程并移除持续运动和长距离空间插值，保留所有章节及可读内容。

## 六章各自的视觉任务

| 章节 | 主要视觉系统 |
| --- | --- |
| **01 — Light** | 光束、玻璃边缘与局部投影光迹；桌面标题的局部字形进入玻璃后方 |
| **02 — Surface** | 透明、磨砂与反射的材质差异，以及厚度和表面感 |
| **03 — Refraction** | 透射玻璃与程序化光束；棱角改变视觉中的光路和色彩 |
| **04 — Reflection** | 三面实时平面镜显示主相机画外的门廊和 ECHO 字形，重组前景和背景 |
| **05 — Layers** | 多层透明结构在同一相机空间内错位、展开与交接 |
| **06 — Glasshouse** | 玻璃面、结构、地面光影和建筑体量组成最终空间 |

环境和气氛贯穿六章，作为光、反射与空间的连续变化存在。

## 实现结构

项目采用原生 JavaScript、Vite、Three.js、GSAP / ScrollTrigger 与 Lenis。没有应用框架和后端服务。

| 文件 / 目录 | 职责 |
| --- | --- |
| `index.html` | 语义化页面入口与内容结构 |
| `src/` | 场景、材质、滚动旅程、界面与样式源码 |
| `src/main.js` | GSAP 统一时钟、Lenis / ScrollTrigger 同步、输入与页面恢复 |
| `src/journey.js` | 单一归一化进度、章节采样、交接与减少动态效果逻辑 |
| `src/world.js` | 八块共享玻璃面、六组姿态、相机、棱镜、镜面与最终建筑 |
| `src/optical-pass.js` | 缓冲交替读写的逐层透射、磨砂扩散与显示亮度域 FXAA，优先使用线性 HDR |
| `src/caustic-field.js` | 原创局部尖点光迹 GLSL，生成聚焦、分叉与渐隐的焦散近似 |
| `src/atmosphere.js` | 天空与远处地面共用的线性光颜色场 |
| `src/optics.js` | 程序化环境照明、材质基底、地面投影光影与光束 |
| `src/type-plane.js` | 桌面 Hero 标题右侧 18% 字形的场景文字平面与屏幕对齐 |
| `src/assets/focused-light.png` | 专为本项目生成的黑底光投影纹理，经 GLSL 投射到局部玻璃与地面 |
| `src/ui.js` / `src/style.css` | 章节文案、材质 / 光照控制、目录与响应式版式 |
| `tests/journey.test.mjs` | 可逆性、连续性、端点及有限数值域检查 |
| `tools/serve.mjs` | 只服务 `dist/` 的免依赖本地静态服务器 |
| `dist/` | 可立即运行的生产构建 |
| `third-party-licenses/` | 随使用的软件与字体保留的授权文件 |
| `ATTRIBUTION.md` | 原创素材说明、第三方组件及研究参考 |
| `DESIGN.md` | 视觉语言、场景生命周期、移动重构与源码对应 |

整个装置由单一、可逆的滚动坐标驱动。**八块主要玻璃面在六组姿态之间连续变换**，相机与共享物体一起把前一章的结构交给下一章。章节的稳定区间保留完整构图，微小的光影、入射角与空间呼吸维持 living hold。棱镜和门框在交接中沿纵深退远并逐渐透出，保持空间中的体量感。相同滚动坐标会得到相同的主体姿态；环境时间单独处理。

**滚动和渲染共用 GSAP ticker**：Lenis 在同一时钟中推进，ScrollTrigger 提供旅程进度，随后采样场景并渲染。异步字体、纹理与着色器准备完成后，初始化继续沿用当前 ticker 时间，使加载期间的提前滚动与场景启动处于同一条时间轴。画布固定在视口，文档高度提供滚动距离；实现没有 ScrollTrigger pin，也没有逐章 pin / unpin。几何直接读取当前进度，不再增加一层追赶目标值的动画。

**透射由 `src/optical-pass.js` 逐层完成。** 首先渲染背景、文字与不透明物体，然后把可见玻璃按相机空间深度由远至近排序。每层读取已经完成的背后画面，并将折射、吸收与高光合成到另一张缓冲；两张缓冲交替读写，使前面的玻璃能看见已经经过后面玻璃的内容。支持浮点颜色缓冲时使用线性 HDR，否则降级至 8 位缓冲。`MeshPhysicalMaterial` 保留基于材质的镜面高光和环境反射计算，玻璃的内置 `transmission` 在这条自定义路径中关闭。

磨砂以 mip 层级采样扩散背后画面，避免多个锐利副本叠出重影文字。全部玻璃合成后，**同一个末端 pass 执行 FXAA 与输出处理**：每次 FXAA 采样先进行 ACES 色调映射和 sRGB 输出转换，再用显示颜色的亮度差识别边缘。光学层始终在线性颜色中合成，每个最终采样只转换一次，不额外叠加一遍输出编码。

**文字与反射分开采用适合各自用途的实现。** 桌面 Hero 标题右侧 18% 的字形区域通过 `src/type-plane.js` 进入玻璃后的场景，参与真实的透射合成；标题主体保留 DOM 清晰度，移动端全部使用 DOM 标题。三个位于玻璃上的 Three.js `Reflector` 执行平面反射，显示主相机画外的门廊与 ECHO 字形；每面镜子渲染时暂时隐藏另外两面，避免递归反射。地面倒影采用带衰减的镜像几何近似，没有使用地面平面反射或光线追踪。

窗口或字体尺寸变化时，文字平面重新测量 DOM；如果 Canvas 像素尺寸改变，先释放旧的 `CanvasTexture`，再创建与新尺寸匹配的纹理，避免向原尺寸的 GPU 存储上传更大的位图。

**局部光迹来自专用纹理与程序化细节的组合。** `src/assets/focused-light.png` 是由 OpenAI ImageGen 为本项目生成的黑底光投影材质纹理（gobo）。GLSL 根据世界空间光向将它投射到玻璃与地面，再结合 `src/caustic-field.js` 的局部尖点光迹；它不是整屏背景或玻璃摄影。具体文件来源、尺寸与授权见 `ATTRIBUTION.md`。

天空和远处地面共同调用 `src/atmosphere.js` 的线性光颜色场。远端地面逐渐融入同一组背景颜色，保持明暗变化中的空间连续性，避免两套独立背景计算造成地平线接缝。

**光学范围说明：** 本作品以视觉创作为目标。逐层透射属于屏幕空间近似，地面及玻璃上的焦散由投影纹理与程序化光迹共同构成，光谱束和地面倒影也经过视觉设计。没有执行完整光线追踪、能量守恒验证或真实玻璃色散计算；它不是用于科学测量的光学模拟器。

## 响应式与运行支持

桌面与手机采用各自的相机位置、取景目标、文字层级和滚动距离。手机进入 Layers 时，中间部分玻璃面通过连续的光学淡出减少视觉密度，边缘、倒影与阴影同步减弱；反向滚动使用同一权重恢复。版式为材质按钮、滑块和底部导航留出空间。

渲染按像素预算限制缓冲分辨率。**DPR 为 1 的桌面在预算允许时默认请求 1.25 倍渲染像素比**，以超采样改善边缘；桌面请求上限为 1.5、移动端为 1.65，同时分别受约 340 万 / 160 万像素预算与自适应质量系数约束。4K 视口不代表强制以完整 4K 像素数量执行每一次透射合成。浏览器隐藏或打开目录时暂停场景工作，返回时根据当前滚动位置恢复。

建议使用支持 WebGL 2、开启硬件加速的现代 Chrome、Edge、Firefox 或 Safari。代码提供 WebGL 不可用时的可读降级内容。设备、驱动、系统节能模式和浏览器设置都会影响实时玻璃的帧率；4K 下的性能应以实际设备体验为准。

遇到问题时：

| 现象 | 处理方法 |
| --- | --- |
| 双击启动器后提示找不到 Node.js | 安装符合上文版本要求的 Node.js，重新打开终端 / 启动器 |
| 提示 `dist/index.html` 不存在 | 重新完整解压交付 ZIP；若在改源码，执行 `npm ci`、`npm run build` |
| 端口已被占用 | 关闭已有预览，或改用 `--port 4174` |
| 直接打开 HTML 后空白或资源失败 | 使用 HTTP 预览服务，不使用 `file://` |
| 只有降级内容，没有实时玻璃 | 检查浏览器 WebGL 2 与硬件加速设置，更新显卡驱动后重启浏览器 |
| 修改源码后预览没有变化 | `node tools/serve.mjs` 查看的是 `dist/`；先重新构建，或使用 `npm run dev` |
| 手机无法访问电脑上的预览 | 明确使用 `--host 0.0.0.0`，确认同一网络、IP 和本地防火墙设置 |
