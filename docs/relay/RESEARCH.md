# RELAY — research and representation

RELAY is an original toy transport protocol. RFC 9293 §2.2 informs the ideas of ordering, detection and retransmission, and Ryoji Ikeda's *datamatics* is a methodological reference for making data perceptible; no artwork, code or sound is borrowed. Block size, channels, acknowledgement strategy, queue admission and budgets are authored demonstration rules.
