    Behind the work

    A small world.
    Real consequences.

    RELAY is an original toy protocol. A sentence becomes UTF-8 bytes, takes a route, and finds its order again. It all happens here, in your browser.

    Arrival is a fact. Confirmation is knowledge.

    An orange block travels outward; a green acknowledgement travels back. Losing the second does not erase the first. The sender keeps its copy until the acknowledgement returns.

    Looking never changes the outcome.

    Scroll to change your point of view. Play, pause or step to move simulation time. The event strip reads recorded moments without changing the current round. Changing a message starts a new round.

    The rules of this world

    Five bytes per block. Four unconfirmed blocks in the sending window. Eleven demonstration seconds before retry. At most four sends per block, with a 64-second round deadline.

    Six junctions form two alternative paths. A closed channel refuses new traffic in either direction; a block already travelling finishes that hop. Queued blocks choose another open path or wait. The speed control changes the queue's admission interval, not the propagation delay or a real TCP congestion window.

    The receiver checks each block's round, range and byte payload, ignores duplicate content and acknowledges it again. Only complete characters before the first byte gap are displayed. Exhausted blocks remain retained but release a window place so later blocks can still travel.

    Every event has a simulation timestamp and stable sequence. A seed and the same timed operations produce the same result, independent of scrolling and refresh rate. A hidden tab pauses; returning never catches up.
