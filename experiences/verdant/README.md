# VERDANT in the Collection

The original complete experience is retained under this directory. Use the root `npm run dev` and open `/verdant/`; build/deploy instructions are in [the Collection README](../../README.md). Assets live in `../../public/verdant/`. No original cloud/server starter is required.

Typography uses flow-based reading groups for Architecture, Understory, Coda and mobile Arrival. Wide/short Architecture changes line grouping, not the complete visual identity. The single sticky journey, scene masks and living photographic surfaces remain. See [asset sources](ASSET-SOURCES.md).
