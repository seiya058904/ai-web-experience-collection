# ORBITAL in the Collection

The original complete experience is retained under this directory. Use the root `npm run dev` and open `/orbital/`; build/deploy instructions are in [the Collection README](../../README.md). Assets live in `../../public/orbital/`. No original cloud/server starter is required.

The eight scenes, original spacecraft, WebGL renderer, Canvas fallback, controls, audio and reading companion remain. Only path/runtime integration and idle readiness scheduling were changed. See [upstream source notes](SOURCE.md) and the retained notices in THIRD-PARTY-LICENSES.
